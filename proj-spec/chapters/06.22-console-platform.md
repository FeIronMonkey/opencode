## Behavior

### Context, actor, and database sessions

`Context.create` uses `AsyncLocalStorage`. `use()` throws `Context.NotFound` when empty (`packages/console/core/src/context.ts`).

`Actor.provide(type, properties, cb)` stores the actor and nests `Log.provide`. `Actor.assert(type)` throws `` `Expected actor type ${type}, got ${actor.type}` ``. `assertAdmin` throws `Action not allowed. Ask your workspace admin to perform this action.` unless `userRole() === "admin"`. `workspace()` / `account()` throw when the current actor lacks `workspaceID` / `accountID`.

`Database.use` reuses an existing transaction context or runs the callback against the PlanetScale client and then runs queued `effects`. `Database.transaction` nests via `TransactionContext` or opens `client().transaction`. `Database.effect` queues work until the outer transaction finishes (`packages/console/core/src/drizzle/index.ts`).

### Subscription usage analysis

`Subscription.getLimits` parses `Resource.ZEN_LIMITS.value` with `LimitsSchema` (keys `free`, `lite`, `black` with plan `"20"`/`"100"`/`"200"`) (`packages/console/core/src/subscription.ts`).

`analyzeRollingUsage`: window is `window * 3600 * 1000` ms. If `timeUpdated` is before `now - window`, status `"ok"`, `usagePercent` `0`, `resetInSec` `window * 3600`. Else if usage below `centsToMicroCents(limit * 100)`, `"ok"` with floored percent capped at 100. Else `"rate-limited"`, `usagePercent` `100`.

`analyzeWeeklyUsage` uses `getWeekBounds(now)` (Monday 00:00 UTC through +7 days; Sunday offset `(getUTCDay() + 6) % 7`) (`packages/console/core/src/util/date.ts` `getWeekBounds`).

`analyzeMonthlyUsage` uses `getMonthlyBounds(now, timeSubscribed)`: period anchors on subscription UTC day/time, clamping to month length (`getMonthlyBounds`).

Statuses are `"ok"` or `"rate-limited"` as above.

### Quota reset

`Quota.reset({ workspaceID, plan })`: `plan` `"lite"` zeros `rollingUsage`/`weeklyUsage`/`monthlyUsage` on non-deleted `LiteTable` rows (timestamps unchanged). `plan` `"subscription"` zeros `rollingUsage`/`fixedUsage` on `SubscriptionTable`. Returns `before` sums (`packages/console/core/src/quota.ts`).

### Referrals

`normalizeCode` uppercases, strips non `[A-Z0-9]`, slices to `CODE_LENGTH` (`Referral.normalizeCode`). New codes: last 10 chars of `ulid()`, uppercased (`generateCode`).

`summary` ensures a `ReferralCodeTable` row, then lists inviter/invitee rewards as `pending` / `available` / `applied` with amounts in cents.

`applyReward` sets `timeApplied` and `Billing.subtractLiteUsage`. `usagePreview` compares lite rolling/weekly/monthly percents before vs after subtracting the reward.

`createFromAccount` no-ops on empty code; rejects invalid code, already-redeemed invitee, self-referral; no-ops if the invitee has no workspaces, already has lite, or has a payment with `enrichment.type` `'lite'`.

`create` writes inviter + invitee `ReferralRewardTable` rows of `REWARD_AMOUNT`. `completeFromLiteSubscription` inserts inviter reward and, if missing, invitee reward.

### OpenAuth issuer

Default export `fetch` (`packages/console/function/src/auth.ts`):

1. If path is `/authorize` and `redirect_uri` is non-null, reject when `isAllowedAuthorizationRedirect(client_id ?? "", redirect_uri)` is false: body `Unauthorized client`, status `400`.
2. OpenAuth `issuer` with GitHub + Google providers, Cloudflare KV storage, `allow` = same redirect helper.
3. `success`: GitHub loads `/user/emails` and `/user` with `User-Agent` `opencode` and `Accept` `application/vnd.github+json`. Requires primary verified email. Google requires `id.email_verified`. Email provider implementation is commented out; other providers throw `Unsupported provider`.
4. If `Resource.App.stage !== "production"` and email does not `endsWith("@anoma.ly")`, throw `Invalid email`.
5. Match existing `AuthTable` by provider+subject or email subject. Create `Account.create({})` when neither exists (`newAccount = true`). Upsert github/google + `email` auth rows.
6. Under `Actor.provide("account", …)`: `User.joinInvitedWorkspaces()`; if the account has no live workspace membership, `Workspace.create({ name: "Default" })`.
7. Return `ctx.subject("account", accountID, { accountID, email, newAccount })`.

### Authorization redirect allowlist

`isAllowedAuthorizationRedirect(clientID, redirectURI)` (`packages/console/function/src/auth-redirect.ts`):

- `clientID` MUST be `"app"` (otherwise false).
- `redirectURI` MUST parse as `URL`.
- Hostname `localhost` or `127.0.0.1`: protocol `http:` or `https:`.
- Else protocol MUST be `https:` and hostname MUST be `opencode.ai` or `endsWith(".opencode.ai")`.

### Inference log processor

`tail` (`packages/console/function/src/log-processor.ts`) processes Cloudflare `TraceItem`s that have a POST `request` whose pathname is one of:

- `/zen/v1/chat/completions`, `/zen/v1/messages`, `/zen/v1/responses`, or starts with `/zen/v1/models/`
- `/zen/go/v1/chat/completions`, `/zen/go/v1/messages`, `/zen/go/v1/responses`, or starts with `/zen/go/v1/models/`

IP from header `x-real-ip`. Logs whose message starts with `_metric:` are JSON-parsed (`slice(8)`). Emits `event_type` `"llm.error"` when `llm.error.code` is present, plus `"completions"`. If `Resource.LakeIngest` is linked, POSTs `{ events }` with `Authorization: Bearer ${secret}`. Lake rows use `_datalake_key` `"inference.event"` and `dataset` `"zen"`.

`ipPrefix`: IPv4 → `` `${ip}/32` ``; IPv6 → first four hextets + `::/64` (expand `::`, lowercase, strip leading zeros per hextet except keep a zero nibble via `/^0+(?=.)/`).

### Model TPS stats

POST-only (`packages/console/function/src/stat.ts`). Non-POST: `Method Not Allowed`, status `405`. Body `{ ids: string[] }`. Empty `ids` returns `{}`. Each id maps to 30 `{ interval, qualify, unqualify }` (zeros when missing).
