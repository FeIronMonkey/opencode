## Behavior

### App bootstrap, locale path, and theme

`strip` / `route` / `localizedUrl` (`packages/stats/app/src/lib/language.ts`):

1. Strip locale prefix via re-exported `localeStrip`, then keep segments after the last `data` path segment, always rewriting onto `basePath` `/data` (preserve trailing slash).
2. `route(locale, pathname)` applies console `localeRoute` to that normalized path.
3. `localizedUrl` prefixes `https://opencode.ai` (same `baseUrl`; OQ-6.23-12).

`LanguageProvider` (`packages/stats/app/src/context/language.tsx`) name `"StatsLanguage"`: server uses `localeFromRequest`; client prefers `fromPathname`, then cookie, then `document.documentElement.dataset.locale`, then `navigator.languages` / `navigator.language`, else `"en"`. `setLocale` writes `document.cookie = cookie(next)` and the footer language `<select>` assigns `route(locale, pathname)` keeping search and hash.

`I18nProvider` (`packages/stats/app/src/context/i18n.tsx`) name `"StatsI18n"`: `t(key, params)` looks up `dict(locale)[key]` and replaces `{{name}}` tokens. English copy is the `en` object in `packages/stats/app/src/i18n.ts`. Dictionaries exist for keys of `dictionaries`: `ar`, `br`, `da`, `de`, `en`, `es`, `fr`, `it`, `ja`, `ko`, `no`, `pl`, `ru`, `th`, `tr`, `uk`, `zh`, `zht`. English `app.title` is `"AI Model Usage Rankings | OpenCode Data"`.

`LocaleLinks` emits `rel="canonical"` for the current locale URL, `rel="alternate"` `hreflang` per `tag(locale)` for every `LOCALES` entry, and `hreflang="x-default"` for English (`packages/stats/app/src/component/locale-links.tsx`).

HTML shell (`entry-server.tsx`): `lang={tag(locale)}`, `dir={dir(locale)}`, `data-locale={locale}`. Inline `stats-theme-preload-script` reads `localStorage.getItem("opencode:stats-theme")`; only `"dark"` / `"light"` / `"system"` are kept (else `"system"`). Sets `document.documentElement.dataset.statsTheme` and `color-scheme` unless system. Runtime `applyThemePreference` does the same (`stats-shell.tsx`). Pages persist preference with `window.localStorage.setItem(themeStorageKey, preference)`.

`getGitHubStars` (`stats-shell.tsx`) formats `stargazers_count` with `Intl.NumberFormat("en", { notation: "compact", maximumFractionDigits: 0, roundingIncrement: 5 })`.

`setStatsPageCacheHeaders` sets `Cache-Control` to `statsPageCacheControl` and `Vary` to existing values plus `Accept-Language`, `Cookie`, and `LOCALE_HEADER` (case-insensitive dedupe).

`runStatsEffect` is `Effect.runPromise` (`packages/stats/app/src/stats-runtime.ts`).

### Model catalog

`loadModelCatalog` (`packages/stats/app/src/routes/model-catalog.ts`) fetches the three catalog URLs in parallel. HTTP `!ok` or throw yields `undefined` payload (`fetchCatalogPayload`). Labs HTML is parsed for `<script id="search-index">` JSON; items with `type === "lab"` are kept (`readLabSearchIndex`).

Each catalog model requires string `id` and `name` with `id` split into lab + remaining slug (`readModelCatalogEntry`). Lab/slug are `catalogSlug` (trim, lower, non-alphanumeric → `-`, collapse dashes). Costs overlay from pricing payload keys `catalogIdKey(id)`, `` `${lab}/${slug}` ``, or `slug`. Lab id aliases in `catalogLabSlug`: `moonshot` → `moonshotai`; `qwen` → `alibaba`; `zhipu` / `zai` → `zhipuai`. Display names in `formatCatalogLabName` include `moonshotai` → `"Moonshot"`, `zhipuai` → `"Zhipu"`, `xai` → `"xAI"`, etc.

`findModelCatalogEntry(catalog, model, lab?)` first applies imported `statModel(model, undefined)` (OQ-6.23-11), then matches `entry.id`, then lab+slug, then slug only.

`isProviderlessLab` is true when lab is missing or `catalogSlug(lab) === "unknown"`. `isKnownCatalogLab` is false for providerless labs; otherwise it compares slugged `formatCatalogLabName` against catalog lab ids.

### Home page

Server query `getStatsHomeData` (`packages/stats/app/src/routes/index.tsx`, query name `"getStatsHomeData"`): `runStatsEffect(getStatsHomeData())` plus `loadModelCatalog()`. Home binds:

| Field | Source slice |
|-------|----------------|
| `usage` / `users` / `leaderboard` | `stats.*.Go["2M"]` |
| `market` | `stats.market["2M"]` |
| `tokenCost` | `priceTokenCostFromCatalog(stats.tokenCost.Go, catalog)` |
| `cacheRatio` / `sessionCost` | `stats.*.Go` |
| `retention` / `country` | `stats.retention` / `stats.country` |
| `catalogLabs` | `catalog.labs.map((lab) => lab.id)` |

`priceTokenCostFromCatalog` drops rows with no catalog `cost`; sets `total` to catalog `output`, `input`/`output` from catalog, `cached` to `cacheRead ?? input`; sorts by `total` then `model`.

Home OG image is `banner.jpg` resolved against `localizedUrl("en", "/data/")` (`image/jpeg`, 1200×630). Lab, model, and compare index use `banner.png` (`image/png`). Compare detail uses `twitter:card` `summary` and no og image block.

Sections (ids): `#top-models` (chart + `#leaderboard`), `#unique-users`, `#retention` (hardcoded title `"Weekly Retention"`), `#session-cost`, `#token-cost`, `#cache-ratio`, `#market-share`, `#geo-breakdown`, `#model-comparison`. Geo list shows `data.slice(0, 15)`. Token cost rows `slice(0, 13)`; cache ratio and session cost `slice(0, 16)`. Default active index for market/cost charts is `2` (clamped).

Leaderboard: first 3 featured, rest compact; mobile repeats full list as featured. Rank is `String(rank).padStart(2, "0")`. `change === null` displays `home.new` (`"New"`); else `+N%` or `N%`. Tokens via `formatBillions`: `>= 1000` as `T`, else `${value}B`. Links: `language.route(`${BASE_URL}${modelSlug(provider)}/${modelSlug(model)}`)`. `modelSlug` trims, lowercases, non-alnum → `-`. Provider icons: `"MiniMax"` → `"minimax"`, `"Moonshot"` → `"moonshotai"`, `"Zhipu"` → `"zhipuai"`, else `author.toLowerCase()`.

Country `ZZ` displays `home.unknown` (`"Unknown"`). Share `formatGeoShare`: one decimal when `0 < value < 1`, else integer percent.

Home comparison pairs (`homeComparisonPairs`): leaderboard index pairs `[0,1]`, `[0,2]`, `[1,2]`, `[2,3]` with details `"Top two by recent usage"`, `"Leader vs challenger"`, `"Adjacent leaderboard pair"`, `"Top model alternative"`. Featured cards use `canonicalComparisonHref` (sorted `lab/slug` path), max 4 pairs (`ComparisonCardsSection` `variant="featured"`).

Empty-state copy uses i18n keys such as `home.noUsageTitle` `"No usage data"`. Loading shows `home.loadingTitle` `"Loading data"`.

### Lab and model pages

Lab query `"getStatsLabPageData"`: catalog + `getStatsHomeData()`; `stats` is `getStatsLabData(lab.id)` when `findModelCatalogLab` hits, else `null`. Missing lab still renders `lab.notFound` `"No models matched this lab."` (`LabNotFound`). OG path `/data/${lab.id}`. Header links `#overview`, `#usage`, `#models`. Lab comparisons titled `` `${name} Model Comparisons` ``.

Model query `"getStatsModelPageData"`: `findModelCatalogEntry(catalog, modelParam, labParam)`; `getStatsModelData(model, lab)` when both lab and model strings are non-empty. Render continues if catalog entry **or** stats exist; otherwise `ModelNotFound`. Imported `statModel` canonicalizes the displayed model (OQ-6.23-11). If that result equals `"glm-5.3-flash"`, former name is `"ox-alpha"` and public name `"GLM-5.3-Flash"`; path fallback uses catalog id `zhipuai/glm-5.3-flash`. `"unknown"` has no public name. Header includes `#momentum`, `#efficiency`, `#peers`.

### Comparison pages

Compare index title `"AI Model Comparison"`; description `"Compare AI models on key metrics including benchmarks, price, context length, and other model features."`. Selector navigates with `window.location.href = comparisonHref(...)` when both models differ. Empty catalog: `"No models found"` / `"The model list could not be loaded."`. Category cards (`buildComparisonCategories`): `"Flagship models"`, `"Most affordable"` (sort by `modelCost`), `"Best for code"` (`toolCall || reasoning`), `"Image generation"` (output modality contains `"image"`). Selector pool is `models.slice(0, 120)`.

Family route: `resolveComparisonFamily` on both params; missing family, missing latest model, or same slug → `comparison() === null`: `<Title>Model comparison not found</Title>`, `robots` `noindex,follow`, copy `"Comparison not found"` / `"Choose two model families to compare."`, link `${BASE_URL}compare`.

Family slugs (`comparisonFamilies` in `packages/stats/app/src/lib/comparison-pages.ts`): `gpt`, `claude`, `gemini`, `deepseek`, `qwen`, `glm`, `kimi`, `minimax`, `grok`, `mistral`, `llama`, `nemotron`, `mimo`, `command`, `sonar`, `longcat`, `step`, `mai` (labs and aliases in that file). Candidates require the family lab, prefix match on family/slug/name, text in+out modalities, and slug not matching `audio|embedding|guard|image|moderation|omni|rerank|safety|speech|transcribe|tts|vision`. Sort: newest `releaseDate`/`lastUpdated`, then `preferredFamilies`, then variant penalty for `highspeed|latest|preview|turbo|ultraspeed`, then shorter slug. Duplicate `-latest`/`-highspeed`/`-ultraspeed` aliases with the same release+family as a non-suffix sibling are dropped.

Canonical family path: `/data/compare/${slugA}/${slugB}` with slugs sorted. Canonical model path: `/data/compare/${lab}/${slug}/...` with model `id`s sorted. `latestFamilyComparisonPath` returns the family path only when both models are that family’s latest candidate and families differ.

Detail page (`model-compare-detail.tsx`): loads `getStatsModelsComparisonData` with `{ provider: lab, model: slug }`. Extra models from `?add=` comma list of `lab/slug` (exactly two `/` parts after split), capped so total ≤ 6. `robots` is `noindex,follow` when more than two models, else `index,follow`. Canonical URL uses family path when `family` prop is set; else family path if both catalog entries are latest family heads; else sorted model path. JSON-LD `@type` `"WebPage"` with `about` `SoftwareApplication` entries. Adding models navigates via `comparisonModelsHref` (`?add=` joined remaining `lab/slug`).

Sitemap `GET`: catalog + imported `runtime.runPromise(getStatsHomeData()).catch(() => undefined)` (OQ-6.23-11). Entries: `/data/compare`, every unordered family pair that resolves, then model pairs from `comparisonSitemapModels(catalog, stats?.leaderboard["All Users"]["2M"])` **except** pairs that have `latestFamilyComparisonPath`. `lastmod` is ISO date (`slice(0, 10)`) of `min(now, max(dates))`. XML `urlset` 0.9; `loc` is `new URL(path, baseUrl)` with `&"<>'` escaped.

### Newsletter and health

Health `GET` (`packages/stats/app/src/routes/api/health.ts`): JSON `{ ok: true, app: "stats" }`.

Newsletter `POST`: requires `content-type` containing `multipart/form-data` or `application/x-www-form-urlencoded`. Reads `email` from `formData()`. Puts `https://api.emailoctopus.com/lists/${listId}/contacts` with `Authorization: Bearer ${Resource.EMAILOCTOPUS_API_KEY.value}` and body `{ email_address: emailAddress.trim() }`. Success: `{ success: true }`. Subscribe modal posts to `${BASE_URL}api/newsletter` as `FormData`; success copy `modal.success` `"You're subscribed."`; HTTP error uses JSON `error` string if present else `modal.error` `"Failed to subscribe"`.

Header/footer: GitHub `target="_blank"` `rel="noreferrer"`; Try OpenCode `https://opencode.ai/`; legal `https://opencode.ai/legal/terms-of-service` and `.../privacy-policy`; contact `mailto:hello@opencode.ai`; Discord `https://opencode.ai/discord`; X `https://x.com/opencode`; YouTube `https://www.youtube.com/@anomalyco`. Footer status copy `footer.status` `"All systems Operational"`; copyright `footer.copyright` `"© 2026 Anomaly Innovations Inc."`. Mobile nav id `stats-mobile-nav`; menu viewport `max-width: 89.999rem`.

## Error handling

| Condition | Result | Source |
|-----------|--------|--------|
| Client missing `#app` | `throw new Error("Root element #app not found")` | `packages/stats/app/src/entry-client.tsx` |
| Newsletter content-type not form | HTTP 400 `{ error: "Email address is required" }` | `POST` (`api/newsletter.ts`) |
| Missing/blank `email` | HTTP 400 `{ error: "Email address is required" }` | `POST` |
| EmailOctopus `!response.ok` | HTTP 502 `{ error: "Failed to subscribe" }` | `POST` |
| Subscribe `fetch` network failure | UI `modal.error` `"Failed to subscribe"` | `SubscribeModal` (`stats-shell.tsx`) |
| Catalog HTTP/parse failure | Empty/`undefined` payloads; catalog may have zero models | `fetchCatalogPayload`, `fetchLabCatalogPayload` |
| Sitemap `getStatsHomeData` throw | `stats` treated as `undefined`; compare URLs still emitted | `sitemap.xml.ts` `.catch(() => undefined)` |
| Unknown lab param | In-page `lab.notFound`; not an HTTP error in this file | `[lab]/index.tsx` `LabNotFound` |
| Unknown model (no catalog, no stats) | In-page `model.noDataTitle` / `model.noMatched` | `[lab]/[model].tsx` `ModelNotFound` |
| Unresolvable family compare | Title `"Model comparison not found"`; `robots` `noindex,follow` | `compare/[firstFamily]/[secondFamily].tsx` |
| Compare index with `< 2` catalog models | `"No models found"` / `"The model list could not be loaded."` | `compare/index.tsx` |

GitHub stars errors are swallowed to `fallbackStars` (`getGitHubStars` `.catch`). Theme `localStorage` read in the preload script is inside `try/catch` and ignored on throw.
