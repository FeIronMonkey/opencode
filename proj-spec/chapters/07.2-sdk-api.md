# 7.2 SDK API

> **Spec chapter:** Public TypeScript export surface for `@opencode-ai/client`, `@opencode-ai/sdk`, and `@opencode-ai/sdk-next`.
> **Parent:** [7 Interface](../07-interface.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/client/` (`@opencode-ai/client`), `packages/sdk/js/` (`@opencode-ai/sdk`), `packages/sdk-next/` (`@opencode-ai/sdk-next`)

Retrospective description of shipped consumer imports, factories, and named methods (C8). Package construction, codegen pipelines, interceptors, and in-process host wiring are specified in [6.7 Client](06.7-client.md), [6.8 SDK](06.8-sdk.md), and [6.9 SDK-next](06.9-sdk-next.md). This chapter is the interface companion for those three packages (T1-chapter-map.md §4: 7.2 ← 6.7 / 6.8 / 6.9).

This leaf covers the `client`, `sdk`, and `sdk-next` members of the multi-leaf set `schema`, `core`, `protocol`, `server`, `client`, `sdk`, `sdk-next`, `plugin`, `ui`.

Generated trees in this slice (`src/generated`, `src/generated-effect` under `packages/client`; `packages/sdk/js/src/v2/gen/`; published `packages/sdk/js/dist/`) are **generated**. They are not the behavioral source of truth (C5). Regeneration commands for this slice are `bun run generate` (`packages/client`) and `./packages/sdk/js/script/build.ts`. Canonical home for workspace generate command names is 10.2. This chapter does **not** claim that these packages invoke `generate:tailwind`, `generate:v2-oc2`, or `db:generate` / `drizzle-kit generate`.

### Package export maps

Hand-authored `exports` maps in the three `package.json` files are the consumer subpath contract. `@opencode-ai/client` runtime dependencies are `@opencode-ai/schema` and `@opencode-ai/protocol`. `@opencode-ai/sdk-next` runtime dependencies are `@opencode-ai/client`, `@opencode-ai/core`, `@opencode-ai/server`, and `effect`. `@opencode-ai/sdk` runtime dependency is `cross-spawn`.

## Behavior

### Promise client

`packages/client/src/index.ts` re-exports generated Promise modules and `export type { EventsSubscribeOutput as OpenCodeEvent } from "./generated/types"`. `packages/client/README.md`: zero-Effect Promise client using `fetch`.

`packages/client/test/promise.test.ts` `"exposes every standard HTTP API group"`: `OpenCode.make({ baseUrl: "http://localhost:3000" })` has group keys:

`health`, `location`, `agents`, `sessions`, `messages`, `models`, `providers`, `integrations`, `credentials`, `permissions`, `files`, `commands`, `skills`, `events`, `ptys`, `questions`, `references`, `projectCopies`.

Those names match `groupNames` values in `packages/client/src/contract.ts` (canonical projection table: [6.7 Client](06.7-client.md)). `omitEndpoints` is `Set(["fs.read", "pty.connect", "pty.connectToken"])`.

| Method | Behavior (from tests / contract) |
|--------|----------------------------------|
| `messages` keys | `["list"]` (`endpointNames["session.messages"]` = `"list"`) |
| `integrations` keys | `list`, `get`, `connectKey`, `connectOauth`, `attemptStatus`, `attemptComplete`, `attemptCancel` |
| `files` keys | `["list", "find"]` |
| `ptys` keys | `["list", "create", "get", "update", "remove"]` |
| `sessions.get({ sessionID })` | Wire projection; numeric `time.created` (`"sessions.get returns the wire projection"`) |
| `events.subscribe()` | `AsyncIterable` of SSE JSON events (`"events.subscribe exposes the Promise event stream wire projection"`) |
| Session methods | `list`, `active`, `create`, `switchAgent`, `switchModel`, `prompt`, `compact`, `wait`, `context`, `history`, `events`, `interrupt`, `message` (`"session methods use the public HTTP contract"`) |
| `sessions.prompt` body | JSON `{ prompt: { text: "Hello" }, resume: false }` when those arguments are passed (same test) |

HTTP path/method pairs for those session calls: [6.7 Client](06.7-client.md). Public HTTP/`HttpApi` as a server contract is out of this slice.

### Effect client

`packages/client/src/effect.ts` re-exports generated Effect `OpenCode` plus Schema namespaces `Agent`, `Command`, `Credential`, `FileSystem`, `Integration`, `Location`, `Model`, `Permission`, `PermissionSaved`, `Project`, `ProjectCopy`, `Provider`, `Pty`, `Question`, `Reference`, `Session`, `SessionInput`, `SessionMessage`, `Skill`, `Prompt`, values `AbsolutePath` and `RelativePath`, and `export type { OpenCodeEvent } from "@opencode-ai/protocol/groups/event"`. Comment on that file: `/effect` must never import Core or Server.

`packages/client/README.md`: Effect network client using an environment-provided `HttpClient`; callers construct decoded inputs such as `Location.Ref`, `AbsolutePath`, `Prompt`.

`packages/client/test/effect.test.ts` uses the same session method names as the Promise session test, with decoded identifiers (`Session.ID.make`, `Prompt.make`, …). `events.subscribe()` is an Effect `Stream`. `{ data: … }` envelopes are unwrapped on several session results (`created.id`, `admitted`, `active` map, `context` as `[]`).

`packages/client/test/import-boundaries.test.ts` `"isolates each public entrypoint"`: browser bundle of `@opencode-ai/client` includes none of `effect`, `packages/schema`, `packages/protocol`, `packages/core`, or `packages/server`; `@opencode-ai/client/effect` includes `effect`, schema, and protocol and includes none of core or server.

### Legacy SDK

`packages/sdk/js/src/index.ts` and `src/v2/index.ts` re-export client and server modules and define `createOpencode`. Public names: `createOpencodeClient`, `createOpencodeServer`, `createOpencodeTui`, `OpencodeClient`, type alias `OpencodeClientConfig` (generated `Config`), plus re-exported generated types.

v2 additionally exports `data` (`packages/sdk/js/src/v2/data.ts`). `data.message.user(input)` returns `{ info, parts }` with `info.id` `"asdasd"`, `info.role` `"user"`, `info.time.created` `Date.now()`, and each part `id` `"asdasd"`.

v2 `createOpencodeClient` also aliases `FileSystemEntry as LocationFileSystemEntry` (`packages/sdk/js/src/v2/client.ts`).

v1 `createOpencodeClient` loads `packages/sdk/js/src/gen/` (`packages/sdk/js/src/client.ts`). `./packages/sdk/js/script/build.ts` writes `./src/v2/gen` then runs `bun prettier --write src/gen`; it does not emit v1 `src/gen`. v2 generated trees under `src/v2/gen/` are not the behavioral source of truth (C5). `packages/sdk/js/test/session-history.test.ts` `"uses numeric Session history positions"`: `V2SessionHistoryData` `query.after` and `query.limit` are `number` (post-codegen patch of `src/v2/gen` in `script/build.ts`).

Server/TUI spawn the `opencode` binary (`serve` plus `--hostname=` / `--port=`; TUI optional `--project=` / `--model=` / `--session=` / `--agent=`). Child env includes `OPENCODE_CONFIG_CONTENT` as `JSON.stringify(options.config ?? {})`. Startup URL is parsed from a stdout line starting with `opencode server listening` via `/on\s+(https?:\/\/[^\s]+)/`. Details: [6.8 SDK](06.8-sdk.md).

## Error handling

| Surface | Condition | Observable | Source |
|---------|-----------|------------|--------|
| Promise `events.subscribe` | SSE `data:` is not JSON | Reject `{ name: "ClientError", reason: "MalformedResponse" }` | `packages/client/test/promise.test.ts` `"events.subscribe terminates on malformed Promise SSE data"` |
| Promise `sessions.create` | JSON `_tag` `"UnauthorizedError"`, HTTP 401 | `isUnauthorizedError(error)` is `true` | `"middleware errors remain declared client errors"` |
| Promise `sessions.history` | JSON `_tag` `"SessionNotFoundError"`, HTTP 404 | `isSessionNotFoundError(error)` is `true` | `"sessions.history decodes SessionNotFoundError"` |
| Effect `events.subscribe` | Undecodable SSE payload | Failed Effect `_tag` `"ClientError"` | `packages/client/test/effect.test.ts` `"events.subscribe terminates on Effect protocol decode failures"` |
| Effect `sessions.history` | Same `SessionNotFoundError` JSON, HTTP 404 | Failed Effect `_tag` `"SessionNotFoundError"` | `"sessions.history retains the typed SessionNotFoundError"` |
| sdk-next `sessions.events` / `interrupt` / `message` | Unknown `sessionID` | `_tag` `"SessionNotFoundError"` | `packages/sdk-next/test/embedded.test.ts` `"embedded client uses the real router and handlers"` |
| sdk-next `sessions.message` | Known session, foreign `messageID` | `_tag` `"MessageNotFoundError"` | same |
| Legacy `createOpencodeServer` | Timeout | `Error` message `` Timeout waiting for server to start after ${options.timeout}ms `` | `packages/sdk/js/src/server.ts` / `src/v2/server.ts` |
| Legacy `createOpencodeServer` | Listen line unmatched | `Error` `` Failed to parse server url from output: ${line} `` | same |
| Legacy `createOpencodeServer` | Child exits before listen | `Error` `` Server exited with code ${code} `` plus optional `` \nServer output: ${output} `` | same |
| Legacy HTTP `{ throwOnError: true }` | Non-`Error` body | `wrapClientError` (`packages/sdk/js/src/error-interceptor.ts`); wrapper rules: [6.8 SDK](06.8-sdk.md) | |
| v2 HTML response | `content-type` exactly `text/html` | `Error("Request is not supported by this version of OpenCode Server (Server responded with text/html)")` | `packages/sdk/js/src/v2/client.ts` |

`isUnauthorizedError` and `isSessionNotFoundError` are imported from `@opencode-ai/client` in Promise tests (`packages/client/src/index.ts`). sdk-next re-exports `ClientError` from `@opencode-ai/client/effect`.
