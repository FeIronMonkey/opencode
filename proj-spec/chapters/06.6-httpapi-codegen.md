# 6.6 HttpApi Codegen

> **Spec chapter:** Build-time generator that reflects an Effect `HttpApi` contract into Promise and Effect HTTP client source.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/httpapi-codegen/src/index.ts`

`@opencode-ai/httpapi-codegen` is a private build-time package. It compiles one authoritative `HttpApi` definition into a shared contract, then emits independent Promise or Effect client implementations. Generated output is written to a consumer directory (see [6.7 Client](06.7-client.md)); this package is the generator, not a generated tree. Tests under `packages/httpapi-codegen/test/` are the executable specification for generator behavior.

## Construction / configuration

| Parameter | Default | Notes |
|-----------|---------|-------|
| Package name | `@opencode-ai/httpapi-codegen` | `private: true`; exports `"."` → `./src/index.ts` (`packages/httpapi-codegen/package.json`) |
| Runtime dependencies | `effect`, `prettier@3.6.2` | Used for schema reflection, Effect `FileSystem`, and Prettier formatting before write (`packages/httpapi-codegen/package.json`) |
| `compile` `groupNames` | omitted | Maps source group identifiers to consumer-facing group names (`compile`, `packages/httpapi-codegen/test/generate.test.ts` "separates hosted and consumer group names") |
| `compile` `endpointNames` | omitted | Maps endpoint names to explicit public operation names (`compile`, `packages/httpapi-codegen/test/generate.test.ts` "supports explicit public endpoint names") |
| `compile` `omitEndpoints` | omitted | `ReadonlySet<string>` of endpoint names excluded from the contract (`compile`, `packages/httpapi-codegen/test/generate.test.ts` "omits custom transport endpoints") |
| `emitPromise` `outputTypes` | omitted | Per-operation wire-type overrides keyed as `"<group>.<operationName>"` with `{ name, import }` (`emitPromise`, `packages/httpapi-codegen/test/generate.test.ts` "allows Promise outputs to use an authoritative imported wire type") |
| `emitEffectImported` `module` | required | Import path for authoritative API or schema symbols (`emitEffectImported`, `packages/httpapi-codegen/test/generate.test.ts` "emits an Effect client against an imported authoritative API") |
| `emitEffectImported` shape | one of three | `{ module, api }`, `{ module, group }`, or `{ module, endpoints }` (`emitEffectImported`, `packages/httpapi-codegen/test/generate.test.ts`) |
| `generate` `directory` | required | Output directory for Effect client files (`generate`, `packages/httpapi-codegen/src/index.ts`) |
| Manifest filename | `.httpapi-codegen.json` | Tracks generated file paths for stale cleanup (`manifestName`, `write`) |

The package remains independent of OpenCode Core and uses synthetic `HttpApi` fixtures in its tests (`packages/httpapi-codegen/README.md` Boundary).

## Behavior

### Pipeline

| Phase | Entry | Output |
|-------|-------|--------|
| Compile | `compile(api, options?)` | `Contract` with grouped `Endpoint` metadata and derived `Operation` summaries |
| Emit Effect (portable) | `emitEffect(contract)` | `Output` with one module per `HttpApiGroup`, plus `client-error.ts`, `client.ts`, `index.ts` |
| Emit Effect (imported) | `emitEffectImported(contract, options)` | `Output` with adapters in `client.ts` referencing authoritative imports; no per-group modules |
| Emit Promise | `emitPromise(contract, options?)` | `Output` with `types.ts`, `client-error.ts`, `client.ts`, `index.ts` |
| Write | `write(output, directory)` | Creates directory, removes stale manifest-owned files, formats with Prettier, writes files and manifest |
| Generate (legacy) | `generate(api, { directory })` | `compile` → `emitEffect` → `write` as one Effect requiring `FileSystem` (`generate`) |

Promise and Effect emitters share the same `operations` list from `compile` (`packages/httpapi-codegen/test/generate.test.ts` "compiles one contract for Promise and Effect emitters").

### Contract reflection (`compile`)

| Rule | Behavior |
|------|----------|
| Endpoint inclusion | Every reflected endpoint is included unless listed in `omitEndpoints` (`compile`, `HttpApi.reflect`) |
| Public endpoint name | `compile` sets `operation.name` to `options?.endpointNames?.[endpoint.name] ?? clientEndpointName(endpoint.name)`; `clientEndpointName` returns `name.slice(name.lastIndexOf(".") + 1)` (`compile`, `clientEndpointName`, `packages/httpapi-codegen/test/generate.test.ts` "uses the unqualified endpoint name for the public client") |
| Input flattening | Path, query, header, and payload struct fields merge into one input object with `source` tags (`compile`, `packages/httpapi-codegen/test/generate.test.ts` "flattens transport input channels into one domain input") |
| Input mode | `"none"` when zero fields; `"optional"` when every field is optional; `"required"` when any field is required (`compile` `operation.inputMode`, `packages/httpapi-codegen/test/generate.test.ts`) |
| `{ data: A }` envelope | Exact single-field `data` success structs unwrap to the inner value in emitted clients (`isDataEnvelope`, `packages/httpapi-codegen/test/generate.test.ts` "unwraps an exact data success envelope") |
| No-content success | Maps to operation success `"void"` (`HttpApiSchema.isNoContent`, `packages/httpapi-codegen/test/generate.test.ts` "maps no-content success to void") |
| Other single success | Maps to operation success `"value"` (`packages/httpapi-codegen/test/generate.test.ts` "returns a non-envelope success unchanged") |
| SSE success | Maps to operation success `"stream"`; emitted Effect clients return `Stream`, not `Effect<Stream>` (`packages/httpapi-codegen/README.md` Settled rules; `packages/httpapi-codegen/test/generate.test.ts` "models an SSE success as a direct stream") |
| Declared errors | Tagged error identifiers from endpoint error schemas plus `"ClientError"` in every operation's `errors` list (`compile` `operation.errors`, `packages/httpapi-codegen/test/generate.test.ts` "maps transport and decode failures to one stable client error") |
| Group module paths | One self-contained TypeScript module per group; unsafe identifiers become `group-<index>` with case-insensitive uniqueness against reserved names `client`, `client-error`, `index` (`uniqueModule`, `packages/httpapi-codegen/test/generate.test.ts` "uses safe unique module paths without changing public group identifiers") |
| Transport identifiers | Source group and endpoint identifiers are preserved internally (`packages/httpapi-codegen/README.md` Settled rules). Groups remap only via `groupNames` (`options?.groupNames?.[group.identifier] ?? group.identifier`). Public operation names remap implicitly without `endpointNames`: `compile` sets `operation.name` to `options?.endpointNames?.[endpoint.name] ?? clientEndpointName(endpoint.name)`, and `clientEndpointName` takes the segment after the last `.`. README: endpoint operation IDs are projected to their final dot-delimited segment (`compile`, `clientEndpointName`) |

### Effect emission (`emitEffect`)

Portable Effect output regenerates standard `HttpApi` transport codecs from decoded schemas, embeds runtime schemas (including tagged errors), preserves transformations, and wraps `HttpApiClient.make` with group adapters (`packages/httpapi-codegen/README.md` Settled rules; `renderEffectFiles`, `renderGroup`). Per-group modules and portable `client.ts` begin with `// Generated by @opencode-ai/httpapi-codegen. Do not edit.` (`renderGroup`, `renderClient`); portable Effect `client-error.ts` and `index.ts` from `renderEffectFiles` omit that banner (`renderEffectFiles`, `packages/httpapi-codegen/src/index.ts`).

When any endpoint schema is not `effectPortable`, `emitEffect` fails and callers must use `emitEffectImported` with authoritative imports (`emitEffect`, `packages/httpapi-codegen/test/generate.test.ts` "rejects custom transformations hidden beneath standard HttpApi codecs").

### Effect emission with imports (`emitEffectImported`)

| Option shape | Generated API construction |
|--------------|----------------------------|
| `{ module, api }` | Imports `api` symbol; `HttpApiClient.ForApi<typeof api>` |
| `{ module, group }` | Imports one `HttpApiGroup`; `HttpApi.make("generated").add(<group>)` |
| `{ module, endpoints }` | Imports endpoint constants; rebuilds `HttpApi` from mapped `"<group>.<endpoint>"` keys |

Adapters stay in the root `client.ts`; schema dependencies may duplicate across portable group modules (`packages/httpapi-codegen/README.md` Boundary).

### Promise emission (`emitPromise`)

| Aspect | Behavior |
|--------|----------|
| Runtime | Zero-Effect client using `fetch`; structural wire-oriented types without runtime schema validation (`packages/httpapi-codegen/README.md` Settled rules) |
| Success encoding | JSON value bodies, SSE `data` mode, and no-content (`HttpApiSchema.isNoContent`). `renderPromiseClient` sets `empty: ${endpoint.operation.success === "void"}`; skip-body (cancel, return `undefined`) only when `endpoint.operation.success === "void"` (no-content). JSON value successes call `request()`, which parses the body via `json()`. SSE successes (`success === "stream"`) call `sse()`. Rejects text, binary, non-JSON value bodies, and SSE with non-never error streams (`renderPromiseClient`, `assertPromiseEndpoint`, `packages/httpapi-codegen/test/generate.test.ts` "maps an emitted no-content response to undefined"; "rejects Promise transports that are not implemented") |
| Error handling | Declared tagged errors reject with parsed JSON; transport, unexpected status, and decode failures reject with `ClientError` (`renderPromiseClient`, `packages/httpapi-codegen/test/generate.test.ts`) |
| SSE streams | Lazy `AsyncIterable`; no automatic reconnect (`packages/httpapi-codegen/README.md` Settled rules; `packages/httpapi-codegen/test/generate.test.ts` "iterates an emitted SSE stream lazily without reconnecting") |
| Wire types | Brands erased; non-recursive schema references inlined; `Schema.Json` becomes standalone `JsonValue` (`structuralType`, `packages/httpapi-codegen/test/generate.test.ts`) |
| Path templates | `:param` segments require matching params fields; `*` wildcards rejected (`promisePath`, `packages/httpapi-codegen/test/generate.test.ts`) |
| Index export | `export * as OpenCode from "./client"` (`emitPromise` `index.ts`) |

### Write and manifest (`write`)

| Rule | Behavior |
|------|----------|
| Output paths | Flat filenames only; no absolute paths, `.`, `..`, directory separators, or `.httpapi-codegen.json` as a generated file (`isSafeOutputPath`, `write`) |
| Duplicate paths | Case-insensitive uniqueness enforced before any write (`write`) |
| Symlink targets | Existing symbolic links at output paths are rejected (`write`, `packages/httpapi-codegen/test/write.test.ts` "rejects existing symbolic-link output targets") |
| Stale cleanup | Reads prior manifest; removes files listed there but absent from the new output set (`write`, `packages/httpapi-codegen/test/write.test.ts` "removes only stale files owned by the previous manifest") |
| Formatting | Each file content is formatted with Prettier (`parser: "typescript"`, `semi: false`, `printWidth: 120`) before write (`write`) |
| Manifest write | Sorted JSON array of output paths, trailing newline (`write`) |

Workspace-level regeneration commands that invoke this generator (consistency token **`generate`**) are documented in [10.2 Generate](10.2-generate.md).

## Error handling

Failures surface as `GenerationError` (`reason: string`; `message` equals `reason`) (`GenerationError`, `packages/httpapi-codegen/src/index.ts`). `generate` and `write` may also fail with Effect `PlatformError` from `FileSystem` (`generate`, `write`).

| Condition | `GenerationError.reason` pattern (representative) | Source |
|-----------|---------------------------------------------------|--------|
| Required client middleware | `Client middleware requires adapter: <key>` | `compile` |
| Multiple success schemas | `Multiple success schemas: <group>.<endpoint>` | `compile` |
| Multiple payload schemas | `Multiple payload schemas: <group>.<endpoint>` | `compile` |
| Input name collision | `Input field collision: <name>` | `compile` |
| Input not a struct | `Input schema must be a struct: <operation>.<source>` | `inputFields` |
| Unportable / non-metadata schema | `Unportable schema: <path>` | `normalizeTransport`, `assertPortable`, `metadataPortable` |
| Non-portable Effect emit | `Effect schema requires authoritative import: <group>.<endpoint>` | `emitEffect` |
| Consumer group collision | `Client group name collision: <name>` | `compile` |
| Endpoint name collision | `Client endpoint name collision: <group>.<operationName>` | `compile` |
| Flat client namespace collision | `Client name collision: <name>` | `compile` |
| Invalid endpoint path | `Invalid endpoint path: <operation>` | `normalizeTransport` |
| Missing imported endpoint | `Missing imported endpoint: <group>.<endpoint>` | `renderImportedProjection` |
| Unsupported Promise encoding / stream / path | `Unsupported Promise …` / `Unsupported Promise path wildcard: …` | `assertPromiseEndpoint`, `promisePath` |
| Non-implemented Promise types | `Referenced Promise types are not implemented` / `Recursive Promise types are not implemented: …` | `structuralType` |
| Unsafe or duplicate output path | `Unsafe output path: …` / `Duplicate output path: …` | `write`, `isSafeOutputPath` |
| Invalid manifest | `Invalid generated file manifest: …` | `write` |
| Prettier failure | `Failed to format <path>: …` | `write` |

Compiler failures inside `generate` are caught and re-thrown as `GenerationError` (`generate`, `packages/httpapi-codegen/test/generate.test.ts` "reports compiler failures in the generate Effect").
