# 7.3 CLI

> **Spec chapter:** Shipped user-facing CLI binaries, global flags, and command/flag contracts for `opencode` and `lildax`.
> **Parent:** [7 Interface](../07-interface.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/opencode/` (`opencode` package, `bin.opencode` → `./bin/opencode`), `packages/cli/` (`@opencode-ai/cli`, `bin.lildax` → `./bin/lildax.cjs`), `packages/script/` (`@opencode-ai/script`; no `bin` field)

This slice is the **interface** contract for the two shipped CLI binaries `opencode` and `lildax` (yargs/Effect argv). Native wrappers, `OPENCODE_BIN_PATH`, and uninstall/upgrade **install flags** are canonical in [10.1 Install](10.1-install.md) (this chapter **links only**). Package internals, TUI runtime, and agent loop behavior live in [6.1 Agent CLI](06.1-agent-cli.md) and [6.15 CLI](06.15-cli.md). This pass is retrospective of shipped code.

`@opencode-ai/script` is a workspace helper imported by CLI build scripts (`packages/opencode/script/build.ts`, `packages/cli/script/build.ts`). It has no `bin` field (`packages/script/package.json`) and is not a user-facing CLI.

## Behavior

### Binary wrappers

Canonical home: [10.1 Install](10.1-install.md) `### opencode binary wrapper` and `### lildax binary wrapper`. This heading does not restate spawn, signal, `OPENCODE_BIN_PATH`, or missing-binary stderr.

### `opencode` global surface

`packages/opencode/src/index.ts` registers yargs commands and global options. `-h`/`--help` uses `cli.parse` with `show()`: if help text does not start with `opencode `, stderr gets `UI.logo()` plus two `EOL` then the text; otherwise the raw help string. After parse, `process.exit()` runs in `finally`.

yargs also registers `.completion("completion", "generate shell completion script")`. Help-snapshot comments treat `completion` as a yargs built-in, not a product command (`packages/opencode/test/cli/help/help-snapshots.test.ts`).

### `opencode` default command (TUI)

Default command is `$0 [project]` describe `"start opencode tui"` (`TuiThreadCommand`, `packages/opencode/src/cli/cmd/tui.ts`). It includes network options via `withNetworkOptions`.

| `--model` / `-m` | string | | `"model to use in the format of provider/model"` |
| `--continue` / `-c` | boolean | | `"continue the last session"` |
| `--session` / `-s` | string | | `"session id to continue"` |
| `--fork` | boolean | | `"fork the session when continuing (use with --continue or --session)"` |
| `--prompt` | string | | `"prompt to use"` |
| `--agent` | string | | `"agent to use"` |
| `--auto` | boolean | `false` | `"auto-approve permissions that are not explicitly denied (dangerous!)"` |
| `--yolo` | boolean | `false` | hidden |
| `--dangerously-skip-permissions` | boolean | `false` | hidden |
| `--mini` | boolean | `false` | `"start the minimal interactive interface"` |
| `--replay` | boolean | | hidden |
| `--no-replay` | boolean | | `"disable mini session history replay on resume and after resize"` |
| `--replay-limit` | number | | `"cap visible mini replay to the newest N messages"` |

If `--replay` is true: stderr `"--replay is not supported; replay is enabled by default"`, `process.exitCode = 1`. With `--mini`, `--port`/`--hostname`/`--mdns`/`--no-mdns`/`--mdns-domain`/`--cors` (exact or `name=`) fail with `` `${network} cannot be used with --mini` ``; `--fork` is passed through to `runMini` and this handler does not emit `"--fork requires --continue or --session"`. Without `--mini`, `--no-replay`, `--replay-limit`, or `--demo` fail with `` `${unsupported} requires --mini` ``; `--fork` without `--continue` or `--session` fails with `"--fork requires --continue or --session"`. Failed `chdir` writes `"Failed to change directory to " + next`.

### Network options

`withNetworkOptions` is used by `acp`, `serve`, `web`, and default TUI (`packages/opencode/src/cli/network.ts`).

`resolveNetworkOptionsNoConfig`: CLI wins when the corresponding argv is present (`--port`, `--hostname`, `--mdns` including `--no-mdns` / `=true`/`=false`, `--mdns-domain`). Otherwise values come from `config.server` then flag defaults. If mDNS is on and config has no `server.hostname`, hostname is `"0.0.0.0"`. CORS is config list concatenated with argv list.

`serve` describe `"starts a headless opencode server"`. If `Flag.OPENCODE_SERVER_PASSWORD` is unset it prints `Warning: OPENCODE_SERVER_PASSWORD is not set; server is unsecured.` then `opencode server listening on http://${server.hostname}:${server.port}` (`packages/opencode/src/cli/cmd/serve.ts`).

`web` describe `"start opencode server and open web interface"`. Unset password uses `!  OPENCODE_SERVER_PASSWORD is not set; server is unsecured.` When hostname is `0.0.0.0`, it prints `Local access:` `http://localhost:${port}`, optional `Network access:` `http://${ip}:${port}` (IPv4, non-internal, not `172.`), optional `mDNS:` `${mdnsDomain}:${port}`, and opens localhost (`packages/opencode/src/cli/cmd/web.ts`).

`acp` describe `"start ACP (Agent Client Protocol) server"` plus `--cwd` default `process.cwd()` (`packages/opencode/src/cli/cmd/acp.ts`). Sets `OPENCODE_CLIENT=acp`.

### `lildax` command tree

Root `Commands` (`packages/cli/src/commands/commands.ts`) plus handlers (`packages/cli/src/index.ts`):

| Command | Description | Params |
|---------|-------------|--------|
| (default `$`) | starts TUI against daemon transport (`packages/cli/src/commands/handlers/default.ts`) | |
| `api` | `"Make a request to the running server"` | argument `operation \| method path` variadic min 1 max 2; `--data`/`-d` optional; `--header`/`-H` at most 100; `--param` optional key-value |
| `debug agents` | `"List all agents"` | JSON list of `client.v2.agent.list` (`packages/cli/src/commands/handlers/debug/agents.ts`) |
| `migrate` | `"Migrate v1 data to v2"` | logs `"No migrations to run."` (`packages/cli/src/commands/handlers/migrate.ts`) |
| `service start` | `"Start the background server"` | writes `Daemon.start()` URL plus EOL |
| `service restart` | `"Restart the background server"` | stop then write `start()` URL |
| `service status` | `"Show background server status"` | `running ${url}` or `stopped` |
| `service stop` | `"Stop the background server"` | |
| `service password [value]` | `"Get or set the server password"` | optional `value`; if provided, daemon `stop()` then write password (`packages/cli/src/commands/handlers/service/password.ts`) |
| `serve` | `"Start the v2 API server"` | `--hostname`, `--port`, `--register`; logs `server listening on ${HttpServer.formatAddress(address)}` |

`api` request: two tokens that look like HTTP method + path starting `/` use `rawRequest`; else a single OpenAPI operation id loaded from `{transport.url}/openapi.json`. Path `{params}` are `encodeURIComponent`; leftover `--param` pairs become query string (`packages/cli/src/commands/handlers/api.ts`). Default `content-type` for `--data` is `application/json` when not already set.

`service start` spawns `process.execPath` with optional entrypoint plus `serve --register` (`packages/cli/src/services/daemon.ts`).

## Error handling

`opencode` `.fail` (`packages/opencode/src/index.ts`): for messages starting `Unknown argument`, `Not enough non-option arguments`, or `Invalid values:`, `if (err) throw err` runs first — `cli.showHelp(show)` runs only when `err` is unset; then execution falls through to `process.exit(1)`. Any other fail with `err` set throws; without `err`, `process.exit(1)`. Top-level catch: `FormatError`; if defined, `UI.error(formatted)`; if `undefined`, `UI.error("Unexpected error" + EOL)` plus `errorMessage(e)`; `process.exitCode = 1`.

`CliError` from `fail(message, exitCode = 1)` is tagged `"CliError"`; `FormatError` prints `message` and may set `process.exitCode` (`packages/opencode/src/cli/effect-cmd.ts`, `packages/opencode/src/cli/error.ts`).

Quoted `FormatError` strings:

| Tag / name | Message shape |
|------------|----------------|
| `MCPFailed` | `MCP server "${name}" failed. Note, opencode does not support MCP authentication yet.` |
| `ProviderModelNotFoundError` | `Model not found: ${providerID}/${modelID}` plus optional `Did you mean: ` + suggestions, then `Try: \`opencode models\` to list available models` and `Or check your config (opencode.json) provider/model names` |
| `ProviderInitError` | `Failed to initialize provider "${providerID}". Check credentials and configuration.` |
| `ConfigJsonError` | `Config file at ${path} is not valid JSON(C)` plus optional `: ${message}` |
| `ConfigDirectoryTypoError` | `Directory "${dir}" in ${path} is not valid. Rename the directory to "${suggestion}" or remove it. This is a common typo.` |
| `ConfigInvalidError` | `Configuration is invalid` plus ` at ${path}` when `path` is set and `path !== "config"` (`packages/opencode/src/cli/error.ts`), plus optional `: ${message}`; issues as `↳ ` + message + space + path joined by `.` |
| `ConfigRemoteAuthError` | `Failed to load remote config` optional ` from ${remote}` + `: the server returned a login page instead of JSON.` plus auth-expired line; if `url`, `Run \`opencode auth login ${url}\` to re-authenticate.` |
| `UICancelledError` | empty string |

`models` missing provider: `Provider not found: ${args.provider}` (`fail`, `packages/opencode/src/cli/cmd/models.ts`). `session delete` missing: `Session not found: ${args.sessionID}`. `pr`: `Could not load instance context`; `Could not find git repository. Please run this command from a git repository.`; `Failed to checkout PR #${prNumber}. Make sure you have gh CLI installed and authenticated.`; defect `opencode exited with code ${code}` (`packages/opencode/src/cli/cmd/pr.ts`).

`mcp add` throws: `A server name is required for non-interactive MCP configuration`; `Provide either --url <url> or a command after --`; `` Invalid URL: ${args.url} ``; `--env is only valid for local MCP servers`; `--header is only valid for remote MCP servers`; `` Invalid ${kind}: ${entry}. Expected KEY=VALUE `` (`packages/opencode/src/cli/cmd/mcp.ts`).

`lildax api`: `Invalid header, expected name:value: ${header}`; `Expected an operation name or an HTTP method and path`; `Failed to load OpenAPI document: HTTP ${status}`; `Operation not found: ${operationID}`; `Missing path parameter: ${name}`. Daemon: `Registered server is not healthy`; `Registered server version does not match the client`; `Server process ${pid} is still running`; `Failed to resolve CLI entrypoint`; `Failed to start server`.
