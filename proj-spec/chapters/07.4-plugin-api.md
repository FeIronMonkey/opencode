## Behavior

### V1 plugin (`@opencode-ai/plugin`)

`Plugin` is `(input: PluginInput, options?: PluginOptions) => Promise<Hooks>` (`packages/plugin/src/index.ts`). `PluginOptions` is `Record<string, unknown>`. `export * from "./tool.js"` re-exports the tool helper from this entry.

`PluginInput` (`packages/plugin/src/index.ts`): `client` (`ReturnType<typeof createOpencodeClient>` from `@opencode-ai/sdk`), `project`, `directory`, `worktree`, `experimental_workspace.register(type, adapter)`, `serverUrl`, `$` (`BunShell` from `packages/plugin/src/shell.ts`).

`Config` is `Omit<SDKConfig, "plugin">` plus optional `plugin?: Array<string | [string, PluginOptions]>`.

`PluginModule`: optional `id?: string`; `server: Plugin`; `tui?: never`.

`WorkspaceAdapter`: `name`, `description`, `configure`, `create`, `remove`, `target`. `WorkspaceTarget` is `{ type: "local"; directory }` or `{ type: "remote"; url: string | URL; headers?: HeadersInit }`.

`Hooks` optional members (`packages/plugin/src/index.ts` `Hooks`):

| Key | Role |
|-----|------|
| `dispose` | `() => Promise<void>` |
| `event` | `{ event: Event }` |
| `config` | `Config` |
| `tool` | `{ [key: string]: ToolDefinition }` |
| `auth` | `AuthHook` |
| `provider` | `ProviderHook` (`id`; optional `models`) |
| `"chat.message"` | session/agent/model input; `message` / `parts` output |
| `"chat.params"` | mutates `temperature`, `topP`, `topK`, `maxOutputTokens`, `options` |
| `"chat.headers"` | mutates `headers` |
| `"permission.ask"` | `Permission` in; `status` `"ask"` \| `"deny"` \| `"allow"` out |
| `"command.execute.before"` | command/session/arguments; `parts` out |
| `"tool.execute.before"` | tool/session/`callID`; `args` out |
| `"shell.env"` | `cwd` / optional session/`callID`; `env` out |
| `"tool.execute.after"` | `title`, `output`, `metadata` out |
| `"experimental.chat.messages.transform"` | `messages` array of `{ info, parts }` |
| `"experimental.chat.system.transform"` | `system: string[]` |
| `"experimental.provider.small_model"` | optional `model` out |
| `"experimental.session.compacting"` | `context: string[]`; optional `prompt` replaces default |
| `"experimental.compaction.autocontinue"` | `enabled` (comment: defaults to `true`; set `false` to skip synthetic continue) |
| `"experimental.text.complete"` | `text` out |
| `"tool.definition"` | `description` and `parameters` out |

`AuthHook`: `provider`; optional `loader`; `methods` array of `{ type: "oauth" | "api"; label; … }`. OAuth `authorize` returns `AuthOAuthResult` (`url`, `instructions`, `method` `"auto"` or `"code"`, plus `callback`). Prompt `when` is `Rule` `{ key, op: "eq" \| "neq", value }`. Deprecated prompt field `condition`; deprecated alias type `AuthOuathResult` = `AuthOAuthResult`.

`BunShell` / `BunShellPromise` / `BunShellOutput` / `BunShellError` are type-only (`packages/plugin/src/shell.ts`): tagged-template shell, `braces`, `escape`, `env`, `cwd`, `nothrow`, `throws`; promise `quiet`, `lines`, `text`, `json`, `arrayBuffer`, `blob`. This package does not implement the shell.

### Tool helper (`@opencode-ai/plugin/tool`)

`tool({ description, args, execute })` returns `input` unchanged (`packages/plugin/src/tool.ts`). `tool.schema` is `z` (zod). `ToolDefinition` is `ReturnType<typeof tool>`.

`ToolContext`: `sessionID`, `messageID`, `agent`, `directory`, `worktree`, `abort`, `metadata`, `ask`. `ToolResult` is `string` or `{ title?; output; metadata?; attachments? }` with `ToolAttachment` `{ type: "file"; mime; url; filename? }`.

### TUI plugin (`@opencode-ai/plugin/tui`)

`TuiPlugin` is `(api: TuiPluginApi, options: PluginOptions | undefined, meta: TuiPluginMeta) => Promise<void>` (`packages/plugin/src/tui.ts`). `TuiPluginModule`: optional `id`; `tui: TuiPlugin`; `server?: never`.

`createBindingLookup(config, options?)` calls `@opentui/keymap/extras` `createBindingLookup` with `config ?? {}`.

Re-exports from `@opentui/core` / `@opentui/keymap` / `@opentui/keymap/extras`: `CliRenderer`, `KeyEvent`, `Renderable`, `SlotMode`; `stringifyKeySequence`, `stringifyKeyStroke`; binding/format helpers listed in `packages/plugin/src/tui.ts`.

`TuiPluginApi` fields (`packages/plugin/src/tui.ts`): `app`, `attention`, optional deprecated `command` (`TuiCommandApi`: `register`, `trigger`, `show`), `keys`, `keymap`, `mode`, `route` (`register`, `navigate`, `current`), `ui` (`Dialog`, `DialogAlert`, `DialogConfirm`, `DialogPrompt`, `DialogSelect`, `Slot`, `Prompt`, `toast`, `dialog`), `tuiConfig`, `kv`, `state`, `theme`, `client`, `event`, `renderer`, `slots`, `plugins` (`list`, `activate`, `deactivate`, `add`, `install`), `lifecycle`.

Deprecated `TuiCommand` / `TuiCommandApi` comments: use `api.keymap.registerLayer`, `api.keymap.dispatchCommand`, and `api.keymap.dispatchCommand("command.palette.show")`.

`TuiAttentionSoundNames`: `["default", "question", "permission", "error", "done", "subagent_done"]`.

`TuiHostSlotMap` slot names: `app`, `app_bottom`, `home_logo`, `home_prompt`, `home_prompt_right`, `session_prompt`, `session_prompt_right`, `home_bottom`, `home_footer`, `sidebar_title`, `sidebar_content`, `sidebar_footer`.

`TuiPluginInstallOptions`: optional `global?: boolean`. `TuiPluginInstallResult`: `{ ok: true; dir; tui }` or `{ ok: false; message; missing? }`.

`TuiPluginEntry.source`: `"file"` \| `"npm"` \| `"internal"`. `TuiPluginState`: `"first"` \| `"updated"` \| `"same"`.

### V2 Effect (`@opencode-ai/plugin/v2/effect`)

`src/v2/effect/index.ts` exports type `PluginContext`, function `define`, type `Plugin`.

`define` returns the `plugin` argument (`packages/plugin/src/v2/effect/plugin.ts`). `Plugin<R = Scope.Scope>`: `id: string`; `effect: (context: PluginContext) => Effect.Effect<void, never, R>`.

`PluginContext` (`packages/plugin/src/v2/effect/context.ts`): `options` (`PluginOptions` from `src/v2/options.ts`: `Readonly<Record<string, any>>`); `agent`, `aisdk`, `catalog`, `command`, `integration`, `plugin`, `reference`, `skill`. Domains other than `aisdk` and `plugin` are `…Hooks & Reload`. `plugin` is `PluginDomain`: `add(plugin)`, `remove(id)` as `Effect.Effect<void>`.

`Hooks<Spec>` (`packages/plugin/src/v2/effect/registration.ts`): each name maps a callback `(input) => Effect.Effect<void> | void` to `Effect.Effect<Registration, never, Scope.Scope>`. `Registration.dispose` is `Effect.Effect<void>`. `Reload.reload` is `() => Effect.Effect<void>`.

Committed README (`packages/plugin/src/v2/effect/README.md`): setup registers hooks imperatively and does not return a hook object; configuration is `ctx.options`; registrations are owned by the plugin scope (closing the scope removes them; early `dispose` allowed); transform hooks are `ctx.{agent,catalog,command,integration,reference,skill}.transform`; OpenCode rebuilds a domain from fresh state and runs active transforms in registration order when a transform is registered or disposed; runtime hooks (`ctx.aisdk.sdk`, `ctx.aisdk.language`) run sequentially in registration order; `reload` belongs to the domain and reruns every active transform; public server client is not part of `PluginContext`.

### V2 Promise (`@opencode-ai/plugin/v2/promise`)

`src/v2/promise/index.ts` exports `PluginContext`, `PluginOptions`, `define`, `Plugin`, `PluginDomain`, `Registration`, `Reload`, `AgentDraft`, `AgentHooks`, `AISDKHooks`, `CatalogDraft`, `CatalogHooks`, `CatalogProviderRecord`, `CommandDraft`, `CommandHooks`, `IntegrationDraft`, `IntegrationHooks`, `IntegrationMethodRegistration`, `ReferenceDraft`, `ReferenceHooks`, `SkillDraft`, `SkillHooks`.

`define` returns the `plugin` argument (`packages/plugin/src/v2/promise/plugin.ts`). `Plugin`: `id`; `setup: (context: PluginContext) => Promise<void> | void`. `PluginDomain.add` / `remove` return `Promise<void>`.

Promise `Hooks` (`packages/plugin/src/v2/promise/registration.ts`): callback may return `Promise<void> | void`; hook installer returns `Promise<Registration>`. `Registration.dispose` is `() => Promise<void>`. `Reload.reload` is `() => Promise<void>`.

`PluginContext` field names match Effect (`packages/plugin/src/v2/promise/context.ts`). README (`packages/plugin/src/v2/promise/README.md`): Promise API is the async/await equivalent of `@opencode-ai/plugin/v2/effect`; same hook/reload capabilities; hook callbacks, registration, `reload`, and `Registration.dispose` use Promises; setup does not return a hook object.

`AISDKHooks` (`packages/plugin/src/v2/effect/aisdk.ts` and `src/v2/promise/aisdk.ts`): `sdk` event `{ model, package, options, sdk? }`; `language` event `{ model, sdk, options, language? }`.

## Error handling

This package’s published runtime helpers do not throw their own error classes: `tool` returns its argument; Effect/Promise `define` returns its argument; `createBindingLookup` forwards to keymap with empty config when `config` is undefined.

Shipped **result and skip shapes** on the TUI types (`packages/plugin/src/tui.ts`):

| Shape | Values |
|-------|--------|
| `TuiPluginInstallResult` failure | `ok: false`; `message: string`; optional `missing?: boolean` |
| `TuiAttentionNotifySkipReason` | `"attention_disabled"` \| `"empty_message"` \| `"blurred"` \| `"focused"` \| `"focus_unknown"` \| `"renderer_destroyed"` |
| `TuiAttentionNotifyResult` | `ok`, `notification`, `sound`, optional `skipped` |

V1 auth failure unions (`packages/plugin/src/index.ts`): OAuth `callback` and API `authorize` may resolve `{ type: "failed" }`.

`BunShell` types document throwing on non-zero exit unless `nothrow()` / `throws(false)` (`packages/plugin/src/shell.ts`); implementation is not in this package.
