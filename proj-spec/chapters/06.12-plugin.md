# 6.12 Plugin

> **Spec chapter:** Shipped `@opencode-ai/plugin` type and helper exports for v1 server plugins, custom tools, TUI plugins, and v2 Effect/Promise plugin definitions.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**Package:** `packages/plugin` (`@opencode-ai/plugin`, `packages/plugin/package.json`)

This leaf is the workspace package named `plugin` in the multi-leaf packages set (`schema`, `core`, `protocol`, `server`, `client`, `sdk`, `sdk-next`, `plugin`, `ui`). It is a TypeScript library of plugin contracts. Runtime work in this package is identity helpers (`tool`, `define`) plus `createBindingLookup`. Hosts that load plugins, invoke `Hooks`, or implement `PluginContext` live outside this slice (see [6.1 Agent CLI](06.1-agent-cli.md), [6.2 Core](06.2-core.md), [6.14 TUI](06.14-tui.md)). The public method catalog for consumers is [7.4 Plugin API](07.4-plugin-api.md). SDK types used here are imported from `@opencode-ai/sdk` / `@opencode-ai/sdk/v2` ([6.8 Legacy SDK](06.8-sdk.md)).

This chapter is retrospective of shipped sources under `packages/plugin`. It does not require product refactors.

### v1 plugin function (`@opencode-ai/plugin`)

`Plugin` is `(input: PluginInput, options?: PluginOptions) => Promise<Hooks>` (`packages/plugin/src/index.ts` `Plugin`). `PluginOptions` is `Record<string, unknown>`. `Config` is `Omit<SDKConfig, "plugin">` with `plugin?: Array<string | [string, PluginOptions]>` (`packages/plugin/src/index.ts` `Config`).

`PluginInput` fields (`packages/plugin/src/index.ts` `PluginInput`):

| Field | Type / role |
|-------|-------------|
| `client` | `ReturnType<typeof createOpencodeClient>` |
| `project` | `Project` (SDK) |
| `directory` | `string` |
| `worktree` | `string` |
| `experimental_workspace` | `{ register(type: string, adapter: WorkspaceAdapter): void }` |
| `serverUrl` | `URL` |
| `$` | `BunShell` |

`WorkspaceAdapter` (`packages/plugin/src/index.ts`): `name`, `description`, `configure`, `create`, `remove`, `target`. `WorkspaceTarget` is `{ type: "local"; directory: string }` or `{ type: "remote"; url: string \| URL; headers?: HeadersInit }`.

`PluginModule` is `{ id?: string; server: Plugin; tui?: never }`. `TuiPluginModule` (tui entry) is `{ id?: string; tui: TuiPlugin; server?: never }` (`packages/plugin/src/index.ts` `PluginModule`, `packages/plugin/src/tui.ts` `TuiPluginModule`).

`Hooks` optional keys (`packages/plugin/src/index.ts` `Hooks`):

| Key | Callback shape (summary) |
|-----|--------------------------|
| `dispose` | `() => Promise<void>` |
| `event` | `(input: { event: Event }) => Promise<void>` |
| `config` | `(input: Config) => Promise<void>` |
| `tool` | `{ [key: string]: ToolDefinition }` |
| `auth` | `AuthHook` |
| `provider` | `ProviderHook` (`id`, optional `models`) |
| `chat.message` | session/agent/model input; mutates `{ message: UserMessage; parts: Part[] }` |
| `chat.params` | mutates `temperature`, `topP`, `topK`, `maxOutputTokens`, `options` |
| `chat.headers` | mutates `{ headers: Record<string, string> }` |
| `permission.ask` | `Permission` in; `{ status: "ask" \| "deny" \| "allow" }` out |
| `command.execute.before` | `{ command, sessionID, arguments }`; `{ parts: Part[] }` |
| `tool.execute.before` | `{ tool, sessionID, callID }`; `{ args }` |
| `shell.env` | `{ cwd, sessionID?, callID? }`; `{ env: Record<string, string> }` |
| `tool.execute.after` | `{ tool, sessionID, callID, args }`; `{ title, output, metadata }` |
| `experimental.chat.messages.transform` | mutates `{ messages: { info: Message; parts: Part[] }[] }` |
| `experimental.chat.system.transform` | `{ sessionID?, model }`; `{ system: string[] }` |
| `experimental.provider.small_model` | `{ provider: ProviderV2 }`; `{ model?: ModelV2 }` |
| `experimental.session.compacting` | `{ sessionID }`; `{ context: string[]; prompt?: string }` |
| `experimental.compaction.autocontinue` | session/agent/model/message/`overflow`; `{ enabled: boolean }` (comment: defaults to `true`; `false` skips synthetic continue) |
| `experimental.text.complete` | `{ sessionID, messageID, partID }`; `{ text: string }` |
| `tool.definition` | `{ toolID }`; `{ description, parameters }` |

`ProviderContext.source` is `"env" | "config" | "custom" | "api"` (`packages/plugin/src/index.ts` `ProviderContext`).

`AuthHook` (`packages/plugin/src/index.ts`): `provider: string`; optional `loader`; `methods` array of `{ type: "oauth", label, prompts?, authorize }` or `{ type: "api", label, prompts?, authorize? }`. Prompt `when` is `Rule` (`key`, `op`: `"eq" | "neq"`, `value`). Prompt `condition` is marked `@deprecated Use \`when\` instead`. `AuthOuathResult` is a deprecated alias of `AuthOAuthResult`.

OAuth `authorize` returns `AuthOAuthResult`: `{ url: string; instructions: string }` plus `method: "auto"` with `callback(): Promise<…>` or `method: "code"` with `callback(code: string): Promise<…>`. Success payloads include either `{ refresh, access, expires, accountId?, enterpriseUrl? }` or `{ key, metadata? }`.

### Tool definition (`./tool`)

`ToolContext` (`packages/plugin/src/tool.ts`): `sessionID`, `messageID`, `agent`, `directory`, `worktree`, `abort` (`AbortSignal`), `metadata({ title?, metadata? })`, `ask(AskInput)`. `AskInput`: `permission`, `patterns`, `always`, `metadata`.

`ToolResult` is `string` or `{ title?: string; output: string; metadata?; attachments?: ToolAttachment[] }`. `ToolAttachment` is `{ type: "file"; mime; url; filename? }`. `ToolDefinition` is `ReturnType<typeof tool>`.

### TUI plugin (`./tui`)

`TuiPlugin` is `(api: TuiPluginApi, options: PluginOptions | undefined, meta: TuiPluginMeta) => Promise<void>` (`packages/plugin/src/tui.ts` `TuiPlugin`).

`TuiPluginApi` includes `app`, `attention`, optional deprecated `command` (`TuiCommandApi`), `keys`, `keymap`, `mode`, `route`, `ui` (`Dialog`, `DialogAlert`, `DialogConfirm`, `DialogPrompt`, `DialogSelect`, `Slot`, `Prompt`, `toast`, `dialog`), `tuiConfig`, `kv`, `state`, `theme`, `client`, `event`, `renderer`, `slots`, `plugins`, `lifecycle`.

Deprecated `command` comments name replacements: `api.keymap.registerLayer({ commands, bindings })`, `api.keymap.dispatchCommand(name)`, `api.keymap.dispatchCommand("command.palette.show")`.

`TuiAttentionSoundNames` is `["default", "question", "permission", "error", "done", "subagent_done"]` (`packages/plugin/src/tui.ts` `TuiAttentionSoundNames`).

`TuiPluginEntry.source` is `"file" | "npm" | "internal"`. `TuiPluginState` is `"first" | "updated" | "same"`. `TuiPluginInstallOptions` is `{ global?: boolean }`.

`plugins.install` is typed to return `TuiPluginInstallResult` (`ok: true` with `dir`, `tui`; or `ok: false` with `message`, optional `missing`).

`TuiHostSlotMap` names: `app`, `app_bottom`, `home_logo`, `home_prompt`, `home_prompt_right`, `session_prompt`, `session_prompt_right`, `home_bottom`, `home_footer`, `sidebar_title`, `sidebar_content`, `sidebar_footer`.

Re-exports from `@opentui/core`, `@opentui/keymap`, and `@opentui/keymap/extras` are listed on `packages/plugin/src/tui.ts` (types plus `stringifyKeySequence`, `stringifyKeyStroke`, `formatCommandBindings`, `formatKeySequence`).

### v2 Effect plugin (`./v2/effect`)

`packages/plugin/src/v2/effect/index.ts` exports type `PluginContext`, function `define`, type `Plugin`. Additional package exports `./v2/effect/plugin` and `./v2/effect/integration` expose `Plugin`/`define`/`PluginDomain` and integration types without going through the index.

Effect `Plugin<R = Scope.Scope>` (`packages/plugin/src/v2/effect/plugin.ts`): `id: string`; `effect: (context: PluginContext) => Effect.Effect<void, never, R>`. `PluginDomain`: `add(plugin) => Effect.Effect<void>`; `remove(id) => Effect.Effect<void>`.

`PluginContext` (`packages/plugin/src/v2/effect/context.ts`): `options` (`PluginOptions` = `Readonly<Record<string, any>>` from `packages/plugin/src/v2/options.ts`); `agent`, `catalog`, `command`, `integration`, `reference`, `skill` each `Hooks & Reload`; `aisdk: AISDKHooks`; `plugin: PluginDomain`.

Effect `Hooks<Spec>` (`packages/plugin/src/v2/effect/registration.ts`): each spec key is `(callback: (input) => Effect.Effect<void> | void) => Effect.Effect<Registration, never, Scope.Scope>`. `Registration.dispose` is `Effect.Effect<void>`. `Reload.reload` is `() => Effect.Effect<void>`.

Transform hook names on drafts:

| Domain | Hook | Draft methods | Source |
|--------|------|---------------|--------|
| `agent` | `transform` | `list`, `get`, `default`, `update`, `remove` | `packages/plugin/src/v2/effect/agent.ts` |
| `catalog` | `transform` | `provider.list/get/update/remove`; `model.get/update/remove`; `model.default.get/set` | `packages/plugin/src/v2/effect/catalog.ts` |
| `command` | `transform` | `list`, `get`, `update`, `remove` | `packages/plugin/src/v2/effect/command.ts` |
| `integration` | `transform` | `list`, `get`, `update`, `remove`; `method.list/update/remove` | `packages/plugin/src/v2/effect/integration.ts` |
| `reference` | `transform` | `add`, `remove`, `list` | `packages/plugin/src/v2/effect/reference.ts` |
| `skill` | `transform` | `source`, `list` | `packages/plugin/src/v2/effect/skill.ts` |

`AISDKHooks` keys are `sdk` and `language` (`packages/plugin/src/v2/effect/aisdk.ts`). `sdk` input includes `model`, `package`, `options`, optional `sdk`. `language` input includes `model`, `sdk`, `options`, optional `language` (`LanguageModelV3`).

`IntegrationHooks` also has `connection.active` and `connection.resolve` (`packages/plugin/src/v2/effect/integration.ts`). OAuth method registration `authorize` returns `IntegrationOAuthAuthorization`: `{ url, instructions }` plus `mode: "auto"` with `callback: Effect.Effect<CredentialOAuth, unknown>` or `mode: "code"` with `callback: (code: string) => Effect.Effect<CredentialOAuth, unknown>` (field name is `mode`, not v1 `method`).

### v2 Promise plugin (`./v2/promise`)

`packages/plugin/src/v2/promise/index.ts` exports `PluginContext`, `PluginOptions`, `define`, `Plugin`, `PluginDomain`, `Registration`, `Reload`, and draft/hook types for agent, AISDK, catalog, command, integration, reference, and skill.

Promise `Plugin` (`packages/plugin/src/v2/promise/plugin.ts`): `id: string`; `setup: (context: PluginContext) => Promise<void> | void`. `PluginDomain.add` / `remove` return `Promise<void>`.

Promise `PluginContext` field names match Effect (`packages/plugin/src/v2/promise/context.ts`). Promise `Hooks<Spec>` (`packages/plugin/src/v2/promise/registration.ts`): each key is `(callback: (input) => Promise<void> | void) => Promise<Registration>`. `Registration.dispose` is `() => Promise<void>`. `Reload.reload` is `() => Promise<void>`.

Promise `AgentDraft`, `CatalogDraft`, `CommandDraft`, `SkillDraft`, `ReferenceDraft`, `CatalogProviderRecord`, and `IntegrationDraft` / `IntegrationMethodRegistration` are re-exported from the Effect modules (`packages/plugin/src/v2/promise/*.ts`). Promise `IntegrationHooks.connection.active` / `resolve` return `Promise<…>` (`packages/plugin/src/v2/promise/integration.ts`).

## Error handling

This package mostly types failure shapes. It does not throw from `tool` / `define` / `createBindingLookup`.

| Shape | Identifiers | Source |
|-------|-------------|--------|
| OAuth / API authorize failure | `{ type: "failed" }` | `packages/plugin/src/index.ts` `AuthOAuthResult`, `AuthHook` api `authorize` |
| API authorize success | `{ type: "success"; key; provider?; metadata? }` | `packages/plugin/src/index.ts` `AuthHook` |
| TUI plugin install failure | `{ ok: false; message: string; missing?: boolean }` | `packages/plugin/src/tui.ts` `TuiPluginInstallResult` |
| TUI plugin install success | `{ ok: true; dir: string; tui: boolean }` | `packages/plugin/src/tui.ts` `TuiPluginInstallResult` |
| Attention notify skip | `TuiAttentionNotifySkipReason`: `"attention_disabled"`, `"empty_message"`, `"blurred"`, `"focused"`, `"focus_unknown"`, `"renderer_destroyed"` | `packages/plugin/src/tui.ts` |
| Attention notify result | `{ ok: boolean; notification: boolean; sound: boolean; skipped?: TuiAttentionNotifySkipReason }` | `packages/plugin/src/tui.ts` `TuiAttentionNotifyResult` |
| Prompt validate | `(value: string) => string \| undefined` | `packages/plugin/src/index.ts` `AuthHook` prompts |
| Bun shell non-zero exit | `BunShell.nothrow` / `throws`: comments state the shell throws on non-zero unless configured otherwise; `BunShellError` is `Error & BunShellOutput` | `packages/plugin/src/shell.ts` |
| Effect integration OAuth errors | `Effect.Effect<…, unknown>` / `unknown` on `authorize`, `callback`, `refresh`, `connection.resolve` | `packages/plugin/src/v2/effect/integration.ts` |
| `Npm.add` | `Effect.Effect<…, unknown>` | `packages/plugin/src/v2/effect/npm.ts` (unexported) |

Concrete `message` strings for `TuiPluginInstallResult` are not emitted in this package.
