## Behavior

### Native wrapper (`bin/lildax.cjs`)

`packages/cli/bin/lildax.cjs` shebang is `#!/usr/bin/env node`. It `spawn`s a resolved native binary with `process.argv.slice(2)` and `stdio: "inherit"`. It forwards `SIGINT`, `SIGTERM`, and `SIGHUP` to the child. On child `exit`, if `signal` is set it `process.kill(process.pid, signal)`; otherwise `process.exit(typeof code === "number" ? code : 0)`. Spawn `error` writes `error.message` to stderr and `process.exit(1)`.

Resolution order (`resolved`):

1. `process.env.OPENCODE_BIN_PATH` if set.
2. Else `path.join(scriptDir, ".lildax")` if that file exists (`scriptDir` is `path.dirname(fs.realpathSync(__filename))`).
3. Else walk from `scriptDir` toward filesystem root, looking under each `node_modules/<name>/bin/<binary>` for names in `names`.

`platform` map: `darwin` → `darwin`, `linux` → `linux`, `win32` → `windows`, else `os.platform()`. `arch` map: `x64`, `arm64`, `arm`, else `os.arch()`. `base` is `"@opencode-ai/cli-" + platform + "-" + arch`. `binary` is `"lildax.exe"` on `platform === "windows"`, else `"lildax"`.

x64 without AVX2 (`supportsAvx2()` false) is `baseline`. Linux also prefers musl vs glibc (`/etc/alpine-release` or `ldd --version` text including `"musl"`). Candidate `names` arrays are those in `packages/cli/bin/lildax.cjs` (glibc/musl × baseline/avx2 order). If nothing resolves, stderr is exactly:

`It seems that your package manager failed to install the right lildax CLI package. Try manually installing ` + quoted `names` joined by ` or ` + ` package`

then `process.exit(1)`.

`supportsAvx2`: non-x64 is `false`. Linux reads `/proc/cpuinfo` for `/(^|\s)avx2(\s|$)/i`. Darwin `sysctl -n hw.optional.avx2_0` stdout trim `"1"`. Windows tries `powershell.exe` / `pwsh.exe` / `pwsh` / `powershell` with `IsProcessorFeaturePresent(40)`; stdout trim lowercased `"true"` or `"1"` is true, `"false"` or `"0"` is false.

### Compile and publish

`packages/cli/script/build.ts` removes `dist`, then for each target `Bun.build` compile of `./src/index.ts` with Solid plugin, `outfile` `./dist/${name}/bin/lildax` where `name` is `lildax-…` with `lildax` replaced by `cli` (example: `cli-linux-x64`). `--single` keeps `allTargets` rows where `item.os === process.platform` and `item.arch === process.arch`; then if `item.avx2 === false` includes the row iff `--baseline` (no `abi` check, so linux x64 `--single --baseline` includes both `{ avx2: false }` and `{ abi: "musl", avx2: false }`); else includes the row iff `item.abi === undefined`. Other flags: `--skip-install`, `--sourcemaps`. `execArgv`: `` `--user-agent=lildax/${Script.version}` ``, `"--use-system-ca"`, `"--"`. `define` includes `OPENCODE_CLI_NAME: `'lildax'`` and `OPENCODE_LIBC` / `FFF_LIBC` / `process.env.OPENTUI_LIBC` on linux (`glibc`/`gnu` vs `musl`). Each target writes `dist/<name>/package.json` with `name` `@opencode-ai/<name>`, `os`/`cpu` from the target.

`packages/cli/script/publish.ts` copies `./bin/lildax.cjs` to `./dist/@opencode-ai/cli/bin/lildax`, writes a meta `package.json` with `bin: { lildax: "./bin/lildax" }`, `os` `["darwin","linux","win32"]`, `cpu` `["arm64","x64"]`, and `optionalDependencies` equal to the scanned dist binary packages. It `npm publish` each binary package then the meta package (`--access public --tag ${Script.channel}`), skipping when `npm view ${name}@${version}` already succeeds.

### Daemon

`Daemon.layer` (`packages/cli/src/services/daemon.ts`) uses `directory = Global.Path.state` (imported from `@opencode-ai/core/global`; concrete directory is outside this slice — OQ-6.15-12), `file = path.join(directory, "server.json")`, `passwordFile = path.join(directory, "password")`.

`password(value?)`: if `value` is undefined and the password file has content, return that string. Else write `value ?? randomBytes(32).toString("base64url")` via `passwordFile + ".tmp"` then rename. Comment in source: keep one private credential across restarts without a password flag or environment variable.

`Registration` JSON: optional `id`, optional `version`, required `url`, `pid` int `> 0`.

`healthy`: decode `server.json`, `createOpencodeClient({ baseUrl: url, headers: ServerAuth.headers({ password }) })`, `client.v2.health.get`; succeeds when `response.data?.healthy === true`. Else fail `Registered server is not healthy`. HTTP/client contracts of `@opencode-ai/sdk` / `@opencode-ai/server` are outside this slice (OQ-6.15-12).

`compatible`: `healthy` plus `info.version === InstallationVersion` (`@opencode-ai/core/installation/version`; OQ-6.15-12). Else `Registered server version does not match the client`.

`start`: if a healthy registration has matching `InstallationVersion` **and** compiled (`path.basename(process.execPath).replace(/\.exe$/, "") !== "bun"`), return `found.url`. Else stop that process if present, then `spawn(process.execPath, [...(entrypoint ? [entrypoint] : []), "serve", "--register"], { detached: true, stdio: "ignore" }).unref()`. Uncompiled requires `process.argv[1]` as `entrypoint` or fails `Failed to resolve CLI entrypoint`. Then retry `compatible` with the 50 ms / 100 recurs schedule; map remaining failure to `Failed to start server`.

`transport`: `{ url: yield* start(), headers: ServerAuth.headers({ password: yield* password() }) }`.

`status`: matching-version healthy URL; else if some other healthy registration exists, `undefined` (file kept); else `fs.remove(file)` and `undefined`.

`stop`: if not healthy, remove `file`. Else `stopProcess` then remove `file`. `stopProcess` signals `SIGTERM`, waits with 50 ms / 100 recurs; if still the same healthy registration, `SIGKILL` and wait again. It no-ops if the live registration is no longer `sameRegistration`.

`register(address)`: write `{ id: randomUUID(), version: InstallationVersion, url: HttpServer.formatAddress(address), pid: process.pid }` to `file + "." + id + ".tmp"` then rename to `server.json`. A scoped fiber every `"10 seconds"` `SIGTERM`s this process if decoded `id` is not this registration (or decode fails). Finalizer removes `file` only when current `id` still matches.

### Default command (TUI)

Root handler (`packages/cli/src/commands/handlers/default.ts`): `daemon.transport()` then `runTui(transport)`.

`runTui` (`packages/cli/src/tui.ts`): `TuiConfig.resolve({}, { terminalSuspend: false })`, then `@opencode-ai/tui` `run({ ...transport, args: {}, config, fetch: gracefulFetch, pluginHost: { start() {}, dispose() {} } })` provided `AppNodeBuilder.build(Global.node)`. TUI rendering is [6.14 TUI](06.14-tui.md) (OQ-6.15-12).

`gracefulFetch`: on HTTP `404`, if pathname is a key in `legacyDefaults`, return `Response.json(fallback)`:

| Pathname | JSON |
|----------|------|
| `/config/providers` | `{ providers: [], default: {} }` |
| `/provider` | `{ all: [], default: {}, connected: [] }` |
| `/agent` | `[]` |
| `/config` | `{}` |

Otherwise return the original response. `preconnect` is `fetch.preconnect`.

### `api` command

Handler (`packages/cli/src/commands/handlers/api.ts`, span `cli.api`): `daemon.transport()`, resolve request, copy `transport.headers` into `Headers`, apply `--header` entries (`indexOf(":")` must be `>= 1`; name/value trimmed). If `--data` is present and `content-type` is unset, set `content-type` to `application/json`. `fetch(new URL(request.path, transport.url), { method, headers, body })`. If response text is non-empty, write it to stdout plus `EOL` unless the text already ends with `EOL`.

`rawRequest`: length `2`, method in `{ delete, get, head, options, patch, post, put }` (compared lowercased), path `startsWith("/")` → `{ method: input[0].toUpperCase(), path: input[1] }`.

Otherwise length must be `1` (else `Expected an operation name or an HTTP method and path`). Loads `GET` `new URL("/openapi.json", transport.url)` with `transport.headers`. Non-OK → `Failed to load OpenAPI document: HTTP ${response.status}`. `resolveOperation` walks `spec.paths` for matching `operationId` and method in that set; missing → `Operation not found: ${operationID}`.

`interpolate`: `{name}` replaced with `encodeURIComponent(params[name])`; missing → `Missing path parameter: ${name}`. Unused params become `URLSearchParams` query string.

### `service` commands

| Command | Behavior | Source |
|---------|----------|--------|
| `service start` | stdout `start()` URL + `EOL` | `handlers/service/start.ts` |
| `service restart` | `stop()` then stdout `start()` URL + `EOL` | `handlers/service/restart.ts` |
| `service status` | stdout `` `running ${url}` `` + `EOL` if URL, else `"stopped"` + `EOL` | `handlers/service/status.ts` |
| `service stop` | `daemon.stop()` | `handlers/service/stop.ts` |
| `service password` | if `value` is defined, `daemon.stop()` first; stdout `password(value)` + `EOL` | `handlers/service/password.ts` |

### `serve` command

`packages/cli/src/commands/handlers/serve.ts` (span `cli.serve`): scoped `listen(hostname, port, daemon.password())`. If `--register`, `daemon.register(address)`. Then `console.log(\`server listening on ${HttpServer.formatAddress(address)}\`)` and `Effect.never`.

`bind` serves `createRoutes(password)` (`@opencode-ai/server/routes`; HTTP route table is [6.5 Server](06.5-server.md) — OQ-6.15-12) with `disableListenLog: true`, `disableLogger: true`, `NodeHttpServer.layer(() => createServer(), { port, host: hostname })`, and `AppNodeBuilder.build(LayerNode.group([Credential.node, PermissionSaved.node]))`.

### `migrate` and `debug agents`

`migrate` (`handlers/migrate.ts`): `Effect.log("No migrations to run.")`.

`debug agents` (`handlers/debug/agents.ts`): `daemon.client()`, `client.v2.agent.list({ location: { directory: process.cwd() } })`, stdout `JSON.stringify(response.data?.data.toSorted((a, b) => a.id.localeCompare(b.id)), null, 2) + EOL`.

## Error handling

| Condition | Emission | Source |
|-----------|----------|--------|
| Wrapper spawn failure | `console.error(error.message)`; exit `1` | `run` (`bin/lildax.cjs`) |
| Wrapper binary missing | stderr install message (quoted `names`); exit `1` | `bin/lildax.cjs` |
| Invalid `--header` | `Error` `` `Invalid header, expected name:value: ${header}` `` | `handlers/api.ts` |
| `api` request neither raw nor single token | `Error` `Expected an operation name or an HTTP method and path` | `resolveRequest` (`handlers/api.ts`) |
| OpenAPI fetch not OK | `Error` `` `Failed to load OpenAPI document: HTTP ${response.status}` `` | `resolveRequest` |
| Unknown operation id | `Error` `` `Operation not found: ${operationID}` `` | `resolveOperation` |
| Missing `{param}` | `Error` `` `Missing path parameter: ${name}` `` | `interpolate` |
| Health check not `healthy: true` | `Error` `Registered server is not healthy` | `healthy` (`daemon.ts`) |
| Registration version ≠ `InstallationVersion` | `Error` `Registered server version does not match the client` | `compatible` |
| Dev start without `argv[1]` | `Error` `Failed to resolve CLI entrypoint` | `start` |
| Spawn throws | `Error` `Failed to start server` with `cause` | `start` |
| `compatible` retry exhausted | `Error` `Failed to start server` | `start` `mapError` |
| PID still alive after wait | `Error` `` `Server process ${pid} is still running` `` | `awaitStopped` |
| `Bun.build` unsuccessful | `console.error` each log; `process.exit(1)` | `script/build.ts` |

Effect CLI / `NodeRuntime.runMain` process exit mapping is not specified in allowed CLI sources (OQ-6.15-10).
