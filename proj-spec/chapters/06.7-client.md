# 6.7 Client

> **Spec chapter:** Shipped `@opencode-ai/client` package — generated Promise (`fetch`) and Effect HTTP clients plus the hand-authored contract and entrypoints that feed codegen.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/client` (`@opencode-ai/client`)

Retrospective description of shipped behavior (C8). This leaf is the `client` package in the multi-leaf set `schema`, `core`, `protocol`, `server`, `client`, `sdk`, `sdk-next`, `plugin`, `ui`. Trees `src/generated` and `src/generated-effect` (under `packages/client`) are **generated**; they are not the behavioral source of truth (C5). Regeneration is invoked from this package as `bun run generate`; the workspace generate token set is recorded below and belongs canonically in [10.2 Generate](10.2-generate.md). This slice does not claim that `@opencode-ai/client` invokes every listed generate command.

Hand-authored sources in this slice: `packages/client/src/index.ts`, `packages/client/src/effect.ts`, `packages/client/src/contract.ts`, `packages/client/script/build.ts`. Generator implementation lives in [6.6 HttpApi codegen](06.6-httpapi-codegen.md). Public SDK-facing method catalog belongs in [7.2 SDK API](07.2-sdk-api.md).

### Regeneration (C5)

Do not edit `src/generated` or `src/generated-effect` directly (`AGENTS.md`). After changing the public Protocol or Server `HttpApi`, run `bun run generate` from `packages/client` (`AGENTS.md`).

Consistency token `generate` (canonical home [10.2 Generate](10.2-generate.md)): `bun run generate` (packages/client); `./packages/sdk/js/script/build.ts`; `generate:tailwind`; `generate:v2-oc2`; `db:generate` / `drizzle-kit generate`.

Consistency token `generated dirs`: `src/generated`, `src/generated-effect`, `packages/sdk/js/src/v2/gen/`, `packages/sdk/js/dist/`. This slice’s generated output is `packages/client/src/generated/` and `packages/client/src/generated-effect/` (T1-chapter-map.md §5). Other listed generated dirs are not produced by this package.

`packages/client/script/build.ts` is the in-slice generator:

1. `compile(ClientApi, { groupNames, endpointNames, omitEndpoints })` with symbols imported from `packages/client/src/contract.ts`.
2. `write(emitPromise(contract, { outputTypes: { "events.subscribe": { name: "OpenCodeEventEncoded", import: 'import type { OpenCodeEventEncoded } from "@opencode-ai/protocol/groups/event"' } } }), …/src/generated)`.
3. `write(emitPromise…)` and `write(emitEffectImported(contract, { module: "../contract", api: "ClientApi" }), …/src/generated-effect)` run concurrently (`concurrency: 2`) under `Effect.provide(NodeFileSystem.layer)` (`script/build.ts`).

`compile`, `emitPromise`, `emitEffectImported`, and `write` are imported from `@opencode-ai/httpapi-codegen` (`script/build.ts`). Emitter semantics are specified in [6.6 HttpApi codegen](06.6-httpapi-codegen.md), not from files under `src/generated` or `src/generated-effect`.

`packages/client/test/contract-identity.test.ts` `"client and Server contracts generate identically"` compiles Server `Api` and `ClientApi` with the same `groupNames`, `endpointNames`, and `omitEndpoints`, then asserts `emitPromise(client)` equals `emitPromise(server)`. That test is the in-slice check that the client-local projection matches Server’s `HttpApi` for Promise emission. `script/build.ts` itself compiles `ClientApi`, not Server `Api`.

### Runtime dependency direction

Committed workspace rule (`AGENTS.md`): runtime dependencies are directed from Schema to Core and Protocol, then from Core and Protocol to Server. Client runtime code may depend on Schema and Protocol but never Core or Server; `sdk-next` composes Client, Core, and Server.

`packages/client/package.json` runtime `dependencies` are `@opencode-ai/schema` and `@opencode-ai/protocol` only. `@opencode-ai/core`, `@opencode-ai/server`, and `@opencode-ai/httpapi-codegen` are `devDependencies`. `packages/client/src/effect.ts` states `/effect` must never import Core or Server.

`packages/client/test/import-boundaries.test.ts` `"isolates each public entrypoint"`: a browser bundle of `@opencode-ai/client` includes none of `effect`, `packages/schema`, `packages/protocol`, `packages/core`, or `packages/server`; a browser bundle of `@opencode-ai/client/effect` includes `effect`, `schema`, and `protocol` and includes none of `packages/core` or `packages/server`.

## Behavior

### Promise entrypoint

`packages/client/src/index.ts` re-exports `./generated/index` and `export type { EventsSubscribeOutput as OpenCodeEvent } from "./generated/types"`. Generated modules under `src/generated` are produced by `emitPromise` in `script/build.ts` (C5).

`packages/client/README.md` Entrypoints: `@opencode-ai/client` is a zero-Effect Promise client using `fetch`.

Tests construct the client as `OpenCode.make({ baseUrl })`, optionally replacing `fetch` (`packages/client/test/promise.test.ts`).

| Method / surface | Behavior |
|------------------|----------|
| `OpenCode.make({ baseUrl })` group keys | `health`, `location`, `agents`, `sessions`, `messages`, `models`, `providers`, `integrations`, `credentials`, `permissions`, `files`, `commands`, `skills`, `events`, `ptys`, `questions`, `references`, `projectCopies` (`packages/client/test/promise.test.ts` `"exposes every standard HTTP API group"`) |
| `client.messages` | keys `["list"]` (same test; matches `endpointNames["session.messages"]` = `"list"` in `packages/client/src/contract.ts`) |
| `client.integrations` | keys `list`, `get`, `connectKey`, `connectOauth`, `attemptStatus`, `attemptComplete`, `attemptCancel` (same test) |
| `client.files` | keys `["list", "find"]` (same test; `omitEndpoints` includes `"fs.read"` in `packages/client/src/contract.ts`) |
| `client.ptys` | keys `["list", "create", "get", "update", "remove"]` (same test; `omitEndpoints` includes `"pty.connect"` and `"pty.connectToken"`) |
| `client.sessions.get({ sessionID })` | `GET` `{baseUrl}/api/session/{sessionID}`; returns wire projection with numeric `time.created` (`"sessions.get returns the wire projection"`) |
| `client.events.subscribe()` | `AsyncIterable` of SSE `data:` JSON objects (heartbeat comment lines are not events); wire `type` values including `"server.connected"` and `"session.next.model.switched"` (`"events.subscribe exposes the Promise event stream wire projection"`) |
| Session HTTP methods | URLs and methods asserted in `"session methods use the public HTTP contract"` (table below) |
| Prompt JSON body | `POST` `…/api/session/{sessionID}/prompt` body `{"prompt":{"text":"Hello"},"resume":false}` (same test) |

### Effect entrypoint

`packages/client/src/effect.ts` re-exports `./generated-effect/index` (from `emitEffectImported` in `script/build.ts`, C5) and re-exports Schema namespaces `Agent`, `Command`, `Credential`, `FileSystem`, `Integration`, `Location`, `Model`, `Permission`, `PermissionSaved`, `Project`, `ProjectCopy`, `Provider`, `Pty`, `Question`, `Reference`, `Session`, `SessionInput`, `SessionMessage`, `Skill`, `Prompt`, plus `AbsolutePath`, `RelativePath`, and `export type { OpenCodeEvent } from "@opencode-ai/protocol/groups/event"`. Comment on `effect.ts`: keep additional network capabilities inside Schema and Protocol; `/effect` must never import Core or Server; datatype exports are preserved so callers do not migrate when internal models reorganize.

`packages/client/README.md` Entrypoints: `@opencode-ai/client/effect` is a rich Effect network client using an environment-provided `HttpClient`. Effect consumers construct decoded inputs such as `Location.Ref`, `AbsolutePath`, `Prompt` (`packages/client/README.md` example; `packages/client/test/effect.test.ts`).

Tests construct `yield* OpenCode.make({ baseUrl: "http://localhost:3000" })` and provide `HttpClient.HttpClient` (`packages/client/test/effect.test.ts`).

| Method / surface | Behavior |
|------------------|----------|
| `client.sessions.get` | Returns decoded Effect projection; `DateTime.toEpochMillis(result.time.created)` matches wire millis (`"sessions.get returns the decoded Effect projection"`) |
| `client.events.subscribe()` | Effect `Stream`; collects decoded events with `type` `"server.connected"` then `"session.next.model.switched"`; durable fields `aggregateID`, `seq`, `version` (`"events.subscribe exposes and decodes the native Effect event stream"`) |
| Session methods | `list`, `active`, `create`, `switchAgent`, `switchModel`, `prompt` (`resume: false`), `compact`, `wait`, `context`, `history` (query `limit`/`after` as strings `"1"`/`"0"` then `"2"`/`"1"`), `events` stream, `interrupt`, `message` (`"session methods retain decoded Effect inputs and outputs"`) |
| `{ data: … }` envelopes | Unwrapped in results (`created.id`, `admitted`, `context` as `[]`, `active` map) (same test) |

## Error handling

| Surface | Condition | Observable |
|---------|-----------|------------|
| Promise `events.subscribe` | SSE `data:` is not JSON | Rejects with `{ name: "ClientError", reason: "MalformedResponse" }` (`packages/client/test/promise.test.ts` `"events.subscribe terminates on malformed Promise SSE data"`) |
| Promise `sessions.create` | JSON `{ _tag: "UnauthorizedError", message: "Authentication required" }` with HTTP 401 | `isUnauthorizedError(error)` is `true` (`"middleware errors remain declared client errors"`) |
| Promise `sessions.history` | JSON `{ _tag: "SessionNotFoundError", sessionID: "ses_missing", message: "Session not found" }` with HTTP 404 | `isSessionNotFoundError(error)` is `true` (`"sessions.history decodes SessionNotFoundError"`) |
| Effect `events.subscribe` | SSE payload missing required fields for decode | Failed Effect with `error._tag` `"ClientError"` (`packages/client/test/effect.test.ts` `"events.subscribe terminates on Effect protocol decode failures"`) |
| Effect `sessions.history` | Same `SessionNotFoundError` JSON and HTTP 404 | Failed Effect with `error._tag` `"SessionNotFoundError"` (`"sessions.history retains the typed SessionNotFoundError"`) |

`isUnauthorizedError` and `isSessionNotFoundError` are imported from `packages/client/src/index.ts` in Promise tests.
