# 10.2 Generate

> **Spec chapter:** Workspace regeneration commands and generated output trees (C5).

This chapter is the canonical home for consistency token **generate** and **generated dirs**. It describes **shipped** regeneration entrypoints only (C8 retrospective). Package runtime behavior belongs in the related §6 leaves. This chapter does **not** claim that any one package invokes every listed command.

Generated trees (`src/generated`, `src/generated-effect`, `packages/sdk/js/src/v2/gen/`, `packages/sdk/js/dist/`) are **generated**. They are not the behavioral source of truth (C5). Point to the generator/script named below.

## Behavior

### Client `bun run generate`

`packages/client/script/build.ts` compiles `ClientApi` from `packages/client/src/contract.ts` with `{ groupNames, endpointNames, omitEndpoints }`, then writes two trees concurrently (`concurrency: 2`, `discard: true`) under `Effect.provide(NodeFileSystem.layer)`:

| Step | Call | Output directory |
|------|------|------------------|
| Promise client | `write(emitPromise(contract, { outputTypes: { "events.subscribe": { name: "OpenCodeEventEncoded", import: 'import type { OpenCodeEventEncoded } from "@opencode-ai/protocol/groups/event"' } } }), …/src/generated)` | `packages/client/src/generated` |
| Effect client | `write(emitEffectImported(contract, { module: "../contract", api: "ClientApi" }), …/src/generated-effect)` | `packages/client/src/generated-effect` |

`write` creates the directory, removes stale paths listed in `.httpapi-codegen.json` that are not in the new output, Prettier-formats TypeScript (`parser: "typescript"`, `semi: false`, `printWidth: 120`), writes files, then writes the manifest as sorted JSON plus a trailing newline (`write`, `packages/httpapi-codegen/src/index.ts`). Checked-in Promise manifest lists `client-error.ts`, `client.ts`, `index.ts`, `types.ts`; Effect manifest lists `client-error.ts`, `client.ts`, `index.ts` (`packages/client/src/generated/.httpapi-codegen.json`, `packages/client/src/generated-effect/.httpapi-codegen.json`). Those files are generated output, not the generator.

`omitEndpoints` is `fs.read`, `pty.connect`, `pty.connectToken` (`packages/client/src/contract.ts`). Emitter semantics belong in [6.6 HttpApi codegen](06.6-httpapi-codegen.md). `script/build.ts` compiles `ClientApi`, not Server `Api`. Equivalence of Promise emission for `ClientApi` vs Server `Api` (same `groupNames` / `endpointNames` / `omitEndpoints`) is asserted by `packages/client/test/contract-identity.test.ts` `"client and Server contracts generate identically"`.

### Legacy JS SDK `./packages/sdk/js/script/build.ts`

`packages/sdk/js/script/build.ts` (`#!/usr/bin/env bun`) `chdir`s to `packages/sdk/js`, then:

1. Runs `` bun dev generate > ${dir}/openapi.json `` with `.cwd` `packages/opencode` (path resolved as `../../opencode` from the SDK package). The OpenAPI document that command emits is outside this slice’s allowed paths (OQ-10.2-2).
2. Loads `./openapi.json`. If `components.schemas` exists, walks `$ref` values starting with `#/components/schemas/` and deletes schema names matching `/^SessionNext\w+1$/` that are not reachable; writes the document back.
3. `createClient` from `@hey-api/openapi-ts` with `input: "./openapi.json"`, `output.path: "./src/v2/gen"`, `tsConfigPath` the package `tsconfig.json`, `clean: true`, plugins:
   - `@hey-api/typescript` (`exportFromIndex: false`)
   - `@hey-api/sdk` (`instance: "OpencodeClient"`, `exportFromIndex: false`, `auth: false`, `paramsStructure: "flat"`)
   - `@hey-api/client-fetch` (`exportFromIndex: false`, `baseUrl: "http://localhost:4096"`)
4. If `src/v2/gen/types.gen.ts` matches `/export type SessionNext\w+1 =/`, throws `Error("Session history generated duplicate Session event variants")`.
5. Replaces `V2SessionHistoryData` query `limit` / `after` types `string` → `number` in `types.gen.ts`. If the replace is a no-op, throws `Error("Session history numeric query patch did not apply")`.
6. Same `string` → `number` replace on the “Get session history” block in `src/v2/gen/sdk.gen.ts`; no-op throws `Error("Session history numeric SDK patch did not apply")`.
7. In `src/v2/gen/client/types.gen.ts`, replaces `=> Promise<ServerSentEventsResult<TData, TError>>` with `=> Promise<ServerSentEventsResult<TData>>`. No-op throws `Error("SseFn patch did not apply; @hey-api/openapi-ts output may have changed (./src/v2/gen/client/types.gen.ts)")`.
8. `bun prettier --write src/gen` then `src/v2`; `rm -rf dist`; `bun tsc`; `rm openapi.json`.

Checked-in `packages/sdk/js/src/v2/gen/types.gen.ts` begins with `// This file is auto-generated by @hey-api/openapi-ts`. `src/gen/` is Prettier-formatted by this script and is not the `createClient` output path.

### UI `generate:tailwind`

`packages/ui/script/tailwind.ts` reads `packages/ui/script/colors.txt`. For each non-empty line it takes the substring before `:`, trims, drops the first two characters, and emits `--color-<name>: var(--<name>);` inside:

```
/* Generated by script/tailwind.ts */
/* Do not edit this file manually */

@theme {
  --color-*: initial;
  …
}
```

It writes that string (trimmed) to `packages/ui/src/styles/tailwind/colors.css`. Source of truth is `colors.txt` plus this script, not the CSS file.

### UI `generate:v2-oc2`

`packages/ui/script/build-oc2-v2-overrides.ts` reads `packages/ui/src/theme/themes/oc-2.json` and `packages/ui/src/v2/styles/theme.css`. For modes `light` (`:root`) and `dark` (`[data-color-scheme="dark"]`) it parses `--v2-*` declarations, drops keys `v2-avatar-fg` and `v2-font-family-sans`, trims values, and merges `{ ...V2_PRIMITIVES_DEFAULT, ...tokens }` into `theme.light.v2Overrides` / `theme.dark.v2Overrides`. It writes JSON with 2-space indent plus a trailing newline and logs `Updated oc-2.json v2Overrides`, the light token count, and `tokens per mode`. Theme JSON `v2Overrides` is generated; CSS tokens and `V2_PRIMITIVES_DEFAULT` are the inputs.

### Stats `db:generate` / `drizzle-kit generate`

`packages/stats/core/package.json` `db:generate` runs `drizzle-kit generate --config=drizzle.config.ts`. Config (`packages/stats/core/drizzle.config.ts`): `dialect: "mysql"`, `schema: ["./src/database/schema.ts"]`, `out: "./migrations/"`, `strict: true`, `verbose: true`, `dbCredentials.ssl.rejectUnauthorized: false`. `migrations/` is drizzle-kit output, not the schema source of truth.

## Error handling

Client generate failures from `write` / compile / emit are `GenerationError` (`reason` string; `message` equals `reason`) or Effect `PlatformError` from `FileSystem` (`packages/httpapi-codegen/src/index.ts`). Compile/emit reason strings are specified in [6.6 HttpApi codegen](06.6-httpapi-codegen.md). `write` reasons used when regenerating client trees:

| Condition | `GenerationError.reason` | Source |
|-----------|---------------------------|--------|
| Path not a single relative filename, or reserved `.httpapi-codegen.json` | `Unsafe output path: ${file.path}` | `write`, `isSafeOutputPath` |
| Case-insensitive duplicate file path | `Duplicate output path: ${file.path}` | `write` |
| Manifest decode failure or unsafe previous paths | `Invalid generated file manifest: ${manifest}` | `write` |
| Existing output is a symbolic link | `Unsafe output path: ${file.path}` | `write` |
| Prettier throws | `Failed to format ${file.path}: ${String(error)}` | `write` |

Unsafe paths: `path === ".httpapi-codegen.json"` or `isAbsolute(path)` or `path === "."` or `path === ".."` or `/[\\/]/.test(path)` (`isSafeOutputPath`).

SDK script throws the `Error` messages quoted under Legacy JS SDK. UI `generate:v2-oc2` throws `Error(\`Missing ${mode} OC-2 tokens\`)` when the CSS block for `light` or `dark` is missing (`readTokens`).

`check:generated` fails when `git diff --exit-code` sees changes under `src/generated` or `src/generated-effect` after generate (`packages/client/package.json`).
