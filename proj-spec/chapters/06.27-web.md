# 6.27 Web (docs and marketing site)

> **Spec chapter:** Shipped Astro/Starlight product docs site, marketing landing page, session share viewer, and plain-text doc export for OpenCode.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/web/` (`@opencode-ai/web`)

Retrospective chapter (C8): describes shipped behavior of the `@opencode-ai/web` workspace package. Astro `base` is `/docs`, so Starlight routes, share pages, and plain-text export all live under that prefix. The site serves product documentation, a localized marketing landing page at the docs index, shareable session pages at `/docs/s/{id}`, and plain-text markdown export at `/docs/{slug...}.md`.

## Behavior

### Site surfaces

| Surface | Route pattern | Behavior |
|---------|---------------|----------|
| Product docs | `/docs/...` (Astro `base`) | Starlight docs with configured sidebar, expressive code themes, last-updated metadata, edit link to GitHub `dev` branch |
| Marketing landing | Docs index | `Hero.astro` renders `Lander` when `slug === ""` (else default Starlight hero). `Lander.astro` owns install commands, feature list, screenshots, and GitHub/Discord footer |
| Session share | `/docs/s/{id}` | `src/pages/s/[id].astro` resolves under `base`; server fetches `${VITE_API_URL}/share_data?id={id}`; renders Solid `Share` island; sidebar hidden; robots meta `noindex, nofollow, noarchive, nosnippet` |
| Plain-text doc export | `GET /docs/{slug...}.md` | `src/pages/[...slug].md.ts` resolves under `base`; returns matching `docs` collection entry body as `text/plain; charset=utf-8` |

Sources: `packages/web/astro.config.mjs`, `packages/web/src/components/Hero.astro`, `packages/web/src/components/Lander.astro`, `packages/web/src/pages/s/[id].astro`, `packages/web/src/pages/[...slug].md.ts`.

### Internationalization

Starlight registers 18 locales: `root` (English, `en`) plus `ar`, `bs`, `da`, `de`, `es`, `fr`, `it`, `ja`, `ko`, `nb`, `pl`, `pt-br`, `ru`, `th`, `tr`, `zh-cn`, `zh-tw`. Arabic uses RTL; others LTR. Source: `packages/web/astro.config.mjs` `starlight.locales`.

Locale resolution helpers live in `packages/web/src/i18n/locales.ts`:

| Function | Behavior |
|----------|----------|
| `exactLocale(input)` | Maps normalized input through `localeAlias`; returns `null` when unknown |
| `matchLocale(input)` | Prefix/alias matching for `Accept-Language` and cookie values; Chinese variants map to `zh-cn` or `zh-tw`; `pt*` → `pt-br`; `no`/`nb`/`nn` → `nb` |

`docsLocale` in `locales.ts` also lists `uk`, but Starlight locale config does not register `uk`.

Middleware (`packages/web/src/middleware.ts` `onRequest`):

| Trigger | Response | `Set-Cookie` |
|---------|----------|--------------|
| `/docs/{segment}/...` where `{segment}` is a known locale slug (`docsAlias`) | 302 redirect to canonical path (`/docs/...` for `root`, else `/docs/{locale}/...`) | Yes — `redirect(..., alias.locale)` sets `oc_locale` (`Max-Age=31536000`, `SameSite=Lax`; value `en` for `root`) |
| `/docs` or `/docs/` with non-root locale from cookie or `Accept-Language` | 302 redirect to `/docs/{locale}/` | No — `redirect(ctx.url, \`/docs/${locale}/\`)` omits the locale argument |
| Other paths | Pass through | — |

Language select (`packages/web/src/components/LanguageSelect.astro`) writes the same `oc_locale` cookie on change.

Doc-page footer (`packages/web/src/components/Footer.astro`) shows edit link, GitHub issue link, Discord link, language select, copyright, and last-updated date for `template === "doc"` pages only.

Share-page header (`packages/web/src/components/Header.astro`) uses a simplified layout when pathname matches `/\/s(\/|$)/` (includes `/docs/s/...`); otherwise delegates to `toolbeam-docs-theme/overrides/Header.astro`.

### Open Graph images

`Head.astro` derives `base` from `import.meta.env.BASE_URL` ( `"docs"` when Astro `base` is `/docs` ), `slug` from the pathname, `isDocs` when `slug === base || slug.startsWith(\`${base}/\`)`, and `isShare` when `slug === \`${base}/s\`` or starts with that prefix.

| Page kind | OG image URL pattern |
|-----------|---------------------|
| Docs pages (including docs home) | When `isDocs`, `${socialCard}/opencode-docs/{encodedTitle}.png?desc={truncatedDesc}`. `encodedTitle` is built in `Head.astro` as `encodeURIComponent(Base64.encode(encodeURIComponent(title.substring(0, 700))))` — truncation is on the raw `title`, then `encodeURIComponent`, then `Base64.encode`, then `encodeURIComponent`. `truncatedDesc` is `encodeURIComponent(description.substring(0, 400))` when `description` is present. Docs home matches because `slug === base` (`"docs"`) makes `isDocs` true — not `${config.url}/social-share.png` |
| Unused initial value | `${config.url}/social-share.png` is assigned to `ogImage` before the `if (isDocs)` block but is overwritten whenever `isDocs` is true |
| Share page (`/docs/s/{id}`) | `${socialCard}/opencode-share/{encodedTitle}.png?model={modelParam}&version={version}&id={id}` built server-side in `s/[id].astro`. Share `encodedTitle` uses the same order: `encodeURIComponent(Base64.encode(encodeURIComponent(data.info.title.substring(0, 700))))`. `Head.astro` skips default OG/twitter image tags when `isShare` |

Sources: `packages/web/src/components/Head.astro`, `packages/web/src/pages/s/[id].astro`, `packages/web/config.mjs`.

### Share viewer (client)

When `Share` mounts (`packages/web/src/components/Share.tsx`):

| Step | Behavior |
|------|----------|
| Validate `id` | Missing `id` → connection status error `error_id_not_found` |
| Validate API URL | Empty `api` prop → error `error_api_url_not_found` |
| WebSocket | Connects to `{apiUrl as wss}/share_poll?id={id}`. `socket.onmessage` does `const [root, type, ...splits] = d.key.split("/")`; requires `root === "session"`. `type === "info"` updates session info. `type === "message"` uses `const [, messageID] = splits` so keys are `session/message/<ignored>/{messageID}` (four segments). `type === "part"` writes `d.content` onto `d.content.messageID` |
| V1 messages | Messages with `metadata` field are converted via `fromV1` before reconcile |
| Reconnect | On close, status `reconnecting` and retry after 2000 ms |
| Debug | URL query `debug=true` enables debug UI |
| Display | Aggregates assistant cost/tokens/models. `formatNumber` in `share/common.tsx` is `Intl.NumberFormat(normalizeLocale(locale)).format(value)` with no currency. `formatCurrency` uses `Intl.NumberFormat` with `style: "currency"`, `currency: "USD"`, and two fraction digits |

Initial session metadata is server-rendered from `/share_data`; live updates arrive over WebSocket.

### Robots policy

`public/robots.txt` allows `/` and disallows site-root paths `/s/` and `/share/`. Those rules are distinct from the deployed share route `/docs/s/{id}` under Astro `base`; the file does not list `/docs/s/`.

### Product naming in UI copy

English i18n strings describe the product as an AI coding agent (for example `app.head.titleSuffix`: "AI coding agent built for the terminal"). Source: `packages/web/src/content/i18n/en.json`. Consistency token `product` (OpenCode) applies at chapter-map level; this package's user-facing strings use "opencode" / "OpenCode" in site title and share copy.

## Error handling

| Condition | HTTP status / client behavior | Source |
|-----------|------------------------------|--------|
| Plain-text doc slug not in `docs` collection | 404; body from `share.not_found` i18n or fallback key string | `packages/web/src/pages/[...slug].md.ts` `GET` |
| Share `/share_data` response missing `info` | 404; `statusText` from `share.not_found` translation | `packages/web/src/pages/s/[id].astro` |
| Share missing `id` (client) | WebSocket not started; status error with `share.error_id_not_found` | `packages/web/src/components/Share.tsx` `onMount` |
| Share missing API URL (client) | Console error; status error with `share.error_api_url_not_found` | `packages/web/src/components/Share.tsx` `onMount` |
| WebSocket error | Status error with `share.error_connection_failed`; logs to console | `packages/web/src/components/Share.tsx` `socket.onerror` |
| WebSocket message parse failure | Logged; message ignored | `packages/web/src/components/Share.tsx` `socket.onmessage` catch |
| `docsAlias` locale redirect | 302 with `Location`; `Set-Cookie` for `oc_locale` | `packages/web/src/middleware.ts` `onRequest` → `redirect(..., alias.locale)` |
| `/docs` or `/docs/` locale redirect | 302 with `Location` to `/docs/{locale}/`; no `Set-Cookie` | `packages/web/src/middleware.ts` `onRequest` → `redirect(ctx.url, \`/docs/${locale}/\`)` |
