# 7.1 HTTP API

> **Spec chapter:** Public HTTP/`HttpApi` catalog **index** (interface companion). Canonical contract is 6.4; canonical `@opencode-ai/server` host is 6.5.
> **Parent:** [7 Interface](../07-interface.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/protocol/` (`@opencode-ai/protocol`), `packages/server/` (`@opencode-ai/server`) — cited here only as the served surface. This chapter does not re-home those packages.

This slice is the **public HTTP/`HttpApi` catalog index**. **Canonical homes:** Protocol groups, `makeApiFromGroup` order, declared errors, and OpenAPI identifiers — [6.4 Protocol](06.4-protocol.md). `@opencode-ai/server` `createRoutes`, auth, location, SSE, PTY, and emitted handler strings — [6.5 Server](06.5-server.md). `opencode` `listen` assembler `HttpApiApp.createRoutes` — [6.1 Agent CLI](06.1-agent-cli.md). Schema `EventManifest` inventories and event types — [8 Domain model](08-domain-model.md). This chapter is the HTTP home for `/api/event` and session event SSE unions (`EventManifest.ServerDefinitions`, `SessionEvent.Durable`, HTTP-synthetic `server.connected`); it is not a second copy of 8’s membership tables, 6.4 route tables, or 6.5 host literals. Generated client trees (`src/generated`, `src/generated-effect`) are not the behavioral source of truth (C5). This pass is retrospective of shipped code.

Runtime dependencies follow: Schema to Core and Protocol, then from Core and Protocol to Server. Client runtime code may depend on Schema and Protocol but never Core or Server; `sdk-next` composes Client, Core, and Server (`AGENTS.md`; `packages/protocol/package.json` depends on `@opencode-ai/schema`; `packages/server/package.json` depends on `@opencode-ai/core` and `@opencode-ai/protocol`).

After changing the public Protocol or Server `HttpApi`, `AGENTS.md` requires `bun run generate` from `packages/client` and forbids editing `src/generated` or `src/generated-effect` directly. Canonical home for workspace generate commands is 10.2. This chapter does **not** claim that `packages/protocol` or `packages/server` invoke `bun run generate`, `./packages/sdk/js/script/build.ts`, `generate:tailwind`, `generate:v2-oc2`, or `db:generate` / `drizzle-kit generate`.

## Behavior

This chapter does not add HTTP methods, paths, or host defaults beyond the index below.

### HttpApi composition

Group add order, permission/question middleware-before/after rules, and API-wide `Authorization` then `SchemaErrorMiddleware` are [6.4 Protocol](06.4-protocol.md) `#httpapi-group-assembly` and `#api-wide-middleware-slots` (`packages/protocol/src/api.ts` `makeApiFromGroup`). Server `handlers` merge order is [6.5 Server](06.5-server.md) `#handler-groups` (`packages/server/src/handlers.ts`).

### Endpoint catalog

Method, path, endpoint id, OpenAPI identifier, success/query shapes, and declared errors are the per-group tables in [6.4 Protocol](06.4-protocol.md). Handler wrapping, default page sizes, and Core calls are [6.5 Server](06.5-server.md).

PTY ticket query/header literals and `hasPtyConnectTicketURL` are [6.4 Protocol](06.4-protocol.md) `#pty`. Whether Server skips Authorization on that URL, empty 404/403 on `pty.connect`, SSE capacity/heartbeat, and Basic/`auth_token` behavior are [6.5 Server](06.5-server.md).

HTTP event SSE unions (payload types only; membership counts and `Event.define` algebra stay in [8 Domain model](08-domain-model.md)): `event.subscribe` (`GET /api/event`) is a union over `EventManifest.ServerDefinitions` plus a synthetic `{ type: "server.connected", data: {} }` variant when that type is absent (`packages/protocol/src/groups/event.ts`); the handler first frame is `{ type: "server.connected", data: {} }` ([6.5 Server](06.5-server.md) SSE). `session.events` (`GET /api/session/:sessionID/event`) streams `SessionEvent.Durable`. Schema `ServerEvent.Connected` on full `EventManifest.Definitions` is [8 Domain model](08-domain-model.md); it is not a second HTTP union here.
