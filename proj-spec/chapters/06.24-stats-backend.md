# 6.24 Stats backend

> **Spec chapter:** Lake ingest HTTP server, PlanetScale stats stores, R2 SQL aggregation, and read models for `@opencode-ai/stats-core` / `@opencode-ai/stats-server`.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/stats/core/` (`@opencode-ai/stats-core`), `packages/stats/server/` (`@opencode-ai/stats-server`)

This slice is the stats **backend**: Effect services and CLIs in `packages/stats/core`, plus the ingest HTTP process and hourly sync daemon in `packages/stats/server`. The stats SolidStart site is out of scope (see [6.23 Stats app](06.23-stats-app.md)). This pass is retrospective of shipped code.

`packages/stats/core/migrations/` is drizzle-kit output (`drizzle.config.ts` `out: "./migrations/"`). `packages/stats/core/sst-env.d.ts` and `packages/stats/server/sst-env.d.ts` are SST-generated stubs (`/* This file is auto-generated by SST. Do not edit. */`). Those trees are not the behavioral source of truth. Schema intent lives in `packages/stats/core/src/database/schema.ts`. SST resource shapes used at runtime are declared in `packages/stats/core/src/resource.d.ts` and `packages/stats/server/src/resource.d.ts`.

Workspace `generate` command names have a canonical home in [10.2 Generate](10.2-generate.md). This slice’s package scripts include `db:generate` (`drizzle-kit generate --config=drizzle.config.ts` in `packages/stats/core/package.json`). This chapter does **not** claim that `@opencode-ai/stats-core` or `@opencode-ai/stats-server` invoke `bun run generate` (packages/client), `./packages/sdk/js/script/build.ts`, `generate:tailwind`, or `generate:v2-oc2`.

## Behavior

### Lake ingest HTTP server

`packages/stats/server/src/server.ts` registers SIGTERM/SIGINT via `registerShutdownSignalHandlers`, then serves `Routes` with `HttpRouter.serve` (`disableLogger: true`) on Node `createServer`. `NodeRuntime.runMain` uses `{ disableErrorReporting: true }`.

| Method | Path | Response | Source |
|--------|------|----------|--------|
| GET | `/health` | HTTP 200 JSON `{ ok: true }` | `Routes` (`packages/stats/server/src/router.ts`) |
| GET | `/ready` | HTTP 200 `{ ok: true }` when not shutting down; HTTP 503 `{ ok: false }` when `isShuttingDown()` | `Routes`, `isShuttingDown` (`packages/stats/server/src/shutdown.ts`) |
| POST | `/` | Ingest (semaphore `withPermit`) | `ingest` (`packages/stats/server/src/router.ts`) |

POST `/` authorization: compare `Authorization` / `authorization` header bytes to `Bearer ${Resource.LakeIngestConfig.secret}` with equal-length `timingSafeEqual` (`isAuthorized`). Body is decoded as `{ events?: unknown }` (`IngestPayload`). Non-array `events` is treated as `[]`. Empty `events` returns HTTP 202 `{ ok: true, records: 0 }` without calling Firehose. Successful writes return HTTP 202 `{ ok: true, records: result.records }`.

### Firehose ingest

`Ingest.write` (`packages/stats/server/src/ingest.ts`):

- Empty `events` returns `{ records: 0 }`.
- Each object event needs `_datalake_key` matching `LAKE_TYPE` `/^([A-Za-z0-9_]+)\.([A-Za-z0-9_]+)$/`; capture groups become `database` and `table`.
- Non-objects, arrays, and unmatched keys are skipped for routing; unmatched object events increment `unsupported`. Any `unsupported > 0` fails with `IngestError` message `Unsupported lake event type` and `failed: counts.unsupported`.
- Routed records are JSON Firehose `Data` with `_datalake_key` stripped and `_lake_database`, `_lake_table`, `_lake_operation: "insert"` added (`toFirehoseRecord`).
- Batches of `MAX_FIREHOSE_BATCH_SIZE` go to `PutRecordBatchCommand` on `Resource.LakeIngestConfig.streamName`. Failed items retry with sleep `` `${250 * 2 ** (attempt - 1)} millis` `` until `MAX_FIREHOSE_ATTEMPTS`. Remaining failures yield `IngestError` message `Failed to ingest all lake records`.
- Transport send failure: `IngestError` message `Failed to write lake records to Firehose` with `failed: records.length`.

### Stats sync daemon

`packages/stats/server/src/stat-sync.ts` is a second `NodeRuntime.runMain` (not the `start` script). After optional `initialDelay`, it repeats `Schedule.fixed("1 hour")`.

`initialDelay`: `ModelStatRepo.lastSyncedAt()`; if a timestamp exists, sleep `min(SYNC_INTERVAL_MS - (now - lastSynced), SYNC_INTERVAL_MS)` when that value is `> 0`. Missing `lastSynced` skips delay. `lastSyncedAt` errors are swallowed (`Effect.succeed(null)`).

Each pass: first UTC calendar day (`toISOString().slice(0, 10)`) in process lifetime runs `syncStats({ full: true })`; on failure, logs and falls through to `syncStats({ full: false })`. Later passes the same day run incremental only. Pass failures are logged, not thrown.

`syncStats` (`packages/stats/core/src/stat-sync.ts`):

| Constant | Value | Role |
|---------|-------|------|
| `DATALAKE_INGESTION_LAG_MS` | `5 * 60_000` | `periodEnd` floors to minute after lag |
| `STATS_DATA_START_MS` | `new Date("2026-05-28T00:00:00.000Z").getTime()` | Lower bound for windows |
| `DISPLAY_WINDOW_MS` | `56 * 86_400_000` | Full-pass window |
| `WEEK_MS` | `7 * 86_400_000` | Full-pass ISO week clamp |
| `RETENTION_INCREMENTAL_LOOKBACK_MS` | `16 * 86_400_000` | Incremental retention scan |
| `INCREMENTAL_LOOKBACK_MS` | `2 * 3_600_000` | Incremental usage/geo start vs ISO week |

Full `periodStart` is `max(min(startOfIsoWeek(periodEnd) - WEEK_MS, periodEnd - DISPLAY_WINDOW_MS), STATS_DATA_START_MS)`. Incremental `periodStart` is `max(startOfIsoWeek(periodEnd - INCREMENTAL_LOOKBACK_MS), STATS_DATA_START_MS)`.

Queries: `buildStatsQueries` then `R2Sql.query` concurrency `4`. Rows with `dimension === "model"` / `"provider"` / `"geo"` or `"geo_model"` map through `toModelAggregate` / `toProviderAggregate` / `toGeoAggregate`. If `RetentionStatRepo.available()` is true, `buildRetentionQueries` uses full `periodStart` or `max(startOfUtcDay(periodEnd) - RETENTION_INCREMENTAL_LOOKBACK_MS, STATS_DATA_START_MS)` through `startOfUtcDay(periodEnd)`, then `replace` with `dataset: Resource.StatsSyncConfig.dataset` and `tier: "Go"`. Upserts then `deleteRetiredDimensions` on model/provider/geo. Result `{ ok: true, rows: modelRows.length, startedAt, periodStart, periodEnd }` (ISO strings).

### R2 SQL query construction and aggregation

`buildStatsQueries` (`packages/stats/core/src/domain/inference.ts`) defaults `namespace`/`table`/`dataset` from `Resource.R2Sql` and `Resource.StatsSyncConfig.dataset`. It emits two SQL strings per day and week period (`usage` and `geo` families), `LIMIT 10000`. Periods use UTC day / ISO week starts; last period `end` is `min(start + interval, periodEnd)`.

Usage SQL filters `event_type = 'generation.completed'`, `source IN ('inference', 'inference-legacy')`, exclusive handoff `LIVE_SOURCE_START` `"2026-08-11T10:57:48.186Z"` (`inference-legacy` `<` that instant XOR `inference` `>=`), `product = 'go'` **or** free-tier SQL, non-empty `model_requested`, and `__ingest_ts` / `started_at` bounds. Excludes `lower(model)` in `EXCLUDED_MODELS`. Free tier is `'Free'` when `lower(raw_tier) = 'free'` or model in `FREE_MODELS` (`gpt-5-nano`, `grok-code`, `big-pickle`) or `LIKE '%-free'` / `'%-free:global'`; else `'Go'`. Usage grouping sets: `(tier, provider, model)` and `(tier, provider)` with `approx_distinct(session)` / `approx_distinct(user_key)`. Geo family uses `0 AS sessions` / `0 AS unique_users` and grouping `(tier, country)` plus `(tier, provider, model, country)` with `'all'` provider/model when the model is rolled up.

`buildRetentionQueries` returns one query (or `[]` if no complete cohort/return weeks). Retention SQL requires `product = 'go'`, `user_totals.total_requests >= 10`, share `>= 0.8` on max-request model, `'Go' AS tier`, `LIMIT 10000`.

`R2Sql.query` POSTs `{ query }` to `https://api.sql.cloudflarestorage.com/api/v1/accounts/${Resource.R2Sql.accountId}/r2-sql/query/${Resource.R2Sql.bucket}` with `Authorization: Bearer ${Resource.R2SqlAuthToken.value}`. Null cells are dropped; remaining values `String(...)`. Row count `>= 10000` fails (no silent truncation).

### Normalization and ranking

Quoted identifiers from `packages/stats/core/src/domain/model-normalization.ts`:

| Symbol | Values |
|--------|--------|
| `EXCLUDED_MODELS` | `"alpha-gpt-next"` |
| `STEALTH_MODELS` | `"omen-alpha"` |
| `FREE_MODELS` | `"gpt-5-nano"`, `"grok-code"`, `"big-pickle"` |
| `RETIRED_STAT_PROVIDERS` | `"opencode"` |
| `MODEL_NAME_ALIASES` | `"deepseek-v4-flash-0731"` → `"deepseek-v4-flash"`; `"deepseek-v4-flash-dsv4-flash-final-rnaovd"` → `"deepseek-v4-flash"`; `"ox-alpha"` / `"x-preview-f"` → `"glm-5.3-flash"`; `"xiaomi/mimo-v2.5"` → `"mimo-v2.5"` |
| `RETIRED_STAT_MODELS` | `"big-pickle"` plus alias keys |
| `normalizeInferenceModel` | `toLowerCase().replace(/(-free|:free|:global)+$/, "")` |

`statModel`: after normalize, `big-pickle` uses last path segment of `providerModel`. `statProvider`: stealth → `"unknown"`; excluded models yield `undefined` from `modelAuthor` (dropped by `toModelAggregate`). `opencode` is retired and not kept as provider. `normalizeTier`: `paid`/`zen` → `"Zen"`; `go` → `"Go"`; `free` → `"Free"`; `enterprise` → `"Enterprise"`; `all` → `"all"`. `normalizeCountry`: length ≠ 2 → `"ZZ"`, else uppercased.

`toStatBaseRow` sets `client: "all"`, `source: "all"`. `synthesizeAllTierRows` adds combined `tier: "all"` rows. `combineRows` (`packages/stats/core/src/domain/stat.ts`) sets `p50_duration_ms`, `p95_duration_ms`, `p50_ttfb_ms`, and `p95_ttfb_ms` to `null` on merge. `share` returns `Number(((value ?? 0) / total).toFixed(6))` (a number) or `null` if `total <= 0`. ISO week id from `isoWeekId` (`YYYY-Wnn`).

### Persistence repositories

Tables (`packages/stats/core/src/database/schema.ts`): `model_stat`, `provider_stat`, `geo_stat`, `model_retention`. Period defaults: `dataset`/`tier`/`client`/`source` `"all"`. Geo `provider`/`model` default `"all"`; `country` `char(2)`. Unique indexes include `uniq_model_period`, `uniq_provider_period`, `uniq_country_period`, `uniq_model_retention_cohort`.

Repos (`ModelStatRepo`, `ProviderStatRepo`, `GeoStatRepo`, `RetentionStatRepo`) upsert in `UPSERT_CHUNK_SIZE` chunks with MySQL `onDuplicateKeyUpdate` via `inserted(column)` → `values(\`column\`)`. If the driver error text includes `Unknown column 'unique_users'`, upserts omit `unique_users` (`isMissingUniqueUsersColumn`, `omitUniqueUsers`). `deleteRetiredDimensions` deletes scoped rows whose `provider` is in `RETIRED_STAT_PROVIDERS` or `model` in `RETIRED_STAT_MODELS`. `RetentionStatRepo.replace` deletes by `cohort_date` ∈ scope, `dataset`, `tier`, then inserts. `available()` is false when `isMissingRetentionTable` (error text contains `model_retention` and `exist`).

`ProviderStatRepo.listByPeriod` / `GeoStatRepo.listByPeriod` default `dataset` `"zen"`, `tier`/`client`/`source` `"all"`. `ModelStatRepo.listDaily` filters `grain = "day"`, `client`/`source` `"all"`, `tier` in `DATA_SITE_TIERS` `["Go", "go", "Free", "free"]` (no dataset filter).

`Database.migrate` logs applying/complete; `drizzleMigrate` failure is `MigrationError` message `Failed to apply database migrations`; non-empty `result` fails `Failed to initialize database migrations: ${result.exitCode}`.

### Read models (`StatsHome`)

`getStatsHomeData`, `getStatsModelData`, `getStatsLabData`, `getStatsModelsComparisonData` (`packages/stats/core/src/domain/home.ts`) query PlanetScale with `DATABASE_URL ?? Resource.StatsDatabase.url`. Daily `model_stat` SQL requires `grain = 'day'`, `dataset = 'zen'`, `client = 'all'`, `source = 'all'`, `tier in` `DATA_SITE_TIERS`. Retention SQL: `dataset = 'zen' and tier = 'Go'`. Missing `model_retention` table returns `[]`. Query cache: `QUERY_CACHE_TTL_MS` `5 * 60 * 1000`, `QUERY_CACHE_MAX_ENTRIES` `256`.

`SITE_PRODUCT` is `"Go"`; product `"Go"` includes rows with `tier === "Go" || tier === "Free"`. `buildRetentionEntries`: last `RETENTION_COHORT_WEEKS` (`7`) distinct `cohortDate`s; rank only when `eligibleUserWeeks >= RETENTION_MIN_ELIGIBLE_USER_WEEKS` (`100`); home retention list drops `rank === null` and slices `RETENTION_MODEL_LIMIT` (`15`). Rate is `(retainedUserWeeks / eligibleUserWeeks) * 100` rounded to 1 decimal. Cost uses `DOLLARS_PER_MICROCENT` `1 / 100_000_000`. Country `AQ` is dropped. `leaderboardChange` (`packages/stats/core/src/domain/home.ts`) returns `0` when `current <= 0` (including previous `0` and current `0`); returns `null` when `previous <= 0` and `current > 0`, or when `current >= previous * LEADERBOARD_CHANGE_MIN_MULTIPLE` (`10`); otherwise `percentChange(current, previous)`. `modelSlug` lowercases and replaces non-alphanumeric runs with `-`.

### Athena query client

`Athena.query` (`packages/stats/core/src/athena.ts`) starts Athena in `Resource.InferenceEvent.region` / `workgroup` / `catalog` / `database`. Polls until `SUCCEEDED`. On `FAILED` or `CANCELLED`, `poll` fails with `AthenaQueryError` message `` Athena stats query ${status.State.toLowerCase()}: ${status.StateChangeReason ?? "unknown reason"} `` (`failed` / `cancelled`). Timeout fails with `AthenaQueryTimeoutError` message `` Athena stats query ${queryExecutionId} did not complete ``. Result pages skip the header row on the first page. `syncStats` does not call this client (it uses `R2Sql`).

### Honeycomb backfill CLI

`packages/stats/core/src/honeycomb-backfill.ts` when `import.meta.main`: `queries` or `import`, else usage. Usage text (`usage`):

```
bun src/honeycomb-backfill.ts queries [--tiers Go,Free,Paid] [--limit 1000]
bun src/honeycomb-backfill.ts import [--dry-run] [--upsert-chunk-size 100] [--database-url URL] --dir downloads
bun src/honeycomb-backfill.ts import [--dry-run] [--upsert-chunk-size 100] [--database-url URL] --model-day file.csv [--model-day more.csv] ...
```

`queries` default `--limit` `1000`, `--tiers` `Go,Free,Paid`. Import default `--dataset` `"zen"`, `--upsert-chunk-size` `100`. `--dry-run` skips DB; otherwise `DATABASE_URL` (flag or env) is required (`DATABASE_URL is required unless --dry-run is set`). Unknown `--only` / missing files / invalid flags call `fail` → `console.error` and `process.exit(1)`.

### Unique-users ensure CLI

`ensure-unique-users.ts` checks `information_schema` for `unique_users` on `geo_stat`, `model_stat`, `provider_stat`. All present: `console.log("unique_users columns complete")`, exit `0`. `--check` with missing: `console.log` of `` unique_users columns missing on ${missing.join(", ")} `` then `process.exit(1)` (stdout; this path does not call Honeycomb `fail`). Otherwise `ALTER TABLE \`${table}\` ADD \`unique_users\` bigint NOT NULL DEFAULT 0`.

## Error handling

| Condition | Result | Source |
|----------|--------|--------|
| Ingest missing/wrong bearer | HTTP 401 `{ ok: false, error: "Unauthorized" }` | `ingest`, `isAuthorized` (`packages/stats/server/src/router.ts`) |
| Ingest body not JSON matching `IngestPayload` | HTTP 400 `{ ok: false, error: "Invalid JSON body" }` | `schemaBodyJson` `onFailure` → `undefined` |
| `IngestError` (`_tag` `"IngestError"`) | HTTP 502 `{ ok: false, records: countRecords(events), failed: error.failed }` | `catchTag("IngestError")` |
| Ready during shutdown | HTTP 503 `{ ok: false }` | `/ready` |
| `DatabaseError` | `name` `"DatabaseError"`; message `Database operation failed` | `packages/stats/core/src/database.ts` |
| Migration apply throw | `MigrationError` message `Failed to apply database migrations` | `Database.migrate` |
| Migration `result` truthy | `MigrationError` `Failed to initialize database migrations: ${result.exitCode}` | `Database.migrate` |
| R2 fetch throw | `R2SqlQueryError` `Failed to run R2 SQL stats query` | `R2Sql.query` |
| R2 body read throw | `Failed to read R2 SQL stats response` | `R2Sql.query` |
| R2 JSON schema fail | `R2 SQL returned an invalid stats response` | `R2Sql.query` |
| R2 `!ok` / `!success` / no `result` | `R2 SQL stats query failed: ${JSON.stringify(decoded.errors)}` | `R2Sql.query` |
| R2 rows ≥ `10000` | `R2 SQL stats query reached the 10000 row limit` | `R2Sql.query` |
| Athena start/poll/results failures | `AthenaQueryError` messages `Failed to start Athena stats query`, `Athena did not return a query execution id`, `Failed to poll Athena stats query`, `Failed to read Athena stats results` | `packages/stats/core/src/athena.ts` |
| Athena `FAILED` / `CANCELLED` | `AthenaQueryError` message `` Athena stats query ${status.State.toLowerCase()}: ${status.StateChangeReason ?? "unknown reason"} `` | `poll` (`packages/stats/core/src/athena.ts`) |
| Athena poll timeout | `AthenaQueryTimeoutError` message `` Athena stats query ${queryExecutionId} did not complete `` | `poll` (`packages/stats/core/src/athena.ts`) |
| Stats read throw | `StatsDataError` name `"StatsDataError"` message `Failed to load stats data` | `packages/stats/core/src/domain/home.ts` |
| Honeycomb CLI `fail` | `console.error(message)` then `process.exit(1)` (stderr) | `fail` (`packages/stats/core/src/honeycomb-backfill.ts`) |
| Unique-users `--check` when columns missing | `console.log` of `` unique_users columns missing on ${missing.join(", ")} `` then `process.exit(1)` (stdout; not `fail`) | `packages/stats/core/src/ensure-unique-users.ts` |
