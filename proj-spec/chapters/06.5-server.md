### Route layer construction

### Auth configuration

`ServerAuth.Config` service id is `@opencode/ServerAuthConfig` (`packages/server/src/auth.ts`).

`ServerAuth.required(config)` is true when `Option.isSome(config.password)` and `config.password.value !== ""` (`required`).

`ServerAuth.authorized(credentials, config)` is true when password is `Option.some`, `credentials.username === config.username`, and `Redacted.value(credentials.password) === config.password.value` (`authorized`).

`ServerAuth.header(credentials?)` returns `undefined` when `credentials?.password ?? process.env.OPENCODE_SERVER_PASSWORD` is missing. Otherwise it returns `` `Basic ${Buffer.from(`${credentials?.username ?? process.env.OPENCODE_SERVER_USERNAME ?? "opencode"}:${password}`).toString("base64")}` `` (`header`). `headers` wraps that as `{ Authorization: authorization }` or `undefined`.

### CORS origin policy

`CorsConfig` is `Context.Reference` `@opencode/ServerCorsConfig` with `defaultValue: () => undefined` (`packages/server/src/cors.ts`). `routes.ts` does not provide a custom CORS layer; PTY handlers read `CorsConfig` (`packages/server/src/handlers/pty.ts`).

`isAllowedCorsOrigin(input, opts)`:

| Input | Result |
|-------|--------|
| falsy | `true` |
| starts with `"http://localhost:"` | `true` |
| starts with `"http://127.0.0.1:"` | `true` |
| `"oc://renderer"` prefix match via `startsWith("oc://renderer")` | `true` |
| `"tauri://localhost"`, `"http://tauri.localhost"`, or `"https://tauri.localhost"` | `true` |
| matches `/^https:\/\/([a-z0-9-]+\.)*opencode\.ai$/` | `true` |
| otherwise | `opts?.cors?.includes(input) ?? false` |

`isAllowedRequestOrigin(input, host, opts)` returns `true` for falsy `input`; otherwise `true` when `host` is set and `new URL(origin).host === host` (`sameHost`); otherwise `isAllowedCorsOrigin` (`cors.ts`). Invalid origin URLs make `sameHost` return `false`.

### Request location resolution

`location.layer` implements `LocationMiddleware` by reading `HttpServerRequest`, building `Location.Ref`, and `Effect.provide(locations.get(ref(request)))` (`packages/server/src/location.ts`). `LocationServiceMap.Service` is imported from `@opencode-ai/core/location-services` in this file (`location.ts`); `routes.ts` registers `LocationServiceMap.node` from `@opencode-ai/core/location-service-map`.

`ref(request)`:

| Field | Sources (first defined wins) |
|-------|-------------------------------|
| workspace | query `location[workspace]`, else header `x-opencode-workspace` |
| directory | query `location[directory]`, else header `x-opencode-directory` after `decode`, else `process.cwd()` |

`decode` uses `decodeURIComponent` and returns the original string on throw (`decode` in `location.ts`). Workspace id is `WorkspaceV2.ID.make` only when a workspace string is present. Directory is `AbsolutePath.make(directory)`.

`response(data)` yields `{ location: new Location.Info({ directory, workspaceID, project }), data }` from `Location.Service` (`response` in `location.ts`).

### Session location middleware

`sessionLocationLayer` reads `HttpRouter.RouteContext` `params.sessionID`, decodes with `Schema.decodeUnknownEffect(SessionV2.ID)`, loads `SessionTable.directory` and `SessionTable.workspace_id` via drizzle `eq(SessionTable.id, sessionID)`, then provides `locations.get(Location.Ref.make({ directory, workspaceID }))` (`packages/server/src/middleware/session-location.ts`). Decode failure maps to `InvalidRequestError` `{ message: "Invalid session ID", field: "sessionID" }`. Missing row maps to `SessionNotFoundError` with `message: \`Session not found: ${sessionID}\``. The `get()` Effect is piped `Effect.orDie`.

### Default PTY environment

`PtyEnvironment.Service` id is `@opencode/ServerPtyEnvironment`. The default `layer` implements `get` as `Effect.succeed({})` (`packages/server/src/pty-environment.ts`). `node` is `makeGlobalNode({ service: Service, layer, deps: [] })`.

### Message list cursor

`MessageHandler` (`server.message`, `session.messages`) (`packages/server/src/handlers/message.ts`):

- If both `ctx.query.cursor` and `ctx.query.order !== undefined`, fails `InvalidCursorError` `{ message: "Cursor cannot be combined with order" }`.
- Cursor decode: `JSON.parse(Buffer.from(input, "base64url").toString("utf8"))` then `Schema.decodeUnknownSync` of `{ id: SessionMessage.ID, order: "asc" \| "desc", direction: "previous" \| "next" }`. Throw → `InvalidCursorError` `{ message: "Invalid cursor" }`.
- `order` is `decoded?.order ?? ctx.query.order ?? "desc"`.
- `session.messages` with `limit: ctx.query.limit ?? 50` and optional `{ id, direction }` cursor.
- Encode: `Buffer.from(JSON.stringify({ id, order, direction })).toString("base64url")`.
- Returns `{ data, cursor: { previous, next } }` from first/last messages.

`Session.NotFoundError` and `Session.MessageDecodeError` map as in session context (not-found string / `UnknownError` with log `"failed to decode session message"`).

### Event subscribe

`EventHandler` handles raw `event.subscribe` (`packages/server/src/handlers/event.ts`):

1. Builds a connected event `{ id: EventV2.ID.create(), type: "server.connected", data: {} }`.
2. Acquires `EventV2.allBounded(events, 256)` then `Stream.make(connected).pipe(Stream.concat(live))`.
3. Maps each item through `Schema.encodeUnknownSync(OpenCodeEvent)` into SSE `{ _tag: "Event", event: "message", id: undefined, data: JSON.stringify(...) }`, then `Sse.encode()`.
4. Merges `Stream.tick("15 seconds")` mapped to `": heartbeat\n\n"` with `{ haltStrategy: "left" }`.
5. Returns `HttpServerResponse.stream(..., { contentType: "text/event-stream", headers: { "Cache-Control": "no-cache, no-transform", "X-Accel-Buffering": "no", "X-Content-Type-Options": "nosniff" } })`.

`PtyHandler` uses `Pty.Service`, `PtyTicket.Service`, `CorsConfig`, and `PtyEnvironment.Service` (`packages/server/src/handlers/pty.ts`). Ticket scope is `{ directory: location.directory as string, workspaceID: location.workspaceID }`.

| Endpoint name | Behavior |
|---------------|----------|
| `pty.list` | `response(pty.list())` |
| `pty.create` | `cwd` is `ctx.payload.cwd \|\| location.directory`. `env` is `{ ...ctx.payload.env, ...(yield* environment.get({ directory: location.directory, cwd })) }`. `args` copied to a new array when present. Wrapped in `response`. |
| `pty.get` / `pty.update` | `pty.get` / `pty.update`; `Pty.NotFoundError` → `PtyNotFoundError` `{ ptyID, message: \`PTY session not found: ${ctx.params.ptyID}\` }`; `response`. |
| `pty.remove` | `pty.remove` with same not-found mapping; NoContent. |
| `pty.connectToken` | Requires request header `PTY_CONNECT_TOKEN_HEADER` equal to `PTY_CONNECT_TOKEN_HEADER_VALUE` (imported from `@opencode-ai/protocol/groups/pty`) **and** `isAllowedRequestOrigin(origin, host, cors)`. Failure → `ForbiddenError` `{ message: "Invalid PTY connect token request" }`. Then `pty.get` (not-found mapping) and `response(tickets.issue({ ptyID, ...ticketScope }))`. |
| `pty.connect` (raw) | See below. |

`pty.connect` (`PtyHandler.connect`):

1. If `pty.get` yields `Pty.NotFoundError`, return `HttpServerResponse.empty({ status: 404 })`.
2. If query `PTY_CONNECT_TICKET_QUERY` is set: consume the ticket only when `isAllowedRequestOrigin` is true; otherwise treat as invalid. Invalid → `HttpServerResponse.empty({ status: 403 })`.
3. Query `cursor`: `Number(parsedCursor)` when present; kept only when `Number.isSafeInteger(cursorNumber) && cursorNumber >= -1`; else `undefined`.
4. Upgrade via `ctx.request.upgrade` (`Effect.orDie`).
5. `pty.attach` with `onData` / `onEnd` into an unbounded queue. `Pty.NotFoundError` / `Pty.ExitedError` send `Socket.CloseEvent(4404, "session not found")` or `(4404, "session exited")` via `closeAccepted` (1 second timeout) and then `HttpServerResponse.empty()` when `attachment` is missing.
6. Replay `PtyProtocol.chunks(attachment.replay)`, then `PtyProtocol.metaFrame(attachment.cursor)`, then `attachment.activate()`.
7. Race drain-to-socket vs `socket.runRaw` decoding with `PtyProtocol.decodeInput` (undefined decode is ignored). Ensures `attachment.detach()`. `onEnd` enqueues `Socket.CloseEvent(1000)`.

## Error handling

Protocol `httpApiStatus` values for tagged errors are [6.4 Protocol](06.4-protocol.md). This section records Server mapping and extra HTTP statuses.

### Unauthorized Basic

When `ServerAuth.required(config)` is false, `authorizationLayer` is a pass-through (`packages/server/src/middleware/authorization.ts`).

When required:

1. If `hasPtyConnectTicketURL(new URL(request.url, "http://localhost"))` (imported from `@opencode-ai/protocol/groups/pty`), skip credential checks (comment: browsers cannot set headers on WebSocket upgrades; the connect handler validates the ticket).
2. Else credentials come from query `auth_token` if present, else `Authorization` matching `/^Basic\s+(.+)$/i`, else empty `{ username: "", password: Redacted.make("") }`.
3. Base64 decode failure or missing `:` yields empty credentials (`decodeCredential`).
4. If `ServerAuth.authorized` is false: append pre-response header `www-authenticate` = `Basic realm="Secure Area"` and fail `UnauthorizedError({ message: "Authentication required" })`.

### Schema errors

`schemaErrorLayer` uses `HttpApiMiddleware.layerSchemaErrorTransform(SchemaErrorMiddleware, ...)` (`packages/server/src/middleware/schema-error.ts`). The transform truncates `error.cause.message` at 1024 characters, appending `` `... (${reason.length - REASON_LIMIT} more chars)` `` when longer, logs `"schema rejection"` with `{ kind, reason }`, then fails `InvalidRequestError({ message: reason, kind: error.kind })`.

### Unexpected server errors

Where handlers catch Snapshot or message-decode failures, they allocate `ref` as `` `err_${crypto.randomUUID().slice(0, 8)}` `` and fail `UnknownError({ message: "Unexpected server error. Check server logs for details.", ref })` (`session.ts`, `message.ts`).

### PTY connect statuses

`pty.connect` uses empty bodies: HTTP 404 when the PTY is missing before upgrade; HTTP 403 when a ticket is present but origin/ticket consume fails; empty 200-class empty response when attach fails after close-frame attempt (`HttpServerResponse.empty()` / `{ status: 404 }` / `{ status: 403 }` in `packages/server/src/handlers/pty.ts`).
