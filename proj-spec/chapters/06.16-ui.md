# 6.16 Shared UI kit

> **Spec chapter:** SolidJS component library, themes, i18n, and shared UI contexts consumed by product surfaces.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/ui/` (`@opencode-ai/ui`)

Retrospective chapter (C8). `@opencode-ai/ui` is a **multi-leaf package** in the workspace: it ships hand-authored SolidJS components, theme JSON, locale dictionaries, CSS, and several generated asset trees. Consumers import it as a library; it does not host a standalone product surface. Primary consumers are [6.14 TUI](06.14-tui.md), [6.17 Session UI](06.17-session-ui.md), [6.18 App](06.18-app.md), [6.20 Enterprise](06.20-enterprise.md), [6.21 Console app](06.21-console-app.md), and [6.23 Stats app](06.23-stats-app.md) (`findings/T1-chapter-map.md` §2, §6).

### Generated assets (C5)

Generated trees are **not** behavioral source of truth. Regenerate or rebuild from the cited generators; do not treat generated files as hand-authored contracts.

| Output | Generator | Regenerate |
|--------|-----------|------------|
| `src/styles/tailwind/colors.css` | `script/tailwind.ts` reads `script/colors.txt` and writes `@theme` color aliases | `bun run generate:tailwind` (`packages/ui/script/tailwind.ts` header comment) |
| `src/theme/themes/oc-2.json` `v2Overrides` | `script/build-oc2-v2-overrides.ts` reads `src/v2/styles/theme.css` and merges into OC-2 JSON | `bun run generate:v2-oc2` (`packages/ui/script/build-oc2-v2-overrides.ts`) |
| `src/components/file-icons/types.ts` and `sprite.svg` | `vite-plugin-icons-spritesheet`: `src/assets/icons/file-types` → `src/components/file-icons` | Vite dev/build (`packages/ui/vite.config.ts` `iconsSpritesheet[0]`) |
| `src/components/provider-icons/types.ts` and `sprite.svg` | `vite-plugin-icons-spritesheet`: `src/assets/icons/provider` → `src/components/provider-icons` | Vite dev/build (`packages/ui/vite.config.ts` `iconsSpritesheet[1]`) |
| Provider SVG assets under `src/assets/icons/provider/` | Custom Vite plugin fetches from models API on dev/build start | Vite dev/build; optional `OPENCODE_MODELS_URL` (default `https://models.opencode.ai`) (`packages/ui/vite.config.ts` `fetchProviderIcons`) |
| `dist/**/*.d.ts` | `tsc` declaration emit | `bun run build` |

**App icons (separate from Vite spritesheets):** `@opencode-ai/ui/icons/app` resolves to `src/components/app-icons/types.ts` (`packages/ui/package.json`). That file’s header marks it generated (`// This file is generated by icon spritesheet generator`), but `vite.config.ts` defines no `iconsSpritesheet` entry for `src/assets/icons/app/`. Source raster/SVG assets live under `src/assets/icons/app/` and are published via `package.json` `files` (`src/assets/icons/app/*`). The `app-icon` component imports those assets directly (`packages/ui/src/components/app-icon.tsx`).

## Behavior

### Component libraries

The package ships two parallel component sets:

| Set | Location | Import pattern | CSS |
|-----|----------|----------------|-----|
| v1 | `src/components/*.tsx` | `@opencode-ai/ui/<name>` | Co-located `*.css`, aggregated by `src/styles/index.css` |
| v2 | `src/v2/components/*-v2.tsx` (and shared `icon.tsx`, `wordmark-v2.tsx`, `tab-state-indicator.tsx`) | `@opencode-ai/ui/v2/<name>` | Co-located `*.css` plus `src/v2/styles/` |

v1 components include layout, input, feedback, and session-adjacent widgets (accordion, button, dialog, diff-changes, scroll-view, tabs, toast, …) under `src/components/` (file listing from `packages/ui/src/components/`).

v2 components mirror and extend that surface under `src/v2/components/`. A subset imports `@kobalte/core`: `accordion-v2`, `button-v2`, `checkbox-v2`, `dialog-v2`, `icon-button-v2`, `menu-v2`, `radio-v2`, `select-v2`, `switch-v2`, `tabs-v2`, and `tooltip-v2` (grep `packages/ui/src/v2/components/`). `toast-v2` renders via `solid-sonner` (`Toaster`, `toast` from `solid-sonner`); it imports only `isRTL` from `@kobalte/core/i18n` (`packages/ui/src/v2/components/toast-v2.tsx`). `avatar-v2`, `project-avatar-v2`, and `diff-changes-v2` are plain Solid components with no `@kobalte/core` import.

Storybook `*.stories.tsx` files colocate with components for dev documentation; they are excluded from the declaration build (`packages/ui/tsconfig.build.json` `exclude`).

### Styles

`src/styles/index.css` imports theme layers, base styles (including KaTeX CSS), and every v1 component stylesheet (`packages/ui/src/styles/index.css`).

`src/styles/tailwind/index.css` is the Tailwind v4 entry: it imports Tailwind theme/utilities, local utilities, and the v1 style bundle (`packages/ui/src/styles/tailwind/index.css`).

### Theme system

| API | Behavior | Source |
|-----|----------|--------|
| `ThemeProvider` / `useTheme` | Manages theme id, color scheme (`light` \| `dark` \| `system`), lazy-loads JSON themes from `src/theme/themes/*.json`, applies CSS variables to `:root`, persists choices in `localStorage` | `packages/ui/src/theme/context.tsx` |
| Default theme id | `"oc-2"`; legacy `"oc-1"` normalizes to `"oc-2"` | `packages/ui/src/theme/context.tsx` `normalize` |
| Storage keys | `opencode-theme-id`, `opencode-color-scheme`, `opencode-theme-css-light`, `opencode-theme-css-dark` | `packages/ui/src/theme/context.tsx` `STORAGE_KEYS` |
| `applyTheme`, `loadThemeFromUrl`, `getActiveTheme`, `removeTheme`, `setColorScheme` | Imperative DOM theme loader for non-Solid hosts | `packages/ui/src/theme/loader.ts` |
| Color math + defaults | `resolveTheme`, `resolveThemeV2`, scale generators, and named preset exports (`DEFAULT_THEMES`, individual theme constants) | `packages/ui/src/theme/index.ts`, `packages/ui/src/theme/default-themes.ts` |
| Theme JSON count | 37 preset files under `src/theme/themes/` | `packages/ui/src/theme/themes/` |

`ThemeProvider` listens for cross-tab `storage` events and `prefers-color-scheme` changes when scheme is `system` (`packages/ui/src/theme/context.tsx` `onStorage`, `onMedia`).

### Internationalization

| Item | Behavior | Source |
|------|----------|--------|
| Canonical key set | `UiI18nKey` derived from `src/i18n/en.ts` `dict` | `packages/ui/src/context/i18n.tsx` |
| Locale modules | One dictionary file per locale under `src/i18n/` (62 locales) | `packages/ui/src/i18n/` |
| `I18nProvider` / `useI18n` | Context exposes `locale`, optional `layoutLocale`, `t(key, params?)`, and `plural(key, count, params?)` | `packages/ui/src/context/i18n.tsx` |
| Plural keys | Fixed set `UI_PLURAL_KEYS`; lookup uses `Intl.PluralRules` per locale | `packages/ui/src/context/i18n.tsx` `UI_PLURAL_KEYS`, `pluralCategory` |

Package `AGENTS.md` requires contributors to route user-visible copy through i18n keys rather than hardcoded English in production components (`packages/ui/AGENTS.md` Localization).

### Markdown rendering

`createMarkdownParser(highlight)` builds a `Marked` instance that:

- Renders links with `class="external-link"`, `target="_blank"`, `rel="noopener noreferrer"` (`packages/ui/src/context/marked-parser.tsx` `renderer.link`).
- Supports inline `\(...\)` and block `$$\n...\n$$` KaTeX via custom extensions (`packages/ui/src/context/marked-parser.tsx` `katexExtension`).
- Delegates fenced code blocks to the supplied `highlight(code, language)` callback via `marked-shiki` (`packages/ui/src/context/marked-parser.tsx`).

`MarkedProvider` wires the parser to a shared Shiki highlighter (`preferredHighlighter: "shiki-wasm"`, theme `"OpenCode"`), loading bundled languages on demand (`packages/ui/src/context/marked.tsx`).

### Scroll view helpers

`scroll-view.tsx` exports keyboard scroll routing helpers used by the scroll-view component:

| Function | Behavior | Source |
|----------|----------|--------|
| `scrollKey` | Maps navigation keys (arrows, PageUp/Down, Home/End, Space, Shift+Space) to scroll directions; Space → `page-down`, Shift+Space → `page-up`; returns `undefined` when `altKey`, `ctrlKey`, or `metaKey` is set, or when `shiftKey` is set on keys other than Space | `packages/ui/src/components/scroll-view.tsx` `scrollKey`, `scroll-view.test.ts` |
| `canScrollKey` | Returns whether the element can still scroll in the requested direction | `packages/ui/src/components/scroll-view.test.ts` |
| `scrollTopFromThumbPointer` | Computes thumb-drag scroll position; keeps downward thumb movement monotonic when content height changes | `packages/ui/src/components/scroll-view.test.ts` |

## Error handling

| Condition | Behavior | Source |
|-----------|----------|--------|
| `useDialog` outside `DialogProvider` or without Solid owner | Throws `Error("useDialog must be used within a DialogProvider")` | `packages/ui/src/context/dialog.tsx` `useDialog` |
| `SegmentedControlItemV2` outside `SegmentedControlV2` | Throws `Error("SegmentedControlItemV2 must be used inside SegmentedControlV2")` | `packages/ui/src/v2/components/segmented-control-v2.tsx` |
| Theme variant defines both `palette` and `seeds`, or neither | Throws `Error` from `resolveThemeVariant` | `packages/ui/src/theme/resolve.ts` |
| Missing grey primitive when resolving v2 foreground | Throws `Error` | `packages/ui/src/theme/v2/foreground.ts` |
| `loadThemeFromUrl` non-OK response | Throws `Error` including status text | `packages/ui/src/theme/loader.ts` `loadThemeFromUrl` |
| KaTeX render failure | `throwOnError: false` — invalid math does not abort parse | `packages/ui/src/context/marked-parser.tsx` `renderKatexToken` |
| Missing i18n key (fallback context) | Renders `String(key)` | `packages/ui/src/context/i18n.tsx` `fallback.t` |
| Missing template param | Substitutes empty string | `packages/ui/src/context/i18n.tsx` `resolveTemplate` |
| Unknown theme id in `setTheme` | `console.warn` and no-op | `packages/ui/src/theme/context.tsx` `setTheme` |
| `localStorage` unavailable or quota errors | Read/write/remove fail silently (return `null` or no-op) | `packages/ui/src/theme/context.tsx` `read`, `write`, `drop` |
