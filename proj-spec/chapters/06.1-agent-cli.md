# 6.1 Agent CLI

> **Spec chapter:** Primary user CLI `opencode` (`packages/opencode`) and workspace `@opencode-ai/script` (T1 cluster: one concern).
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/opencode/` (`opencode`), `packages/script/` (`@opencode-ai/script`)

This slice is the **agent CLI**: the `opencode` yargs process (`packages/opencode/src/index.ts`), its npm `bin` shim, and the `@opencode-ai/script` helpers used for channel/version/team at release time. Alternate CLI `lildax` is out of scope (see [6.15](06.15-cli.md) when present). HTTP server internals, TUI widget behavior, plugin/tool/LLM/domain schemas, and install packaging are linked, not respecified. This pass is retrospective of shipped code.

Workspace `generate` command names have a canonical home in [10.2 Generate](10.2-generate.md). This slice’s `packages/opencode/package.json` scripts do **not** invoke `bun run generate` (packages/client), `./packages/sdk/js/script/build.ts`, `generate:tailwind`, `generate:v2-oc2`, or `db:generate` / `drizzle-kit generate`. The CLI subcommand `opencode generate` prints an OpenAPI document to stdout; it is not those workspace generators.

Published bins in this workspace include `opencode` (this slice) and `lildax` (not this package). `packages/opencode/package.json` `"bin"` maps `opencode` → `./bin/opencode`.

Runtime dependency direction (root `AGENTS.md`): Schema to Core and Protocol, then from Core and Protocol to Server; Client runtime may depend on Schema and Protocol but never Core or Server; sdk-next composes Client, Core, and Server. `packages/opencode/package.json` lists runtime `dependencies` including `@opencode-ai/schema`, `@opencode-ai/protocol`, `@opencode-ai/server`, `@opencode-ai/sdk`, `@opencode-ai/plugin`, `@opencode-ai/llm`, `@opencode-ai/codemode`, `@opencode-ai/tui`, and `@opencode-ai/script`. `@opencode-ai/core` is listed under `devDependencies` only (`workspace:*`). T1 map: 6.1 depends 6.4, 6.5, 6.8, 6.10, 6.12, 6.13, 6.14, 8; consumed by 7.3, 10.1.

## Behavior

### Yargs process entry

`packages/opencode/src/index.ts` builds `yargs(hideBin(process.argv))` and registers commands in this order: `acp`, `mcp`, `TuiThreadCommand` (`$0`), `attach`, `run`, `generate`, `debug`, `console`, `providers`, `agent`, `upgrade`, `uninstall`, `serve`, `web`, `models`, `stats`, `export`, `import`, `github`, `pr`, `session`, `plugin`, `db`.

If argv includes `-h` or `--help`, parse uses a callback that writes help via `show()`. `show` writes `UI.logo()` plus two `EOL`s to stderr then the help text, unless the trimmed help already starts with `"opencode "`. Non-help parse is `await cli.parse()`. After parse, `finally` always `process.exit()`.

`.fail` (`packages/opencode/src/index.ts`): for messages starting with `"Unknown argument"`, `"Not enough non-option arguments"`, or `"Invalid values:"`, if `err` is set it `throw err` immediately (no `showHelp`). If `err` is unset it `cli.showHelp(show)` then falls through. After that branch (and for all other messages), if `err` is set it `throw err`; otherwise `process.exit(1)`. Errors thrown from handlers are caught below (see Error handling).

Help-text snapshots enumerate top-level argv names `acp`, `mcp`, `attach`, `run`, `debug`, `providers`, `agent`, `upgrade`, `uninstall`, `serve`, `web`, `models`, `stats`, `export`, `import`, `github`, `pr`, `session`, `plugin`, `db` plus listed subcommands. Default `$0` help and yargs `completion` are excluded from that snapshot list. Top-level `--help` is asserted to contain `--mini` and not `--thinking`, `--variant`, or `--demo` (`packages/opencode/test/cli/help/help-snapshots.test.ts`).

### Default TUI and mini mode

`TuiThreadCommand` is `command: "$0 [project]"` with describe `"start opencode tui"` (`packages/opencode/src/cli/cmd/tui.ts`). Positional `project` is `"path to start opencode in"`. `resolveThreadDirectory(project, envPWD, cwd)` resolves `project` against `Filesystem.resolve(envPWD ?? cwd)` when set; otherwise `Filesystem.resolve(cwd)`.

`--model` alias `-m` (`provider/model`). `--continue` alias `-c`. `--session` alias `-s`. `--fork` describe: `"fork the session when continuing (use with --continue or --session)"`. `--auto` default `false`. Hidden `--yolo` and `--dangerously-skip-permissions` default `false`. `--mini` default `false` (`"start the minimal interactive interface"`). `--replay` hidden; `--no-replay` described; `--replay-limit` number; `--demo` hidden.

If `args.replay === true`, `UI.error("--replay is not supported; replay is enabled by default")` and exit code 1. `noReplay` is `args.replay === false || args.noReplay === true`.

With `--mini`: any of `--port`, `--hostname`, `--mdns`, `--no-mdns`, `--mdns-domain`, `--cors` present on `process.argv` fails with `` `${network} cannot be used with --mini` ``. Otherwise `runMini({ directory: resolveThreadDirectory(args.project), ... })` including `fork: args.fork` (no `--fork requires --continue or --session` check on this path).

Without `--mini`: `--no-replay`, `--replay-limit`, or `--demo` fail with `` `${unsupported} requires --mini` ``. Then, if `args.fork` and not `--continue` and not `--session`, `UI.error("--fork requires --continue or --session")` and `process.exitCode = 1`. Then `process.chdir` to `resolveThreadDirectory(args.project)` or `UI.error("Failed to change directory to " + next)`. A `Worker` loads `OPENCODE_WORKER_PATH` if defined, else `./cli/tui/worker.js` next to the compiled URL if it exists, else `../tui/worker.ts`. SIGUSR2 calls worker `reload`. Shutdown: `client.call("shutdown")` with 5s timeout then `worker.terminate()`. Prompt is CLI `--prompt` plus piped stdin (`input()`). If `--port`, `--hostname`, or resolved `mdns === true`, TUI uses worker `server` URL plus `ServerAuth.headers()`; else in-process fetch/events to `"http://opencode.internal"`. TUI host implementation lives in [6.14 TUI](06.14-tui.md).

`AttachCommand` (`attach <url>`, describe `"attach to a running opencode server"`) shares `--mini` / replay rules. `--replay === true` uses the same unsupported message. Mini attach calls `runMini` with `attach: args.url` and `fork: args.fork` (no `--fork requires --continue or --session` check). Without `--mini`, `--no-replay` / `--replay-limit` require `--mini`; then the same `--fork requires --continue or --session` check as non-mini `$0`. `--dir` `chdir`s when possible; missing local dir keeps the string for remote attach. Non-mini attach validates session then `cli/tui/layer` `run`.

`runMini` invokes `RunCommand.handler` with `$0: "opencode"`, `_: ["mini"]`, `mini: true`, `format: "default"`, `replay: input.replay ?? true` (`run.ts`).

### Network listen options

`withNetworkOptions` adds `--port`, `--hostname`, `--mdns`, `--mdns-domain`, `--cors` (`packages/opencode/src/cli/network.ts`). `resolveNetworkOptionsNoConfig(args, config?)`: CLI flags win when present on argv before `--`. Else `config?.server` `port` / `hostname` / `mdns` / `mdnsDomain` / `cors`. If mdns is on and `config?.server?.hostname` is unset, hostname becomes `"0.0.0.0"`. CORS concatenates config then argv.

Default TUI (`packages/opencode/src/cli/cmd/tui.ts`) calls `resolveNetworkOptionsNoConfig(args)` with **no** config, so `config.server` listen fields are not applied on that path. `serve` / `web` / `acp` call `resolveNetworkOptions(args)`, which loads global config then `resolveNetworkOptionsNoConfig(args, config)`. `serve` / `web` call `Server.listen(opts)` ([6.5 Server](06.5-server.md)). If `Flag.OPENCODE_SERVER_PASSWORD` is unset, `serve` logs `"Warning: OPENCODE_SERVER_PASSWORD is not set; server is unsecured."`; `web` prints the same text with UI warning styling (`"!  OPENCODE_SERVER_PASSWORD is not set; server is unsecured."`). `serve` then prints `` `opencode server listening on http://${server.hostname}:${server.port}` `` and `Effect.never`. `web` prints logo and URLs; hostname `0.0.0.0` opens `http://localhost:${server.port}` and lists non-internal IPv4 addresses that do not start with `"172."`.

`acp` sets `OPENCODE_CLIENT=acp`, listens, builds `@opencode-ai/sdk/v2` `createOpencodeClient` against `http://${hostname}:${port}` with `ServerAuth.headers()`, and runs Agent Client Protocol over stdin/stdout NDJSON ([6.8 SDK](06.8-sdk.md)).

### `opencode run`

`RunCommand` describe `"run opencode with a message"`. `instance: (args) => !args.attach`. `directory` is resolved `--dir` when not attaching.

Message is positional `message..` plus `--` remainder. `--command` is `"the command to run, use message for args"`. `--share`, `--file`/`-f` array, `--title`, `--attach`, `--password`/`-p`, `--username`/`-u` (username describe: defaults to `OPENCODE_SERVER_USERNAME` or `'opencode'`), `--dir`, `--port` (local server; random if omitted), `--variant`, `--thinking`, hidden `--mini`, `--interactive`/`-i`, `--auto` plus hidden `--yolo` / `--dangerously-skip-permissions`.

Handler (`Cli.run`): `auto` is `--auto` or `--yolo` or `--dangerously-skip-permissions`. `thinking` defaults `true` when `args.mini`, else `false`. Interactive (`args.mini`) plus `--command` → `"--mini cannot be used with --command"`. Interactive when `args._?.[0] !== "mini"` → `"--mini must be used without the run subcommand"`. Interactive without TTY stdout → `"--mini requires a TTY stdout"`. Missing controlling terminal for mini input → `INTERACTIVE_INPUT_ERROR` `"--mini requires a controlling terminal for input"` (`runtime.stdin.ts`; Windows `CONIN$`, else `/dev/tty`).

Non-interactive default streams a prompt and exits when idle. `--format json` streams raw JSON events. `--mini` / `runMini` is direct interactive split-footer mode (local or `--attach`). In-process vs attach uses [6.5](06.5-server.md) and [6.8](06.8-sdk.md).

### Script package

`packages/script/src/index.ts` loads `rootPkg` from `path.resolve(import.meta.dir, "../../../package.json")` and requires `packageManager` (split on `"@"` for bun version). Range is `` `^${expectedBunVersion}` ``. Mismatch throws `` `This script requires bun@${expectedBunVersionRange}, but you are using bun@${process.versions.bun}` ``. Missing `packageManager` throws `"packageManager field not found in root package.json"`.

`Script.channel`: `OPENCODE_CHANNEL`, else `"latest"` if `OPENCODE_BUMP` or `OPENCODE_VERSION` not starting with `"0.0.0-"`, else `git branch --show-current` trimmed. `Script.preview` is `CHANNEL !== "latest"`. `Script.version`: `OPENCODE_VERSION` if set; else preview `` `0.0.0-${CHANNEL}-${ISO slice}` `` (ISO `slice(0, 16)` with `[-:T]` stripped); else npm `https://registry.npmjs.org/opencode-ai/latest` `.version` then bump `major` / `minor` / default patch via `OPENCODE_BUMP`. `Script.release` is `!!OPENCODE_RELEASE`. `Script.team` is lines from `../../../.github/TEAM_MEMBERS` (trim, drop empty and `#` comments) plus `["actions-user", "opencode", "opencode-agent[bot]"]`. Module logs `` `opencode script` `` plus `JSON.stringify(Script, null, 2)`. Root `package.json` / `.github/TEAM_MEMBERS` are outside this slice’s allowed citation set (OQ-6.1-9).

### Native bin launcher

`packages/opencode/bin/opencode` is `#!/usr/bin/env node`. Forwards argv and `SIGINT`/`SIGTERM`/`SIGHUP` to a child. Target: `OPENCODE_BIN_PATH`, else `path.join(scriptDir, ".opencode")` if that file exists, else walk parents for `node_modules/<name>/bin/opencode` (`opencode.exe` on windows). Platform map: `darwin`/`linux`/`win32`→`windows`; else `os.platform()`. Arch map: `x64`/`arm64`/`arm`; else `os.arch()`. Package names prefer AVX2 vs `-baseline` and linux musl (`/etc/alpine-release` or `ldd --version` containing `"musl"`). If unresolved: stderr `"It seems that your package manager failed to install the right version of the opencode CLI for your platform. You can try manually installing "` plus quoted candidate names joined with `" or "`, then `process.exit(1)`. Child `error` prints `error.message` and exits 1. Child exit with signal re-raises it; else `process.exit(code ?? 0)`.

## Error handling

Top-level catch (`packages/opencode/src/index.ts`): `const formatted = FormatError(e)` then `if (formatted) UI.error(formatted)`. Empty string (cancel) is falsy, so `UI.error` is skipped. The unexpected path runs only when `formatted === undefined`: `UI.error("Unexpected error" + EOL)` and stderr `errorMessage(e)`. `process.exitCode = 1` is always set. `UI.error` prefixes `"Error: "` (strips a leading `"Error: "` from the message) with danger styling (`packages/opencode/src/cli/ui.ts`).

`CliError` (`effect-cmd.ts`): `fail(message, exitCode = 1)` → tagged `"CliError"`. `FormatError` copies `exitCode` onto `process.exitCode` and returns `message`.

| Tag / name | Printed text (from `FormatError`) |
|------------|-----------------------------------|
| `CliError` | `message` |
| `MCPFailed` | `` `MCP server "${name}" failed. Note, opencode does not support MCP authentication yet.` `` |
| `AccountServiceError` / `AccountTransportError` | `message` |
| `ProviderModelNotFoundError` | `` `Model not found: ${providerID}/${modelID}` ``; optional `"Did you mean: "` + suggestions; `` `Try: \`opencode models\` to list available models` ``; `` `Or check your config (opencode.json) provider/model names` `` |
| `ProviderInitError` | `` `Failed to initialize provider "${providerID}". Check credentials and configuration.` `` |
| `ConfigJsonError` | `` `Config file at ${path} is not valid JSON(C)` `` plus optional `: ${message}` |
| `ConfigDirectoryTypoError` | `` `Directory "${dir}" in ${path} is not valid. Rename the directory to "${suggestion}" or remove it. This is a common typo.` `` |
| `ConfigFrontmatterError` | `message` |
| `ConfigRemoteAuthError` | login-page lines; optional `` `Run \`opencode auth login ${url}\` to re-authenticate.` `` |
| `ConfigInvalidError` | `` `Configuration is invalid` `` plus path/message; issues as `"↳ " + message + " " + path.join(".")` |
| `UICancelledError` | `""` |

HTTP `cause.body` is formatted recursively. Unrecognized errors return `undefined` (unexpected-error path).

`models` unknown provider: `fail(\`Provider not found: ${args.provider}\`)`. `session delete` missing session: `fail(\`Session not found: ${args.sessionID}\`)`. `pr` without git: `"Could not find git repository. Please run this command from a git repository."`; failed `gh pr checkout`: `` `Failed to checkout PR #${prNumber}. Make sure you have gh CLI installed and authenticated.` ``. Plugin missing module: `UI.error("module is required")` and `process.exitCode = 1`.

`upgrade` method `"unknown"`: `` `opencode is installed to ${process.execPath} and may be managed by a package manager` ``. Choco elevation: `"Please run the terminal as Administrator and try again"` when stderr includes `"not running from an elevated command shell"`.
