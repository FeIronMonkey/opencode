# 6.20 Enterprise

> **Spec chapter:** SolidStart enterprise app for session share HTTP APIs, object storage, and the public share viewer.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/enterprise/` (`@opencode-ai/enterprise`)

This slice is the **Enterprise app**: a SolidStart site that stores share metadata and session snapshots in S3-compatible object storage, exposes `/api/share*` (plus a support delete path), and renders `/share/:shareID` using [6.16 Shared UI kit](06.16-ui.md) and [6.17 Session UI](06.17-session-ui.md). Runtime helpers come from [6.2 Core](06.2-core.md) (`iife`, `lazy`, `Binary`, `NamedError`). This pass is retrospective of shipped code (C8).

`packages/enterprise/sst-env.d.ts` is SST-generated (`/* This file is auto-generated by SST. Do not edit. */`) and is not the behavioral source of truth for runtime bindings.

`Share.Data` payloads use `z.custom` wrappers around types imported from `@opencode-ai/sdk/v2` (`Session`, `Message`, `Part`, `SnapshotFileDiff`, `Model`). Those type contracts are not specified here; see OQ-6.20-001.

### Object storage

`Storage` (`packages/enterprise/src/core/storage.ts`) is a lazy singleton (`lazy` from `@opencode-ai/core/util/lazy`). `OPENCODE_STORAGE_ADAPTER` selects the backend:

| `OPENCODE_STORAGE_ADAPTER` | Endpoint | Required env |
|----------------------------|----------|--------------|
| `"s3"` | `` `https://s3.${region}.amazonaws.com` `` | `OPENCODE_STORAGE_BUCKET`, `OPENCODE_STORAGE_ACCESS_KEY_ID`, `OPENCODE_STORAGE_SECRET_ACCESS_KEY`; `OPENCODE_STORAGE_REGION` default `"us-east-1"` |
| `"r2"` | `` `https://${accountId}.r2.cloudflarestorage.com` `` | `OPENCODE_STORAGE_ACCOUNT_ID`, `OPENCODE_STORAGE_BUCKET`, `OPENCODE_STORAGE_ACCESS_KEY_ID`, `OPENCODE_STORAGE_SECRET_ACCESS_KEY` |
| any other / unset | — | Throws `Error` message `No storage adapter configured` |

Logical keys are `string[]`. On the wire they become `key.join("/") + ".json"` (`resolve`). `read` JSON-parses the object body or returns `undefined` when the adapter returns `undefined` (HTTP 404). `write` PUT-s `JSON.stringify(value)` with `Content-Type: application/json`. `list` maps object keys by stripping a trailing `.json` and `split("/")`.

S3 list uses `list-type=2` and `prefix`. Optional `max-keys` from `limit`. Optional `start-after` is `prefix + after + ".json"`. Optional `before` keeps keys strictly less than `prefix + before + ".json"`. List XML keys are taken from `/<Key>([^<]+)<\/Key>/g`.

`Storage.update` reads a key, throws `Error` message `Not found` if missing, mutates the draft, writes it back. No caller in this package uses `update`.

## Behavior

### Share records

`Share` (`packages/enterprise/src/core/share.ts`) stores `Share.Info`: `{ id, secret, sessionID }` at `["share", id]`.

`Share.Data` is a Zod discriminated union on `type`: `"session"`, `"message"`, `"part"`, `"session_diff"`, `"model"`. Merge identity (`key`):

| `type` | Merge key |
|--------|-----------|
| `session` | `"session"` |
| `message` | `` `message/${item.data.id}` `` |
| `part` | `` `part/${item.data.messageID}/${item.data.id}` `` |
| `session_diff` | `"session_diff"` |
| `model` | `"model"` |

`merge` last-write-wins on those keys, then sorts keys with `localeCompare` and returns the values (`merge` in `packages/enterprise/src/core/share.ts`).

`Share.create({ sessionID })`: `isTest` is `process.env.NODE_ENV === "test"` **or** `sessionID.startsWith("test_")`. `id` is `(isTest ? "test_" : "") + sessionID.slice(-8)`. `secret` is `crypto.randomUUID()`. If `get(id)` is already defined, throws `Share.Errors.AlreadyExists`. Otherwise writes `["share", id]` and an empty snapshot `["share_snapshot", id]` as `{ data: [] }`.

`Share.get(id)` reads `["share", id]`.

`Share.remove({ id, secret })`: missing share → `NotFound`; `share.secret !== secret` → `InvalidSecret`. Then removes `["share", id]` and every listed key under prefixes `share_snapshot`, `share_compaction`, `share_event`, and `share_data` for that id.

`Share.removeAdmin({ id })`: missing share → `NotFound`; otherwise `remove` with the stored secret.

`Share.sync({ share: { id, secret }, data })`: same NotFound / InvalidSecret checks; snapshot is `readSnapshot` or `legacy`; then `writeSnapshot(id, merge(existing, data))`.

`Share.data(shareID)` returns `readSnapshot` or `legacy`.

`legacy`: reads `["share_compaction", shareID]` (default `{ data: [], event: undefined }`) and lists `["share_event", shareID]` with `before: compaction.event`, then `toReversed()`. Empty event list: if `compaction.data.length > 0`, writes that snapshot; returns `compaction.data`. Non-empty: listed keys are `Storage.read<Data[]>(event)` (stored JSON **is** `Share.Data[]`); those reads are `flatMap((item) => item ?? [])` and merged with `compaction.data`. Writes compaction `{ event: list.at(-1)?.at(-1), data: next }` and the snapshot, returns `next`.

`Share.syncOld` writes per-item keys under `["share_data", shareId, …]` (`session`, `message/{id}`, `part/{messageID}/{id}`, `session_diff`, `model`). No HTTP route in this package calls `syncOld`.

### HTTP API

`packages/enterprise/src/routes/api/[...path].ts` mounts a Hono app at `basePath("/api")` with `cors()`. SolidStart `GET` / `POST` / `PUT` / `DELETE` all `app.fetch(event.request)`.

OpenAPI handler: `GET /api/doc`. Documentation `info.title` is `Opencode Enterprise API`, `version` `1.0.0`, `description` `Opencode Enterprise API endpoints`, `openapi` `3.1.1`.

| Method | Path | Body | Success body | Source |
|--------|------|------|--------------|--------|
| POST | `/api/share` | `{ sessionID: string }` | `{ id, secret, url }` | `share.create` |
| POST | `/api/share/:shareID/sync` | `{ secret: string, data: Share.Data[] }` | `{}` | `share.sync` |
| GET | `/api/share/:shareID/data` | — | JSON array of `Share.Data` | `share.data` |
| DELETE | `/api/share/:shareID` | `{ secret: string }` | `{}` | `share.remove` |
| DELETE | `/api/support/actions/remove-share` | `{ shareID: string }` (min length 1) after auth | `{ success: true, message: "Share removed" }` | handler below |

Create URL: `` `${protocol}://${host}/share/${share.id}` `` where `protocol` is header `x-forwarded-proto` or `x-forwarded-protocol` or `"https"`, and `host` is `x-forwarded-host` or `host`.

GET data sets `Cache-Control` to `public, max-age=30, s-maxage=300, stale-while-revalidate=86400`.

Support delete: `Authorization` compared with `timingSafeEqual` to `Bearer ${SUPPORT_API_KEY.value}` (equal-length buffers only). `SUPPORT_API_KEY` is read from `Resource` (`sst`) as `{ value: string }`. See OQ-6.20-002.

### Share viewer

Route `packages/enterprise/src/routes/share/[shareID].tsx`. Layout wrapper `packages/enterprise/src/routes/share.tsx` renders `props.children`.

Server query `getData` (`query` name `"getShareData"`): `Share.get` then `Share.data` using the route `shareID` argument. Missing share throws `SessionDataMissingError` with `data.sessionID` equal to that route argument. Projected result:

- `sessionID` is `share.sessionID`; `shareID` is the route argument (not `share.id`)
- `session`: all `type === "session"` items
- `session_diff[share.sessionID]`: last `session_diff` payload (or `[]`)
- `session_status[share.sessionID]`: always `{ type: "idle" }` (not loaded from storage)
- `message[sessionID]`: appended messages
- `part[messageID]`: appended parts
- `model[share.sessionID]`: last `model` payload

If `Binary.search(result.session, share.sessionID, (s) => s.id)` is not found, throws `SessionDataMissingError` with `data.sessionID` equal to `share.sessionID`.

The page sets the same `Cache-Control` as GET data. `<Meta name="robots" content="noindex, nofollow" />`. Description meta: `opencode - The AI coding agent built for the terminal.` Document title when `info().title` is set: `` `${info().title} | OpenCode` ``.

OG/Twitter image URL (`ogImage`): `https://social-cards.sst.dev/opencode-share/${encodedTitle}.png?model=${modelParam}&version=${version}&id=${shareID}` where `encodedTitle` is `encodeURIComponent(Base64.encode(encodeURIComponent(info().title.substring(0, 700))))`, `version` is `` `v${info().version}` ``, and `modelParam` is taken from unique assistant `modelID`s: one id as-is; two as `encodeURIComponent(`${id0} & ${id1}`)`; more as `encodeURIComponent(`${id0} & ${n-1} others`)`; none → `"unknown"`.

UI composition (implementations live in 6.16 / 6.17): `DataProvider`, `SessionTurn`, `SessionReview`, `MessageNav`, `FileSSR`, `WorkerPoolProvider` via `clientOnly` import of `@opencode-ai/session-ui/pierre/worker` `getWorkerPools()`. Header links: `https://opencode.ai`, `https://github.com/anomalyco/opencode`, `https://opencode.ai/discord`. User messages are filtered `role === "user"` and sorted by `time.created`. Default diff style signal is `"unified"`. `wide` is `diffs().length === 0` (desktop breakpoint `md` when wide, `lg` when not). Mobile tabs label the review pane `` `${diffs().length} Files Changed` ``.

Missing `params.shareID` throws `Error` message `Missing shareID`. After data loads, a failed binary search throws `` `Session ${data().sessionID} not found` ``.

### Locale and HTML document

`entry-server.tsx` `StartServer` document: `<html lang>` from `Accept-Language`. Split on `,`, take each item’s trim before `;`, lowercased; first tag starting with `zh` → `"zh"`; first starting with `en` → `"en"`; missing header or no match → `"en"`. `<title>OpenCode</title>`. `<meta name="theme-color" content="#F8F7F7" />`. Body classes `antialiased overscroll-none text-12-regular`. Mount node `#app`.

`App` (`packages/enterprise/src/app.tsx`) wraps `FileRoutes` with `MetaProvider`, `DialogProvider`, `MarkedProvider`, `Favicon`, `Font`, and `UiI18nBridge`. `detectLocale()`: request `accept-language` via `detectLocaleFromHeader` (zh/en prefix); else if `document.documentElement.lang` (lowercased) starts with `zh` or `en`, that locale; other `lang` values are not used and fall through; else `navigator.languages` (or `[navigator.language]`) looking only for `zh` prefix; else `"en"`. `t`: `locale() === "zh" ? (zh[key] ?? uiEn[key]) : uiEn[key]`, then `value ?? String(key)`. `resolveTemplate` is `/\{{\s*([^}]+?)\s*}}/g`; missing params become `""`. Client effect sets `document.documentElement.lang` to the locale.

## Error handling

Share domain errors (`packages/enterprise/src/core/share.ts` `Share.Errors`):

| Class | Message |
|-------|---------|
| `NotFound` | `` `Share not found: ${id}` `` |
| `InvalidSecret` | `` `Share secret invalid: ${id}` `` |
| `AlreadyExists` | `` `Share already exists: ${id}` `` |

HTTP `/api/share*` handlers do not catch these classes; mapping to HTTP status is not specified in this package (OQ-6.20-003). Zod `fn` wrappers `schema.parse` thrown inputs before the callback.

Support delete (`DELETE /api/support/actions/remove-share`):

| Condition | Status | Body |
|-----------|--------|------|
| Auth header length mismatch or `timingSafeEqual` fail | 401 | `{ error: "Unauthorized" }` |
| JSON body fails `z.object({ shareID: z.string().min(1) })` (parse failure uses `undefined`) | 400 | `{ error: "Invalid request", issues: body.error.issues }` |
| `removeAdmin` rejects | 400 | `{ error: <Error.message or String(error)> }` |

Storage adapter HTTP failures (`packages/enterprise/src/core/storage.ts` `createAdapter`): non-OK read/write/remove/list throw `` `Failed to read ${path}: ${status}` ``, `` `Failed to write ${path}: ${status}` ``, `` `Failed to remove ${path}: ${status}` ``, `` `Failed to list ${prefix}: ${status}` ``. Read status `404` returns `undefined` (not a throw).

`SessionDataMissingError` (`share/[shareID].tsx`): `NamedError` name `SessionDataMissingError`; `schema()` throws `Error` message `SessionDataMissingError does not expose a schema`; `toObject()` is `{ name, data }`. `ErrorBoundary`: `SessionDataMissingError.isInstance` → `NotFound`. Other errors: UI copy `Unable to render this share.` and `Check the console for more details.`, plus a `<pre>` of `error.stack ?? error.message` or `String(error)`, and `console.error`.
