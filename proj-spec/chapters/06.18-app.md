# 6.18 App

> **Spec chapter:** SolidJS web app UI (`@opencode-ai/app`): Vite shell, multi-server HTTP clients, layouts, and session workspace.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**File:** `packages/app/` (`@opencode-ai/app`)

This slice is the shipped **web app UI**. Shared primitives live in [6.16 UI](06.16-ui.md); reusable session file views in [6.17 Session UI](06.17-session-ui.md). HTTP/event clients used here come from [6.8 SDK](06.8-sdk.md) and a vendored `@opencode-ai/client` tarball. Domain types come from [8 Domain model](08-domain-model.md); `base64Encode` / `base64Decode` / `checksum` are imported from [6.2 Core](06.2-core.md) (`@opencode-ai/core/util/encode`). This pass is retrospective of shipped code.

`packages/app/package.json` also lists `@opencode-ai/schema` `workspace:*`. This chapter is **canonical** for `@opencode-ai/app` exports (`AppInterface`, `./desktop-menu`, `./updater`, `./vite`, `./i18n/desktop-native`, routes). The desktop **host** that mounts `AppInterface` is [6.19 Desktop](06.19-desktop.md) (closes OQ-6.18-1 / T1 OQ-T1-4 by pointer).

## Behavior

### Package exports and web entry

`packages/app/src/index.ts` is the library surface. Browser boot is `packages/app/index.html` → `/src/entry.tsx`.

`entry.tsx`:

- Resolves locale via `loadInitialLocale()` then wraps `PlatformProvider` → `AppBaseProviders` → `AppInterface`.
- Sets `platform: "web"`, `version` from `packages/app/package.json`, `draftStore` from `createBrowserDraftStore()`, `openExternal`, `restart` (`window.location.reload()`), `notify`, `getDefaultServer` / `setDefaultServer`.
- `openExternal` requires `URL.canParse` and protocol `http:`, `https:`, or `mailto:`; opens `window.open(url.href, "_blank", "noopener,noreferrer")`.
- `notify` no-ops without `Notification`; requests permission when `"default"`; no-ops unless `"granted"`; no-ops when `document.visibilityState === "visible"` and `document.hasFocus()`; otherwise `new Notification(title, { body: description ?? "", icon: "https://opencode.ai/favicon-96x96-v3.png" })`.
- `getCurrentUrl`: if `location.hostname` includes `"opencode.ai"`, `"http://localhost:4096"`; else if `import.meta.env.DEV`, `` `http://${import.meta.env.VITE_OPENCODE_SERVER_HOST ?? "localhost"}:${import.meta.env.VITE_OPENCODE_SERVER_PORT ?? "4096"}` ``; else `location.origin`.
- `getDefaultUrl`: `localStorage` `opencode.settings.dat:defaultServerUrl` if set, else `getCurrentUrl()`.
- Builds one `ServerConnection.Http` with `http.url: getCurrentUrl()` and optional Basic auth from query `auth_token` (`authFromToken`). `auth_token` is then removed via `history.replaceState`.
- Passes `defaultServer={ServerConnection.Key.make(getDefaultUrl())}`, `canonicalLocalServer={ServerConnection.key(server)}`, `servers={[server]}`, **`disableHealthCheck`** (so the web entry does not block on `ConnectionGate` health).
- If `#root` is missing **and** `import.meta.env.DEV`, throws English/Chinese `error.dev.rootNotFound` (`"Root element not found. Did you forget to add it to your index.html? Or maybe the id attribute got misspelled?"`).

`authFromToken` (`packages/app/src/utils/server.ts`): `decode64` the token; split on first `:`; username empty → `"opencode"`. `authTokenFromCredentials` is `btoa(\`${username ?? "opencode"}:${password}\`)`.

### Vite build and theme preload

`packages/app/vite.config.ts` composes `./vite` plus optional Sentry. `packages/app/vite.js` aliases `@` → `src`, sets `VITE_OPENCODE_CHANNEL`, inlines `public/oc-theme-preload.js` into the HTML script `#oc-theme-preload-script`, and enables Tailwind + `vite-plugin-solid`. Workers use `format: "es"`.

`public/oc-theme-preload.js` (tested via `theme-preload.test.ts`) migrates `localStorage` `opencode-theme-id` `"oc-1"` to `"oc-2"` and drops cached `opencode-theme-css-light` / `opencode-theme-css-dark` for that default.

### App shell

`AppBaseProviders` (`app.tsx`): `MetaProvider`, `Font`, `ThemeProvider` (`onThemeApplied` calls `window.api?.setTitlebar?.({ mode, scheme })`), `LanguageProvider`, `I18nProvider` bridge into `@opencode-ai/ui`, `ErrorBoundary` → `Sentry.captureException` + `ErrorPage`, `QueryProvider`, `WslServersProvider`, `DialogProvider`, `FileComponentProvider` with `File` from `@opencode-ai/session-ui/file`.

`AppInterface` wraps `ServerProvider` → `GlobalProvider` → `SettingsProvider` → `ConnectionGate` → keyed `Show` on `settings.general.newLayoutDesigns().toString()` → `Router` (or `props.router`) whose `root` mounts `TabsProvider`, `PermissionProvider`, `NotificationProvider`, `SharedProviders` (`BodyDesignClass`, `CommandProvider`, `DesktopCommands`, `HighlightsProvider`). When new layout is on, `NewAppLayout` stays mounted across routes. Optional `children`, `serverScoped`, `startup`, `disableHealthCheck`, `servers`, `defaultServer`, `canonicalLocalServer`.

`BodyDesignClass` toggles `document.body` attribute `data-new-layout` and font classes from `newLayoutDesigns()`.

`DesktopCommands` registers command id `"logs.export"` only when `platform.platform === "desktop"` and `platform.exportDebugLogs` exists.

`LayoutCompatibility` is defined in `app.tsx` but never mounted in `AppInterface` / `Routes`; it is not live shell behavior.

### Server connections and clients

`ServerConnection` (`packages/app/src/context/server.tsx`):

| `type` | Key (`ServerConnection.key`) | Notes |
|--------|------------------------------|-------|
| `http` | `Key.make(conn.http.url)` | Web default |
| `sidecar` `variant: "base"` | `"sidecar"` | `builtin`; treated local |
| `sidecar` `variant: "wsl"` | `` `wsl:${distro}` `` | **not** local (`ServerConnection.local`) |
| `ssh` | `` `ssh:${host}` `` | Desktop; still exposes `http` proxy |

`normalizeServerUrl`: trim; empty → `undefined`; missing `http://` or `https://` prefix → prepend `http://`; strip trailing `/`. `add` skips empty URLs; stores without `authToken`; activates the new key.

`resolveServerList`: props servers first, then persisted `list`; same key merges `http` fields so startup `auth_token` credentials override a persisted same-URL row.

`serverName`: `displayName` unless `ignoreDisplayName`; else URL without `https?://` and trailing `/`.

`ServerScope.fromServerKey`: `"sidecar"` or `canonicalLocalServer` → `"local"`; otherwise the server key. Null bytes in scope/key fragments throw `` `${label} cannot contain null bytes` `` (`server-scope.ts`).

HTTP clients (`createSdkForServer` / `createApiForServer` in `utils/server.ts`): `createOpencodeClient` from `@opencode-ai/sdk/v2/client` and `OpenCode.make` from `@opencode-ai/client/promise`, `baseUrl: server.url`, optional `Authorization: Basic …`.

`adaptServerEvent` (`server-sdk.tsx`) maps `permission.v2.asked` → `permission.asked` (and `permission.v2.replied` / `question.v2.*`) while keeping `current`. `resumeStreamAfterPageShow` restarts the event stream only when `PageTransitionEvent.persisted` is true.

### Health and connection gate

`checkServerHealth` (`server-health.ts`): first `OpenCode.make(…).health.get` (test pathname `/api/health`). When `typeof x.healthy === "boolean"`, that path returns `{ healthy: x.healthy, version: x.version }` as-is (a boolean `false` is still a primary success payload). On failure or non-boolean `healthy`, it falls back to `createSdkForServer(…).global.health()` (test pathname `/global/health`), which returns `{ healthy: x.data?.healthy === true, version: x.data?.version }`. Transport/`TypeError`/network-like errors retry; `AbortError`/`TimeoutError` do not.

`useServerHealth` (`server-health.ts`, used from `global.tsx`) polls every `pollMs` (`10_000` ms) while enabled. `HEALTH_POLL_INTERVAL_MS` in `server.tsx` is unused.

`ConnectionGate`: if `disableHealthCheck`, health resource is `true`. Otherwise loops `checkServerHealth(server.current.http)` until healthy, **or** immediately fails when `checkMode === "background"` or `type === "http"`, with Effect timeout `"10 seconds"` then `false`. Blocking unresolved/pending shows `Splash`. Failed health shows `ConnectionError`: copy `app.server.unreachable` (`"Could not reach {{server}}"`) with server name, `app.server.retrying` (`"Retrying automatically..."`), retry interval `1000` ms, and buttons for other servers labeled `app.server.otherServers` (`"Other servers"`). Selecting another server sets blocking mode and `setActive`. Optional `startup` promise: rejection is `console.error("[startup] startup gate failed", error)` and the gate still proceeds.

Web `entry.tsx` sets `disableHealthCheck`, so this gate is for other hosts of `AppInterface`.

### Routing and layouts

Directory segments and server keys in URLs are `base64Encode` from `@opencode-ai/core/util/encode`. `decode64` (`utils/base64.ts`) swallows decode errors.

| Path | When | Component / action |
|------|------|-------------------|
| `/` | legacy layout | `LegacyHome` |
| `/` | new layout | `NewHome` |
| `/:dir` | both | `DirectoryLayout`; `/:dir/` → `Navigate` to `session` |
| `/:dir/session/:id?` | both | `SessionRoute` |
| `/server/:serverKey/session/:id` | legacy | `LegacyTargetSessionRoute` → `legacySessionHref(directory, id)` replace |
| `/server/:serverKey/session/:id` | new | `TargetSessionRoute` |
| `/:dir/session/:id` | new (extra route) | `NewLayoutLegacySessionRedirect` → `sessionHref(legacySessionServer(…), id)` |
| `/new-session` (`?draftId=`) | both | Always mounted: `Routes` in `app.tsx` has `<Route path="/new-session" component={DraftRoute} />` **outside** the new-layout `Show`. `DraftRoute` then branches: missing draft → `Navigate` `"/"`; new layout → `ResolvedDraftRoute` → `NewSession`; legacy → `Navigate` `` `/${base64Encode(draft.directory)}/session` `` |

`sessionHref(server, sessionID)` → `` `/server/${base64Encode(server)}/session/${sessionID}` ``. `legacySessionHref(directory, sessionID)` → `` `/${base64Encode(directory)}/session/${sessionID}` ``. `requireServerKey` throws `"Invalid server route"` when the segment is not exact `base64Encode` of its decode. `legacySessionServer`: unique matching tab’s server; if several tabs share the session id, prefer `active`; else `active`. `draftHref` → `` `/new-session?draftId=${encodeURIComponent(draftID)}` `` (`tabs.tsx`).

`SessionRoute` with new layout and `params.id`: after tabs `ready()`, `Navigate` to `sessionHref(legacySessionServer(session tabs, id, server.key), id)`. New layout without `id` or `draftId`: `tabs.newDraft({ server, directory: sdk().directory }, search.prompt)`.

`DirectoryLayout.decodeDirectory`: failed decode toasts `common.requestFailed` (`"Request failed"`) + `directory.error.invalidUrl` (`"Invalid directory in URL."`) and `navigate("/", { replace: true })`. Successful dir wraps `SDKProvider` + `DirectoryDataProvider` (`DataProvider` from `@opencode-ai/session-ui/context`).

Home session open (`home-session-open.ts`): middle-click (`button === 1`) or primary click plus platform modifier (Mac `meta`, else `ctrl`) without shift/alt opens in background (`shouldOpenSessionInBackground`).

### Persistence

`Persist.global` → storage `"opencode.global.dat"`. Web prefixed keys are `${storage}:${key}` (`localStorageWithPrefix`). String targets (`settings.v3`) use unprefixed `localStorageDirect`. Window-scoped keys on web use `"opencode.window.browser.dat"`. Draft storage names `opencode.draft.${head}.${sum}.dat`; workspace `opencode.workspace.${head}.${sum}.dat` (`checksum` from core). In-memory cache caps `500` entries and `8 * 1024 * 1024` bytes (UTF-16). Quota/get failures disable that prefix (`fallbackSet`) rather than throwing through the UI.

Tabs persist `Persist.window("tabs")` (migrated by `migrateTabs`), plus `tabs.recent`, `tabs.info`, `tabs.closed`.

### Settings and layout transition

`resolveNewLayoutDesigns(retired, preference, fallback = true)`: if `retired`, always `true`; else `preference ?? fallback`. `shouldEnableNewLayout(previous, current)`: versions must match `/^v?(\d+)\.(\d+)\.(\d+)(?:[-+].*)?$/i`; enables when upgrading from `<= 1.17.19` to `> 1.17.19`, or when `previous` is missing and `current > 1.17.19`. Non-semver strings such as `"dev"` do not enable. After sunset, `oldInterfaceRetired` forces new layout. `layoutTransitionState(scheduled, eligible, retired, dismissed)` yields `{ available, notice }` as tested in `settings.test.ts`. `shouldDisplayTabsToast`: true on version upgrade or existing install without previous version.

`newLayoutDesigns()` (`settings.tsx`) evaluates in this order: if `layoutUpgrade()` then `true` (this can force the new layout **before** settings persist `ready()`); else if `!ready()` and not retired then `legacyNewLayoutDesignsDefault` (non-`prod` channel); else `resolveNewLayoutDesigns` with the unclassified or classified fallback.

### Localization

`normalizeLocale`: value in `DESKTOP_NATIVE_LOCALES` or `"en"`. `detectLocale` uses `detectDesktopNativeLocale` on `navigator.languages` or `[navigator.language]`. RTL set: `ar`, `ur`, `pa`, `fa`, `dv`. Dictionaries merge `@/i18n/*` with `@opencode-ai/ui/i18n/*`. `entry.tsx` `getLocale` is only `en` vs `zh` prefix for the missing-root error. Locale files are required to keep every English key, placeholders, and plural variants (`i18n/parity.test.ts`).

### Session workspace

Session pages (`packages/app/src/pages/session`, `pages/new-session`, prompt input, titlebar tabs, file tree, terminal) are part of this package. File rendering is injected from session-ui (`File`). Prompt submit/attachments, timeline projection, global-sync cache/trim/queue, and Playwright regression/performance specs under `packages/app/e2e/` encode those surfaces. This chapter does not duplicate session-ui contracts.

## Error handling

### Invalid routes

`requireServerKey` throws `Error("Invalid server route")`. `rootSession` throws `` `Session parent cycle: ${parentID}` ``. `ServerScope` / scoped keys throw `` `${label} cannot contain null bytes` ``. Invalid `/:dir` is a toast + redirect to `/` (not a thrown route error).

### Connection and SDK errors

Unhealthy gate: `ConnectionError` copy as above. Health function returns `{ healthy: false }` on abort/exhaustion rather than throwing. `error.serverSDK.noServerAvailable` / `error.serverSDK.serverNotAvailable` / `error.serverSync.connectFailed` (`"Could not connect to server. Is there a server running at \`{{url}}\`?"`) are English catalog strings (`i18n/en.ts`).

### Error boundary

`AppBaseProviders` `ErrorBoundary` captures with Sentry and renders `ErrorPage`. Title `error.page.title` (`"Something went wrong"`). Description `error.page.description` unless `error.localServerStartup === true` then `error.page.description.localServerStartup` (`errorDescriptionKey`). Init-error names `MCPFailed`, `ProviderAuthError`, `APIError` format via `error.chain.*`. Circular JSON uses `error.page.circular` (`"[Circular]"`). Chain separator is `"\n" + "─".repeat(40) + "\n"`. Restart (`error.page.action.restart`) is always shown and calls `platform.restart`. Report (`error.page.action.report` / `error.page.action.reported`) is gated on `Sentry.isEnabled`. Export Logs (`error.page.action.exportLogs`) is shown when `platform.platform === "desktop" && platform.exportDebugLogs`.
