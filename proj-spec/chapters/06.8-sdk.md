# 6.8 Legacy JS SDK

> **Spec chapter:** Shipped `@opencode-ai/sdk` package — HTTP client facades, optional local server/TUI launchers, and build-time OpenAPI codegen for the v2 surface.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**Package:** `packages/sdk/js` (`@opencode-ai/sdk`, version from `packages/sdk/js/package.json`)

The legacy JavaScript SDK wraps OpenCode’s HTTP API for Node/Bun consumers. Hand-authored modules provide process management (`createOpencodeServer`, `createOpencodeTui`), HTTP client construction with request/error interceptors, and a convenience `createOpencode` helper that starts a server and returns a preconfigured client. Generated OpenAPI bindings live under `src/gen/` (v1 export paths) and `src/v2/gen/` (v2 export paths). **`src/v2/gen/` is regenerated by `packages/sdk/js/script/build.ts`**; generated trees are not hand-authored behavioral source of truth (C5). Wrapper/interceptor/process behavior is specified from hand-authored modules in this package. **OQ-6.8-1 (Blocking: none):** `script/build.ts` invokes an external `bun dev generate` step outside this slice’s allowed paths; the authoritative OpenAPI contract for that input is not specified here — see [10.2 Generate](10.2-generate.md) / [6.1 Agent CLI](06.1-agent-cli.md) when available. The checked-in `src/gen/` tree is also generated output (not edited by hand) but is **not** re-emitted by the current build script; only formatted during build. Published npm artifacts compile `src/` to `packages/sdk/js/dist/` via `tsc`.

Runtime dependency is limited to `cross-spawn` (`packages/sdk/js/package.json`). The SDK spawns the `opencode` CLI on `$PATH` rather than importing `@opencode-ai/server` or `packages/opencode`, avoiding a workspace cycle (`packages/sdk/js/src/process.ts` comment: `opencode` depends on `@opencode-ai/sdk`).

### Build and regeneration

| Command | Location | Effect |
|---------|----------|--------|
| `bun run build` | `packages/sdk/js/package.json` `scripts.build` | Runs `./script/build.ts` |
| `./packages/sdk/js/script/build.ts` | `packages/sdk/js/script/build.ts` | In-slice generator: writes temp `openapi.json`, generates `src/v2/gen/`, applies post-codegen patches, runs Prettier on `src/gen` and `src/v2`, compiles to `dist/`, removes temp `openapi.json` |

Build pipeline steps in `script/build.ts` (behavioral source of truth for SDK codegen within this slice):

1. Run `bun dev generate > openapi.json` with cwd outside this slice (OQ-6.8-1); consumes the resulting temp file only within this script.
2. Prune unreachable `SessionNext*1` component schemas from the OpenAPI document before codegen.
3. Invoke `@hey-api/openapi-ts` `createClient` with `output.path: ./src/v2/gen`, `OpencodeClient` SDK instance, `client-fetch` plugin, default `baseUrl: http://localhost:4096`.
4. Fail build if duplicate `SessionNext*1` types remain; patch `V2SessionHistoryData` / SDK method signatures so `limit` and `after` query params are `number` (not `string`).
5. Patch `SseFn` return type in `src/v2/gen/client/types.gen.ts` to drop erroneous `TError` generic on `ServerSentEventsResult`.
6. Prettier `src/gen` and `src/v2`; `rm -rf dist`; `bun tsc`; delete `openapi.json`.

See [10.2 Generate](10.2-generate.md) for cross-package regeneration index.

### `createOpencodeServer` / `createOpencodeTui` options

Both v1 (`src/server.ts`) and v2 (`src/v2/server.ts`) expose identical option shapes.

| Parameter | Default | Notes |
|-----------|---------|-------|
| `hostname` | `"127.0.0.1"` | Passed to `opencode serve --hostname=…` |
| `port` | `4096` | Passed to `opencode serve --port=…`. CLI yargs `--port` default is `0`; when that resolved listen port is `0`, the CLI listener prefers `4096` then any free port ([6.1 Agent CLI](06.1-agent-cli.md)). |
| `timeout` | `5000` | Milliseconds to wait for startup log line |
| `signal` | — | `AbortSignal`; abort stops child via `bindAbort` |
| `config.logLevel` | — | When set, adds `--log-level=…` to serve args |
| (env) `OPENCODE_CONFIG_CONTENT` | `"{}"` | JSON-stringified `config` object merged into child env |

`TuiOptions` (both surfaces): optional `project`, `model`, `session`, `agent`, `signal`, `config` — forwarded as `opencode` CLI flags and `OPENCODE_CONFIG_CONTENT`.

### `createOpencodeClient` config

Shared behavior (v1 `src/client.ts`, v2 `src/v2/client.ts`):

| Parameter | Default / behavior |
|-----------|-------------------|
| `fetch` | When omitted, SDK supplies a wrapper that sets `req.timeout = false` then calls global `fetch` |
| `baseUrl` | Optional (`ClientOptions.baseUrl?: string`, `src/v2/gen/client/types.gen.ts`). Codegen sets default `http://localhost:4096` via `@hey-api/client-fetch` plugin in `script/build.ts`. `createOpencodeClient` does not require `baseUrl`; `createOpencode` passes `server.url` when spawning locally |
| `directory` | Sets request header `x-opencode-directory` to `encodeURIComponent(directory)` |
| `experimental_workspaceID` | **v2 only** — sets header `x-opencode-workspace` |
| Generated `Config` | Passed through to `@hey-api/client-fetch` `createClient` (`OpencodeClientConfig` export alias) |

`createOpencode(options?)` (v1 `src/index.ts`, v2 `src/v2/index.ts`): awaits `createOpencodeServer(options)`, then `createOpencodeClient({ baseUrl: server.url })`, returning `{ client, server }`.

### v2 `data` helper

`src/v2/index.ts` re-exports `data` from `src/v2/data.ts`. `data.message.user(input)` synthesizes a `UserMessage` and `Part[]` with placeholder ids `"asdasd"`, `time.created: Date.now()`, and `role: "user"`.

## Behavior

### HTTP client facades

| Export | Behavior |
|--------|----------|
| `createOpencodeClient` | Builds generated `OpencodeClient` (`src/gen/sdk.gen.ts` or `src/v2/gen/sdk.gen.ts`) around `@hey-api/client-fetch` with interceptors |
| `OpencodeClient` | Generated class exposing resource namespaces (`session`, `config`, `event`, etc.); method set mirrors OpenAPI at codegen time |
| Re-exported types | v1: `src/gen/types.gen.ts`; v2: `src/v2/gen/types.gen.ts` plus v2 alias `LocationFileSystemEntry` |

Generated API surface details belong in [7.2 SDK API](07.2-sdk-api.md); this chapter covers wrapper semantics only.

### Request interceptors (directory / workspace → query)

**v1** (`src/client.ts` `rewrite`): For `GET` and `HEAD` only, reads `x-opencode-directory` header (matching raw or URI-encoded `config.directory`). When a directory value is present, adds a `directory` query param only if the URL lacks one, then **always** deletes `x-opencode-directory` from the outgoing request (including when `directory` was already on the URL).

**v2** (`src/v2/client.ts` `rewrite`): For `GET` and `HEAD`, handles `x-opencode-directory` and `x-opencode-workspace`. For paths under `/api/`, sets both bare keys (`directory`, `workspace`) and `location[directory]`, `location[workspace]` query params when absent. Strips both headers after rewrite.

### Response interceptor (v2)

When response `content-type` is exactly `text/html`, v2 client throws `Error("Request is not supported by this version of OpenCode Server (Server responded with text/html)")` (`src/v2/client.ts`).

### Local server launcher

`createOpencodeServer` spawns `opencode serve --hostname=… --port=…` via `cross-spawn` (`src/server.ts`, `src/v2/server.ts`).

| Stage | Behavior |
|-------|----------|
| Startup wait | Parses stdout for line starting with `opencode server listening`; extracts URL via `/on\s+(https?:\/\/[^\s]+)/` |
| Success | Resolves promise with URL string; returns `{ url, close }` where `close()` calls `stop(proc)` |
| Timeout | After `options.timeout` ms, calls `stop(proc)`, rejects with `Timeout waiting for server to start after ${options.timeout}ms` |
| Early exit | Rejects with `Server exited with code ${code}` plus captured stdout/stderr |
| Spawn error | Rejects with underlying error |
| Abort | `bindAbort` stops process; rejection uses `options.signal?.reason` |

Server URL discovery depends on CLI log format from [6.1 Agent CLI](06.1-agent-cli.md).

### TUI launcher

`createOpencodeTui` spawns `opencode` with optional `--project`, `--model`, `--session`, `--agent` flags, `stdio: "inherit"`, and `OPENCODE_CONFIG_CONTENT`. Returns `{ close() }` that clears abort binding and stops the process.

### Process utilities

| Function | Behavior |
|----------|----------|
| `stop(proc)` | No-op if already exited; on Windows tries `taskkill /pid … /T /F`, else `proc.kill()` (`src/process.ts`) |
| `bindAbort(proc, signal?, onAbort?)` | Registers abort listener and process exit/error cleanup; invokes `onAbort` when signal fires; returns cleanup function |

## Error handling

| Condition | Outcome | Source |
|-----------|---------|--------|
| Server startup timeout | `Error` with timeout message | `createOpencodeServer` |
| Unparseable listen line | `Error("Failed to parse server url from output: …")` | `createOpencodeServer` |
| Server process exit before ready | `Error("Server exited with code …")` + output | `createOpencodeServer` |
| Abort during server wait | Rejects with `signal.reason` | `bindAbort` callback in `createOpencodeServer` |
| v2 HTML response | `Error` re unsupported server version | v2 response interceptor |
| HTTP errors with `{ throwOnError: true }` | `wrapClientError` converts non-`Error` bodies to `Error` with message from `data.message`, `message`, or `name` fields; sets `cause: { body, status }` | `src/error-interceptor.ts` |
| HTTP errors without `throwOnError` | Parsed body returned unchanged on result tuple path | `wrapClientError` early return |
| Empty / network errors with `throwOnError` | `Error(\`opencode server ${describe(request, response)}: ${reason}\`)` where `reason` is `(empty response body)` when `response` is defined, else `network error (no response)`; `describe` formats `${method} ${url}` plus optional ` → ${status}` and ` ${statusText}` (`src/error-interceptor.ts` `describe`) | `wrapClientError` |
| Build: duplicate SessionNext types | Build throws | `script/build.ts` |
| Build: history numeric patch miss | Build throws | `script/build.ts` |
| Build: SSE type patch miss | Build throws | `script/build.ts` |
