### Session diffs

`normalize` / `resolveFileDiff` (`packages/session-ui/src/components/session-diff.ts`):

- String `patch` is parsed; otherwise `before`/`after` strings (default `""`) go to `parseDiffFromFile`.
- Cache key is `` `${file}\0${patch}` ``.
- Whole-file unified patches whose `---` / `+++` headers include a tab, or patches starting with `"diff --git "`, with a single hunk at old/new start `1`, become complete (`isPartial: false`) via reconstructed before/after text. `\\ No newline at end of file` lines clear the previous line’s trailing newline.
- Tool-style patches without that header shape, multi-hunk patches, header-only patches, and headerless hunks that get an injected `Index:` wrapper stay partial.
- Headerless patches inject `` `Index: ${file}\n===================================================================\n--- ${file}\t\n+++ ${file}\t\n${patch}` `` so names do not leak across files.
- `text(view, "deletions"|"additions")` joins `deletionLines` / `additionLines`.

`patchFiles` / `patchFile` (`packages/session-ui/src/components/apply-patch-file.ts`) accept array items with `type` in `add` \| `update` \| `delete` \| `move`, string `filePath`, `relativePath` (falls back to `filePath`), and `patch` or `diff` or `before`/`after`. `additions`/`deletions` default to `0`. Non-objects and missing required fields are dropped; non-arrays yield `[]`.

### Markdown streaming and projection

`stream(text, live)` (`packages/session-ui/src/components/markdown-stream.ts`):

- `live === false` uses `completedProjection` (one `mode: "full"` block).
- Reference-style definitions (`]:` plus `/^[ \t]{0,3}\[[^\]]+\]:[ \t]*(?:\S+|\r?\n[ \t]+\S+)/m`) stay one `mode: "live"` block.
- Completed lexer tokens before the last non-space token freeze as `mode: "full"` or completed `mode: "code"`.
- Open fences use `mode: "code"` with `src` = body after the first newline; language is the first whitespace-separated token of fence info.
- Incomplete emphasis/code is healed via `remend(..., { linkMode: "text-only" })`; incomplete markdown links become non-clickable text (`stream` tests).
- Fence close can complete across successive deltas (`closesFence` for `` ` `` and `~`).

`project` reuses frozen prefix blocks; `canReusePendingBlock` requires matching `mode`, prefix `raw` for `code`/`live`, and exact `raw` for `full` (`packages/session-ui/src/components/markdown-projection.ts`).

`inlineCodeKind(text)` (`packages/session-ui/src/components/markdown-inline-code-kind.ts`): `"url"` for `/^https?:\/\//i`; other `scheme://` including `file:` and `ftp:` returns `undefined`; else `"path"` when the text looks like a path/filename from Linguist-derived extension and filename sets; otherwise `undefined`.

`shouldResetCodeTokens` is true when previous is missing, language/generation differs, `stableCount` shrinks, or `raw` is not a prefix of the previous `raw` (`packages/session-ui/src/components/markdown-code-state.ts`).

Markdown HTML is sanitized with DOMPurify (`USE_PROFILES.html` + `mathMl`, `FORBID_TAGS: ["style"]`, added `svg`/`path`). Anchors with `target="_blank"` get `rel` including `noopener` and `noreferrer`. If `DOMPurify.isSupported` is false, `sanitizeMarkdown` returns `""`. Cache is LRU 200 (`packages/session-ui/src/components/markdown-cache.tsx`).

Worker protocol (`packages/session-ui/src/components/markdown-worker-protocol.ts`):

- `markdownBlockKey(owner, cacheKey, index, mode)` → `` `${owner}:${cacheKey}:${index}:${mode}` `` or `` `${owner}:block:${index}` `` when `cacheKey` is missing.
- `applyMarkdownWorkerResponse` ignores `response.id <= state.id`; `reset: true` replaces stable tokens and increments `generation`.
- `shouldReleaseMarkdownWorkerState(complete, latestID, responseID)` is true only when `complete && latestID === responseID`.

`createLatestWorkerQueue` keeps one pending request per key and serializes dispose before a later highlight (`packages/session-ui/src/components/markdown-worker-queue.ts`). `createWorkerTransport` posts one in-flight request per key and retains only the latest queued snapshot (`packages/session-ui/src/components/markdown-worker-transport.ts`).

The worker (`packages/session-ui/src/components/markdown.worker.ts`) uses `createMarkdownParser` from `@opencode-ai/ui` with Shiki; unknown languages highlight as `"text"`.

### Session review

v1 `SessionReview` (`packages/session-ui/src/components/session-review.tsx`) normalizes diffs, skips rendering when `additions === 0 && deletions === 0` (comment: binary files), and treats `changedLines() > 500` as too large unless `force` or a media path (`mediaKindFromPath`). Diff style is `"unified"` \| `"split"`.

v2 shell (`packages/session-ui/src/v2/components/session-review-v2.tsx`) hosts sidebar, file list, expand/collapse, and preview. `shouldVirtualizeReviewDiff` is true when either side exceeds 500 lines. Empty states `SessionReviewEmptyNoGitV2` and `SessionReviewEmptyChangesV2` use i18n keys under `ui.sessionReviewV2.empty.*`.

`mediaKindFromPath` maps `.svg` → `"svg"`, image extensions to `"image"`, audio extensions to `"audio"` (`packages/session-ui/src/pierre/media.ts`). `normalizeMimeType` maps `audio/x-aac` → `audio/aac` and `audio/x-m4a` → `audio/mp4`.

### Tool error and retry copy

`ToolErrorCard` (`packages/session-ui/src/components/tool-error-card.tsx`):

- Known `tool` names map to i18n keys (`read` → `ui.tool.read`, `bash`/`shell` → `ui.tool.shell`, `patch`/`apply_patch` → `ui.tool.patch`, …); unknown names render the raw `tool` string.
- Error text: `error.replace(/^Error:\s*/, "").trim()`, then strip a leading `` `${tool} ` `` prefix.
- Subtitle is the first `": "` segment (capitalized) or `ui.toolErrorCard.failed`; body is the remainder.

`SessionRetry` shows only when `status.type === "retry"`. If `message` includes `"exceeded your current quota"` and `"gemini"`, copy is `ui.sessionTurn.retry.geminiHot`. Otherwise messages longer than 80 characters are sliced to 80 + `"..."`.

## Error handling

| Condition | Behavior | Source |
|----------|----------|--------|
| `parsePatch` / complete-patch reconstruction throws | Treat as not complete; empty or partial Pierre parse | `completePatchContents` / `patchInput` `catch` (`session-diff.ts`) |
| Malformed patch that `parsePatch` cannot turn into lines | `text(..., "deletions"|"additions")` is `""` | `session-diff.test.ts` `ignores malformed persisted patches` |
| `patchFile` invalid raw | `undefined`; omitted from `patchFiles` | `patchFile` |
| Stale highlight `id` | Previous worker state unchanged | `applyMarkdownWorkerResponse` |
| Superseded highlight/project | `MarkdownWorkerSupersededError` | `markdown-worker.ts` |
| Dispose in-flight work | `MarkdownWorkerDisposedError` | `markdown-worker.ts` |
| Worker construct / prior disable | `MarkdownWorkerUnavailableError` with `disabled.message` | `getWorker` |
| Worker `onerror` | Fail all pending with `event.message` or `"Markdown highlighting worker failed"`; terminate worker | `getWorker` |
| `onmessageerror` | Fail with `"Markdown worker response failed"` | `getWorker` |
| Highlight throw other than disposed/superseded/unavailable | `console.error("Markdown highlighting worker failed", error)`; fallback unstyled token | `markdown.tsx` `code` |
| Worker request catch | Posts `{ type: "error", id, message }` | `markdown.worker.ts` |
| `sanitizeMarkdown` without DOMPurify | `""` | `markdown-cache.tsx` |
| Clipboard `writeText` reject in message copy | `false` | `writeClipboard` (`message-part.tsx`) |
| Invalid `codeUrl` | `new URL` `catch` returns `undefined` | `markdown.tsx` |
| `svgTextFromValue` base64 decode | `try`/`catch` swallow | `pierre/media.ts` `decodeBase64Utf8` |
