## Behavior

### File routing, locales, and middleware

`src/middleware.ts` `onRequest`:

1. Replaces the request with `sanitizeServerActionRequest` (`server-action.ts`). For pathname `/_server` only, if `referer` is missing, unparseable, or a different origin than the request, the handler sets `referer` to the request origin. Other paths are unchanged.
2. If the first path segment is a `LOCALES` value, strips that prefix (`strip`), sets `x-opencode-locale`, and appends `oc_locale`.
3. If `?ref=` normalizes to a referral code (`Referral.normalizeCode` via `normalizeReferralCode`), appends `oc_referral`.

`localeFromRequest` order: `x-opencode-locale`, then first path segment, then `/docs/<segment>` via `DOCS_LOCALE`, then `oc_locale` cookie, then `Accept-Language` (`detectFromAcceptLanguage`, default `en`).

`route(locale, pathname)` (`language.ts`): `/docs` goes through `docs()`; `/auth` and `/workspace` stay unprefixed; `en` uses the stripped path; other locales prefix `/${locale}` (root becomes `/${locale}`).

`docs(locale, pathname)` rewrites `/docs` URLs to Starlight segments (`zh` → `zh-cn`, `zht` → `zh-tw`, `br` → `pt-br`, `no` → `nb`, `en` → `root` with `/docs/en` collapsed). Existing docs locale segments, `_` prefixes, and dotted heads are left in place. `goUsageLimits("uk")` returns `/docs/en/go/#usage-limits`; other locales use localized heading ids in `GO_USAGE_LIMITS`.

### Authentication

| Method | Path | Behavior | Source |
|--------|------|----------|--------|
| GET | `/auth` | Redirect to `route(locale, /workspace/<lastSeen>)`; on failure `/auth/authorize` | `auth/index.ts` |
| GET | `/auth/authorize` | OpenAuth `authorize` with callback `./callback` + `continue` query; HTTP 302 to `result.url` | `auth/authorize.ts` |
| GET | `/auth/callback…` | Exchange `code`; store account in session; redirect | `auth/[...callback].ts` |
| GET | `/auth/logout` | Remove `current` account from session; `current` becomes first remaining key; redirect `/zen` | `auth/logout.ts` |
| GET | `/auth/status` | JSON of session data | `auth/status.ts` |

`getActor` (`auth.ts`): no workspace → `account` from `current` or first account, else `public`. With workspace, loads a non-deleted `UserTable` row for session account ids; if `WorkspaceTable.migrated_at` is set, redirects to `Resource.ConsoleMigration.consoleUrl` + `/login` (302 GET/HEAD, else 303) with `Cache-Control: no-store`; else updates `timeSeen` and returns `user`. Missing membership redirects `/auth/authorize`. Missing request event throws `No request event`. Missing `ConsoleMigration.consoleUrl` throws `New Console URL is not configured`.

`withActor` (`auth.withActor.ts`) runs `Actor.provide(actor.type, actor.properties, fn)` after `getActor`.

Callback success: `next` is `/auth` when pathname is `/auth/callback`, else pathname with `/auth/callback` removed, then `route(locale, next)`. Missing code uses English `No authorization code found.` (`en.ts` `auth.callback.error.codeMissing`) when locale is `en`.

### Workspace console

`getLastSeenWorkspaceID` returns the most recently `timeSeen` non-deleted workspace for the account (`workspace/common.tsx`).

`querySessionInfo`: `isAdmin` iff `Actor.userRole() === "admin"`; `isBeta` is `true` unless production, where only workspace `wrk_01K46JDFR0E75SG2Q8K172KF3Y` is beta.

`formatBalance` renders `(amount / 100000000).toFixed(2)`, mapping `"-0.00"` to `"0.00"`.

`createCheckoutUrl` rate-limits via `checkCheckoutRateLimit(Actor.account())` then `Billing.generateCheckoutUrl`. Redis key `${stage}:ratelimit:checkout:${accountID}`: `incr`; expire 3600s on first hit; `count > 5` throws `Too many payment attempts. Please try again later.` (`redis.ts`).

Workspace chrome (`workspace/[id].tsx`) links: Zen (end), Go, usage, keys, members; billing and settings only when `isAdmin`. Home (`[id]/index.tsx`) shows new-user, model, and (admin) provider sections; admins without `customerID` start checkout using `reloadAmount`.

Go usage UI helpers (`lite-usage.ts`):

- `getModelQuotaLimit(limit, multiplier)` is `undefined` when `multiplier` is missing or `<= 0`, else `limit / multiplier`.
- `getUsagePercent` is `0` when `limit === 0`, else `Math.round((amount / limit) * 1000) / 10`.
- `buildLiteUsageBreakdown` groups sources by `[model, multiplier]`, sums `cost`/`quotaCost`, ORs `estimated`, drops zero/zero rows, sorts by `quotaCost` descending, and allocates `contributionPercent` so row percents sum to `usagePercent` (one decimal via tenths).

`createReferralFromCookie` creates a referral from `oc_referral` then clears the cookie (`referral-invite.ts`).

| POST | `/zen/go/v1/chat/completions` | `oa-compat` | `lite` | `authorization` bearer |
| POST | `/zen/go/v1/responses` | `openai` | `lite` | `authorization` bearer |
| POST | `/zen/go/v1/messages` | `anthropic` | `lite` | `x-api-key` |

Bearer token `public` is treated as missing (`zenApiKey` undefined). Client IP is `x-real-ip`, truncated to the first four colon-separated parts when IPv6-like.

Non-Google bodies use `prepareRequestBody`: parse the root `model` from a leading JSON object (skipping nested `"model"`), optionally patch it to the provider model, and when the second `stream()` argument is true append `stream_options: { include_usage: true }` before a trailing `}`. UTF-8 BOM is preserved. Missing body throws `Missing request body`.

If `proxyInference` returns a response, that response is returned before local auth/billing. Failed proxy after a model is present returns `inferenceUnavailable()`.

Catalog is `ZenData.list(opts.modelList)` ([6.22](06.22-console-platform.md)). Unknown model → `ModelError`. Format mismatch → `ModelError`. `trialEnded` → `ModelError` with Go link `https://opencode.ai/go`.

Country: `request.cf.country` or `cf-ipcountry`. `isModelCountryRestricted` is true for `muse-spark-1.3-contributor`, `muse-spark-1.3-contributor-free`, `muse-spark-1.2-contributor`, `muse-spark-1.2-contributor-free` when country is in `MUSE_SPARK_BLOCKED_COUNTRIES` (`AF`, `BY`, `CN`, `CU`, `EH`, `ER`, `ET`, `HK`, `HT`, `IQ`, `IR`, `KH`, `KP`, `LY`, `MM`, `MO`, `NI`, `PK`, `RU`, `SO`, `SY`, `VE`) (`request-country.ts`). That throws `RegionError`.

Go (`modelList === "lite"`) plus `requiresGoTrainingConsent` (`muse-spark-1.3-contributor`, `muse-spark-1.2-contributor` only) and `!allowTraining` → `DataPolicyError`. Go models `deepseek-v4-flash` / `deepseek-v4-pro` require workspace region including `"cn"`.

Anonymous models use `ipRateLimiter`; others use `keyRateLimiter` (no-op without a key). IP limiter: daily Redis key; default-model also tracks lifetime; new IPs (`lifetimeCount < dailyLimit * 7`) may use `dailyLimit * 2`; `retry-after` seconds from `getRetryAfterDay` (ceil remaining UTC day). Key limiter default `1000` per minute window (`retryAfter` `60`).

`authenticate`: missing key when not `allowAnonymous` → `AuthError`; unknown key → `AuthError`; blocked workspace or Anthropic/OpenAI flags on `claude-` / `gpt-` models → `AuthError`; production `alpha-` models unless workspace is in `ADMIN_WORKSPACES` (`wrk_01K46JDFR0E75SG2Q8K172KF3Y`, `wrk_01K6W1A3VE0KMNVSCQT43BG2SX`, `wrk_01KKZDKDWCS1VTJF8QTX62DD50`) → `AuthError` as unsupported model. Those three workspaces are `isFree`.

`validateBilling` sources: `anonymous` (no auth); `byok` (provider credentials); `free` (`isFree` or `allowAnonymous`); `subscription` (Black weekly/rolling via `BlackData`/`Subscription`); `lite` (Go weekly/monthly/rolling via `LiteData`, skipped when all `modelInfo.cost` prices are `0`); else pay-as-you-go `balance` (payment method + positive balance, workspace and user monthly limits). Quota failures may fall through to balance when `useBalance` is set on the subscription/lite billing row.

Provider selection: BYOK credentials force `byokProvider`; else weighted pick among enabled providers that pass budget/TPM/TPS filters, hashed from last 4 chars of sticky id (`x-opencode-session` else workspace or IP); sticky Redis provider may stick unless budget/TPS prefer the hashed pick. Missing provider → `ModelError`.

If `providerInfo.format !== opts.format`, throws `Zen provider format must match request format`. Special Anthropic model prefixes (`arn:aws:bedrock:`, `global.anthropic.`, `databricks-claude-`) throw `Anthropic provider body modifiers are incompatible with streaming`. Upstream `fetch` uses `input.request.signal`. Non-SSE responses rewrite `json.error.message` to `Error from provider (<displayName>): …` when present. SSE streams parse usage, then enqueue `buildCostChunk`; `cancel` cancels the upstream reader.

`isPeakPricing` (`pricing.ts`): China Standard Time (UTC+8), weekdays only, hours `[9,12)` or `[14,18)`. `calculateCost` uses `costPeak` when that is true and `costPeak` exists; else `cost200K` when input+cache tokens exceed `cost200K.threshold`; else `cost`. Token costs are `price * tokens * 100` (cents). `calculateOccurredCost` is `"0"` unless `billingSource === "balance"`, then `(totalCostInCent / 100).toFixed(8)`.

`validateModelSettings` throws `ModelError` `Model is disabled` when the workspace disabled the model, except `lite` and `anonymous` sources.

Redis keys use prefix `${Resource.App.stage}:ratelimit:` (`buildRateLimitKey`).

## Error handling

### Zen handler HTTP mapping

`handler` catch (`handler.ts`): aborted request or `AbortError` → HTTP 499 empty body. JSON errors share `{ type: "error", error: { type, message } }` unless noted.

| Condition | Status | `error.type` |
|-----------|--------|----------------|
| `RegionError`, `DataPolicyError` | 403 | constructor name |
| `AuthError`, `CreditsError`, `MonthlyLimitError`, `UserLimitError`, `ModelError` | 401 | constructor name |
| `RateLimitError`, `FreeUsageLimitError`, `GoUsageLimitError`, `BlackUsageLimitError` | 429 | constructor name; `retry-after` when `retryAfter` set; Go adds `metadata.workspace` and `metadata.limitName` (`"5 hour"` \| `"weekly"` \| `"monthly"`) |
| Other | 500 | `"error"` / `"Internal server error"` |

English `en.ts` strings (locale-resolved via `i18n` + `{{param}}` replacement in `resolve`): `Rate limit exceeded. Please try again later.`; `Model {{model}} is not supported`; `Model {{model}} is not supported for format {{format}}`; `No provider available`; `Provider {{provider}} not supported`; `Missing API key.`; `Invalid API key.`; fraud/block copy ending `help@anoma.ly.`; subscription/Go quota templates; `No payment method. Add a payment method here: {{billingUrl}}`; `Insufficient balance. Manage your billing here: {{billingUrl}}`; workspace/user monthly limit templates; `Model is disabled`; China opt-in `regionNotAllowed`; `This model is not available in your country.`; training opt-in; `Free promotion has ended for {{model}}. You can continue using the model by subscribing to OpenCode Go - {{link}}`.

Provider format mismatch and special Anthropic streaming throws are untyped `Error`s and therefore HTTP 500.

### Other HTTP errors

| Surface | Status | Body / notes |
|---------|--------|----------------|
| Auth callback catch | 500 | `{ error: e.message, cause: searchParams }` |
| Stripe webhook catch | 500 | `{ message: error.message }` |
| Honeycomb bad token | 401 | `{ message: "invalid token" }` |
| Honeycomb Zod fail | 400 | `{ message: "invalid payload" }` |
| Discord post fail | 502 | `{ message: "discord webhook failed" }` |
| Download unknown platform | 404 | empty |
| Download missing GitHub `location` | 502 | empty |
| Changelog fetch fail | 503 | `{ releases: [] }` |
| Enterprise validation | 400 | i18n `enterprise.form.error.allFieldsRequired` / `invalidEmailFormat` |
| Enterprise delivery fail (prod) | 500 | `enterprise.form.error.internalServer` |
| Stats cache without Cloudflare `caches.default` | throws `Cloudflare default cache is unavailable` | `stats-proxy.ts` `defaultCache` |
