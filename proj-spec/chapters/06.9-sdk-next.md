### Runtime dependency direction

Committed workspace rule (`AGENTS.md`): runtime dependencies are directed from Schema to Core and Protocol, then from Core and Protocol to Server. Client runtime code may depend on Schema and Protocol but never Core or Server; `sdk-next` composes Client, Core, and Server.

`packages/sdk-next/package.json` runtime `dependencies` are `@opencode-ai/client`, `@opencode-ai/core`, `@opencode-ai/server`, and `effect`. `packages/sdk-next/src/opencode.ts` imports `OpenCode` from `@opencode-ai/client/effect`, `AppNodeBuilder` / `LayerNode` / `PermissionSaved` / `ApplicationTools` from `@opencode-ai/core`, and `createEmbeddedRoutes` from `@opencode-ai/server/routes`. `packages/sdk-next/test/import-boundaries.test.ts` `"bundles the client and in-memory host"` asserts a Bun bundle of `@opencode-ai/sdk-next` includes inputs under `packages/client`, `packages/core`, and `packages/server`.

### Host construction

`OpenCode.create` is `Effect.fn("OpenCode.create")` (`packages/sdk-next/src/opencode.ts`). It:

1. Builds `AppNodeBuilder.build(LayerNode.group([ApplicationTools.node, PermissionSaved.node]))` with `Layer.buildWithMemoMap` into the current `Scope.Scope`.
2. Reads `ApplicationTools.Service` and `PermissionSaved.Service` from that context.
3. Acquires `HttpRouter.toWebHandler(createEmbeddedRoutes().pipe(HttpRouter.provideRequest(Layer.succeed(PermissionSaved.Service, permissions)), Layer.provide(HttpServer.layerServices)), { disableLogger: true, memoMap })` and releases with `web.dispose`.
4. Installs an in-memory `fetch` that calls `web.handler(new Request(input, init))`.
5. Constructs `OpenCode.make({ baseUrl: "http://opencode.local" })` provided with `FetchHttpClient.layer` and `FetchHttpClient.Fetch` bound to that `fetch`.
6. Returns `{ ...client, tools: { register: tools.register } }`.

`OpenCode.Interface` is `Effect.Success<ReturnType<typeof create>>`. `OpenCode.layer` is `Layer.effect(Service, create())` (`packages/sdk-next/src/opencode.ts`). `packages/sdk-next/README.md` states `OpenCode.layer` adapts `OpenCode.create()` for dependency injection and does not define another host implementation.

`packages/sdk-next/src/index.ts` exports `OpenCode` from `./opencode`, `Tool` from `./tool`, `ClientError` from `@opencode-ai/client/effect`, and types `AbsolutePath`, `Agent`, `Location`, `Model`, `Prompt`, `Provider`, `RelativePath`, `Session`, `SessionInput`, `SessionMessage`, and `OpenCodeEvent` from `@opencode-ai/client/effect`. `packages/sdk-next/src/tool.ts` re-exports `Failure`, `RegistrationError`, and `make` (and types `AnyTool`, `Content`, `Context`, `Definition`) from `@opencode-ai/core/tool/tool`.

## Behavior

`packages/sdk-next/README.md` describes an Effect-native scoped OpenCode host for in-process applications and a transitional package that will replace generated `@opencode-ai/sdk` after consumers migrate. The SDK executes Server’s assembled HTTP router in memory: it opens no listener and performs no network I/O, while preserving the same routing, middleware, handlers, codecs, and errors as the network client.

### Embedded client and session operations

`packages/sdk-next/test/embedded.test.ts` `"embedded client uses the real router and handlers"` runs `Effect.scoped(OpenCode.create())` and exercises the composed client:

| Method / command | Observed behavior |
|------------------|-------------------|
| `tools.register({ embedded_tool: Tool.make({...}) })` | Registers a tool whose `execute` returns `{ ok: true }` |
| `sessions.create({ id, agent, location })` | Returns a session whose `id` equals the supplied `Session.ID` |
| `sessions.switchModel({ sessionID, model })` then `sessions.get({ sessionID })` | `selected.model.id` / `providerID` match the switched `Model.Ref` |
| `sessions.list({ directory })` | `page.data` contains the created session id |
| `sessions.active()` | Equals `{}` in this test |
| `sessions.prompt({ sessionID, prompt, resume: false })` | Returns an admitted input whose `sessionID` matches |
| `sessions.prompt({ sessionID, prompt })` (no `resume: false`) | Yields a user message id; `sessions.events({ sessionID })` emits `session.next.prompted` with that `messageID`; later `sessions.context({ sessionID })` contains `{ id: wake.id, type: "user" }` |
| `sessions.context({ sessionID })` after `switchModel` | Contains a `type: "model-switched"` message |
| `sessions.events({ sessionID })` first event | Matches `{ type: "session.next.model.switched", durable: { seq: 1 } }` |
| `sessions.message({ sessionID, messageID })` | Equals the `model-switched` context message |
| `sessions.interrupt({ sessionID })` | Completes for the existing session |

`packages/sdk-next/README.md`: `sessions.events({ sessionID, after })` replays durable events after the optional aggregate sequence, then emits newly committed durable events; `sessions.interrupt(...)` targets execution owned by this host; `sessions.message(...)` retrieves one projected Session message.

### Global events and host isolation

`packages/sdk-next/test/embedded.test.ts` `"Location-owned runner events reach the ready global client"`: after `events.subscribe()` observes `type === "server.connected"`, `sessions.create` plus `sessions.prompt` produce a `session.next.prompted` event whose `durable` contains `aggregateID` equal to the session id and a numeric `seq`.

`packages/sdk-next/test/embedded.test.ts` `"independent embedded hosts do not share live notifications"`: two `OpenCode.create()` hosts each `events.subscribe()`. After both see `server.connected`, `first.sessions.create` plus `first.sessions.switchAgent({ sessionID, agent: Agent.ID.make("plan") })` opens a `session.next.agent.switched` latch on the first host; the second host’s matching latch stays unset within `"100 millis"`.

`packages/sdk-next/README.md`: registration uses Core’s host-level `ApplicationTools` service shared by the host’s Locations; each Location retains its own `ToolRegistry` for overlay, lookup, and settlement. Closing the owning Effect Scope releases router resources, location services, fibers, and scoped tool registrations.

### Layer service

`packages/sdk-next/test/embedded.test.ts` `"embedded client is available as a Layer service"` provides `OpenCode.layer` and yields `OpenCode.Service`; `sessions.create` returns the supplied session id.
