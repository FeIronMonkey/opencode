# 6.25 @opencode-ai/function

> **Spec chapter:** Cloudflare Worker for session sharing, support webhooks, and GitHub App token exchange.
> **Parent:** [6 Components](../06-components.md)
> **Index:** [README.md](../README.md)

**Files:** `packages/function/src/api.ts`, `packages/function/src/github.ts`

`@opencode-ai/function` is a private Bun workspace package (`packages/function`) that ships a Hono HTTP application and a `SyncServer` Cloudflare Durable Object. The worker exposes session-share APIs (create, sync, poll, read, delete), a Feishu-to-Discord support relay, and GitHub App installation lookup plus OIDC/PAT token exchange for the GitHub Action and CLI. Cloudflare bindings (`SYNC_SERVER`, `Bucket`, `WEB_DOMAIN`) are Hono `Env` values on `c.env`; secrets and GitHub/Discord config use SST `Resource.*` in `api.ts`.

## Behavior

### HTTP routes (Hono app)

| Route | Method | Input | Response / effect | Source |
|-------|--------|-------|-------------------|--------|
| `/` | GET | — | Plain text `Hello, world!` | `packages/function/src/api.ts` `.get("/")` |
| `/share_create` | POST | JSON `{ sessionID }` | Resolves Durable Object stub by short name; calls `share(sessionID)`; returns JSON `{ secret, url }` where `url` is `https://{WEB_DOMAIN}/s/{short}`. Public HTTP path `/s/{short}` is [6.21 Console app](06.21-console-app.md); share viewer origin is [6.27 Web](06.27-web.md) | `packages/function/src/api.ts` `.post("/share_create")` |
| `/share_delete` | POST | JSON `{ sessionID, secret }` | Asserts secret on stub; calls `clear()`; returns `{}` | `packages/function/src/api.ts` `.post("/share_delete")` |
| `/share_delete_admin` | POST | JSON `{ sessionShortName, adminSecret }` | When `adminSecret` matches `Resource.ADMIN_SECRET`, clears the named stub without session secret; returns `{}` | `packages/function/src/api.ts` `.post("/share_delete_admin")` |
| `/share_sync` | POST | JSON `{ sessionID, secret, key, content }` | Asserts secret; calls `publish(key, content)` on stub (return value ignored); always returns `{}` | `packages/function/src/api.ts` `.post("/share_sync")` |
| `/share_poll` | GET | Query `id`; `Upgrade: websocket` header | Proxies to stub `fetch` for WebSocket subscription | `packages/function/src/api.ts` `.get("/share_poll")` |
| `/share_data` | GET | Query `id` | Reads stub storage via `getData()`; aggregates `session/info`, `session/message`, and `session/part` keys into JSON `{ info, messages }` | `packages/function/src/api.ts` `.get("/share_data")` |
| `/feishu` | POST | Feishu webhook JSON | URL verification: when `challenge` is present, echoes `{ challenge }`. Otherwise parses message text, strips a leading `/^@_user_\d+\s*/` mention (`@_user_` plus digits, then optional whitespace), then replaces leading `/^aiden,?\s*/i` with Discord mention `<@759257817772851260> ` (comma after `aiden` optional; `\s*` is optional whitespace, so `aidenhello` still matches). When message is empty after transforms returns `{ ok: true }` without Discord POST; otherwise optionally appends thread id, posts to Discord support channel; returns `{ ok: true }` or error JSON | `packages/function/src/api.ts` `.post("/feishu")` |
| `/exchange_github_app_token` | POST | `Authorization: Bearer {OIDC}` | Verifies GitHub Actions OIDC JWT (issuer `https://token.actions.githubusercontent.com`, audience `opencode-github-action`). `parseRepositoryClaim` only splits JWT `repository` into `{ owner, repo }`. Installation token is obtained with `createAppAuth` plus `octokit.apps.getRepoInstallation` in `.post("/exchange_github_app_token")`; returns JSON `{ token }` | `packages/function/src/api.ts` `.post("/exchange_github_app_token")` |
| `/exchange_github_app_token_with_pat` | POST | JSON `{ owner, repo }`, `Authorization: Bearer {PAT}` | Validates PAT repo permissions (`admin`, `push`, or `maintain`); returns installation token JSON `{ token }` | `packages/function/src/api.ts` `.post("/exchange_github_app_token_with_pat")` |
| `/get_github_app_installation` | GET | Query `owner`, `repo` | Returns JSON `{ installation }` — installation object when found, otherwise `undefined` when GitHub responds Not Found | `packages/function/src/api.ts` `.get("/get_github_app_installation")` |
| `*` | ALL | — | Plain text `Not Found` | `packages/function/src/api.ts` `.all("*")` |

### SyncServer Durable Object

| Method / hook | Behavior | Source |
|---------------|----------|--------|
| `fetch` | Accepts WebSocket; replays all storage keys prefixed `session/` to the client; returns 101 with client socket | `packages/function/src/api.ts` `SyncServer.fetch` |
| `webSocketMessage` | No-op | `packages/function/src/api.ts` `SyncServer.webSocketMessage` |
| `webSocketClose` | Closes socket with reason `Durable Object is closing WebSocket` | `packages/function/src/api.ts` `SyncServer.webSocketClose` |
| `share(sessionID)` | Returns existing `secret` from storage when present; otherwise stores new `randomUUID()` secret and `sessionID`, then returns secret | `packages/function/src/api.ts` `SyncServer.share` |
| `publish(key, content)` | Accepts keys under `session/info/{sessionID}`, `session/message/{sessionID}/`, or `session/part/{sessionID}/` only; on invalid key returns HTTP 400 `Error: Invalid key`; otherwise writes JSON to R2 at `share/{key}.json`, persists to Durable Object storage, broadcasts `{ key, content }` to connected WebSockets | `packages/function/src/api.ts` `SyncServer.publish` |
| `getData` | Lists storage entries whose keys start with `session/` | `packages/function/src/api.ts` `SyncServer.getData` |
| `assertSecret(secret)` | Throws when secret does not match stored secret | `packages/function/src/api.ts` `SyncServer.assertSecret` |
| `clear` | Deletes R2 objects under `session/message/{sessionID}/` (up to 1000) and `session/info/{sessionID}`; calls `storage.deleteAll()` | `packages/function/src/api.ts` `SyncServer.clear` |

### GitHub repository claim parsing

| Input | Output |
|-------|--------|
| JWT payload with string `repository` claim `owner/repo` | `{ owner, repo }` split on `/` (`packages/function/src/github.ts` `parseRepositoryClaim`) |

Parsing uses the `repository` claim only; it does not derive owner/repo from `sub` or other claims.

## Error handling

| Condition | Result | Source |
|-----------|--------|--------|
| Missing `repository` claim (not a string) | Throws `Repository claim is missing` | `packages/function/src/github.ts` `parseRepositoryClaim` |
| `repository` not exactly `owner/repo` (two non-empty segments) | Throws `Repository claim is invalid` | `packages/function/src/github.ts` `parseRepositoryClaim` |
| `publish` key outside allowed session prefixes | `SyncServer.publish` returns HTTP 400 body `Error: Invalid key` (e.g. `/share_sync` does not propagate this; it always responds `{}`) | `packages/function/src/api.ts` `SyncServer.publish`, `.post("/share_sync")` |
| `assertSecret` mismatch | Throws `Invalid secret` | `packages/function/src/api.ts` `SyncServer.assertSecret` |
| `/share_delete_admin` wrong admin secret | Throws `Invalid admin secret` | `packages/function/src/api.ts` `.post("/share_delete_admin")` |
| `/share_poll` missing or non-websocket `Upgrade` | HTTP 426 `Error: Upgrade header is required` | `packages/function/src/api.ts` `.get("/share_poll")` |
| `/share_poll` or `/share_data` missing query `id` | HTTP 400 `Error: Share ID is required` | `packages/function/src/api.ts` `.get("/share_poll")`, `.get("/share_data")` |
| `/exchange_github_app_token` missing bearer token | HTTP 401 `{ error: "Authorization header is required" }` | `packages/function/src/api.ts` `.post("/exchange_github_app_token")` |
| OIDC verification failure | HTTP 403 `{ error: "Invalid or expired token" }` | `packages/function/src/api.ts` `.post("/exchange_github_app_token")` |
| GitHub App token exchange failure (OIDC path) | HTTP 502 with `{ error: "Failed to exchange GitHub App token for {owner}/{repo}" }` | `packages/function/src/api.ts` `.post("/exchange_github_app_token")` |
| PAT path: missing auth, insufficient repo permissions, or other errors | HTTP 401 `{ error: ... }` (message string when `Error`) | `packages/function/src/api.ts` `.post("/exchange_github_app_token_with_pat")` |
| Feishu relay Discord POST failure | HTTP 502 `{ error: "Discord bot message failed" }` | `packages/function/src/api.ts` `.post("/feishu")` |
| Unmatched routes | HTTP response text `Not Found` | `packages/function/src/api.ts` `.all("*")` |
