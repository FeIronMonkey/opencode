# 11.1 Surface example entrypoints

> **Spec chapter:** Shipped start commands, bins, and in-repo example hosts for each T0 product surface.

**Files:** `packages/opencode/package.json`, `packages/cli/package.json`, `packages/tui/package.json`, `packages/desktop/package.json`, `packages/app/package.json`, `packages/server/package.json`, `packages/sdk/js/package.json`, `packages/sdk/js/example/example.ts`, `packages/sdk-next/package.json`, `packages/client/package.json`, `packages/plugin/package.json`, `packages/web/package.json`, `packages/console/app/package.json`, `packages/enterprise/package.json`, `packages/stats/app/package.json`, `packages/slack/package.json`

This leaf records **example entrypoints** for the T0 surfaces assigned in `tmp/executive/opencode-retrospective-spec/findings/T1-chapter-map.md` §4. Each construction row names that surface’s **canonical** §6.x leaf. Product contracts (command trees, auth, listen/timeout, error strings, plugin `define`/`tool`, generated-client regeneration, Bolt/session mapping, sidecar spawn) live only in those chapters. This pass is retrospective of shipped code (C8). T0 surface “Storybook (dev)” is an explicit non-goal (`non-goal:2` in T1 §3) and is not an example host here.

Workspace bins named by T1 consistency tokens: **`opencode`** (`packages/opencode/package.json` `bin.opencode` → `./bin/opencode`) and **`lildax`** (`packages/cli/package.json` `bin.lildax` → `./bin/lildax.cjs`). Bin resolve/`spawn` and CLI name `OPENCODE_CLI_NAME` are specified in [6.1 Agent CLI](06.1-agent-cli.md) and [6.15 CLI (`lildax`)](06.15-cli.md).

### In-repo example file

`packages/sdk/js/example/example.ts` is the legacy SDK example host: it calls `createOpencodeServer()`, `createOpencodeClient({ baseUrl: server.url })`, then session create/prompt. Request/listen/timeout behavior is specified in [6.8 Legacy JS SDK](06.8-sdk.md), not here.
