## Behavior

### CLI binaries `opencode` and `lildax`

Primary CLI entry is `packages/opencode/src/index.ts` (`scriptName("opencode")`). Default command `$0 [project]` is `TuiThreadCommand` (`describe` `"start opencode tui"`) (`packages/opencode/src/cli/cmd/tui.ts`). Other registered commands include `serve` (`describe` `"starts a headless opencode server"`), `web` (`describe` `"start opencode server and open web interface"`), and `run [message..]` (`packages/opencode/src/index.ts`, `packages/opencode/src/cli/cmd/serve.ts`, `packages/opencode/src/cli/cmd/web.ts`, `packages/opencode/src/cli/cmd/run.ts`). `serve` prints `opencode server listening on http://${server.hostname}:${server.port}` and then `Effect.never`. When `Flag.OPENCODE_SERVER_PASSWORD` is unset, `serve` prints `Warning: OPENCODE_SERVER_PASSWORD is not set; server is unsecured.` (`ServeCommand`). `web` uses the same listen path; if `hostname === "0.0.0.0"` it prints `Local access:` `http://localhost:${server.port}` and `open(localhostUrl)`; otherwise it prints `Web interface:` `server.url.toString()` and opens that URL (`WebCommand`).

`packages/opencode/bin/opencode` prefers `OPENCODE_BIN_PATH`, else `bin/.opencode`, else a platform package under `node_modules`, then `spawn`s that binary with `process.argv.slice(2)`.

Alternate CLI entry is `packages/cli/src/index.ts` (`Runtime.run(Commands, Handlers, { version: "local" })`). Default `$` handler starts the TUI via `runTui(transport)` (`packages/cli/src/commands/handlers/default.ts`, `packages/cli/src/tui.ts`). `Commands` description is `"OpenCode 2.0 preview command line interface"`. Subcommands include `api`, `debug agents`, `migrate`, `service` (`start` / `restart` / `status` / `stop` / `password`), and `serve` (`packages/cli/src/commands/commands.ts`). `serve` logs `server listening on ${HttpServer.formatAddress(address)}` (`packages/cli/src/commands/handlers/serve.ts`). `packages/cli/bin/lildax.cjs` resolves like the primary bin, using cache `.lildax` and package names `@opencode-ai/cli-${platform}-${arch}`.

### TUI process

`@opencode-ai/tui` exports `run` (`packages/tui/src/index.tsx`). `Tui.run` takes `TuiInput` with required `url`, `args`, `config`, `pluginHost` (`packages/tui/src/app.tsx`). Alternate CLI `runTui` calls `run` with `args: {}`, `TuiConfig.resolve({}, { terminalSuspend: false })`, and a no-op `pluginHost` (`packages/cli/src/tui.ts`).

### Desktop and web app

Desktop local example: `bun install` then `bun dev` (`packages/desktop/README.md`). `predev` runs `bun run install-electron`, copies icons with `OPENCODE_CHANNEL ?? "dev"`, `cd ../opencode && bun script/build-node.ts`, then `downloadCliToResources()` (`packages/desktop/scripts/predev.ts`). Package/build example: `bun run build && bun run package` with output under `dist/` (`packages/desktop/README.md`).

When `OPENCODE_SIDECAR_V2 !== "1"`, main process listens on `127.0.0.1` with `OPENCODE_PORT` if parseable, else an ephemeral port, `username` `"opencode"`, `password` `randomUUID()`, and `spawnLocalServer` (`packages/desktop/src/main/index.ts`). Sidecar ready timeout is `60_000` ms (`SIDECAR_START_STALL_TIMEOUT` in `packages/desktop/src/main/server.ts`). When `OPENCODE_SIDECAR_V2 === "1"`, `startBackgroundCli` runs bundled `opencode-cli` / `opencode-cli.exe` with `--version`, `service status`, `service start`, and `service get password`; username is `"opencode"` (`packages/desktop/src/main/background-cli.ts`). Status lines that start with `running ` are parsed as the service URL (`serviceUrl`).

Web app UI example: `scripts.dev` / `start` run Vite on port `3000` (`packages/app/vite.config.ts`). `packages/app/README.md` documents `npm run dev` / `npm start` and Open `http://localhost:3000`. `packages/app/AGENTS.md` documents a split example: backend `bun run ./src/index.ts serve --port 4096` from `packages/opencode`, app `bun dev -- --port 4444` from `packages/app`, browser `http://localhost:4444` targeting `http://localhost:4096`.

### Headless HTTP and SDK hosts

`@opencode-ai/server` `createRoutes(password)` uses `ServerAuth.Config.configLayer({ username: "opencode", password: Option.some(password) })` when `password` is set; otherwise `ServerAuth.Config.layer`. `createEmbeddedRoutes()` uses `username: "opencode"` and `password: Option.none()`. `webHandler` serves `routes` with `disableLogger: true` (`packages/server/src/routes.ts`).

Legacy SDK `createOpencodeServer` launches process `opencode` with args `serve`, `--hostname=${options.hostname}`, `--port=${options.port}`, optional `--log-level=`, and env `OPENCODE_CONFIG_CONTENT` JSON (`packages/sdk/js/src/server.ts`). It resolves the first stdout line starting with `opencode server listening` and captures `on\s+(https?:\/\/[^\s]+)`. `createOpencode` returns `{ client, server }` with `createOpencodeClient({ baseUrl: server.url })` (`packages/sdk/js/src/index.ts`). `createOpencodeTui` launches `opencode` with optional `--project=`, `--model=`, `--session=`, `--agent=` (`createOpencodeTui`). In-repo example `packages/sdk/js/example/example.ts` calls `createOpencodeServer()`, `createOpencodeClient({ baseUrl: server.url })`, then `client.session.create()` and `client.session.prompt` with file `mime` `"text/plain"` and text `Write tests for every public function in this file.`

In-process SDK `OpenCode.create` builds `createEmbeddedRoutes()` and `OpenCode.make({ baseUrl: "http://opencode.local" })` (`packages/sdk-next/src/opencode.ts`). Promise client construction example in tests: `OpenCode.make({ baseUrl: "http://localhost:3000" })` (`packages/client/test/promise.test.ts`).

### Plugin and generated-client examples

Promise plugin example (`packages/plugin/src/v2/promise/README.md`): `import { define } from "@opencode-ai/plugin/v2/promise"` then `define({ id: "example", setup: async (ctx) => { ... } })`. `define` returns the given `Plugin` (`packages/plugin/src/v2/promise/plugin.ts`). Effect plugin example (`packages/plugin/src/v2/effect/README.md`): `import { define } from "@opencode-ai/plugin/v2/effect"` then `define({ id: "example", effect: Effect.fn(function* (ctx) { ... }) })` (`packages/plugin/src/v2/effect/plugin.ts`). Tool helper `tool({ description, args, execute })` returns that object (`packages/plugin/src/tool.ts`).

`@opencode-ai/client` `"."` re-exports generated HTTP types from `./generated/index` (`packages/client/src/index.ts`). Regeneration is `scripts.generate` `bun run script/build.ts` in `packages/client/package.json`; that generator, not the generated tree, is the source of truth.

### Docs, console, enterprise, and stats sites

Docs site `astro.config.mjs`: `site` is `https://opencode.ai` when `SST_STAGE === "production"`, else `https://${stage}.opencode.ai` with `stage` `process.env.SST_STAGE || "dev"` (`packages/web/config.mjs`). `base` is `"/docs"`. Console `config.baseUrl` is `"https://opencode.ai"` (`packages/console/app/src/config.ts`). Stats SolidStart app uses `FileRoutes` and `import.meta.env.BASE_URL` (`packages/stats/app/src/app.tsx`).

### Slack bot

`packages/slack/src/index.ts` constructs Bolt `App` with `token` `process.env.SLACK_BOT_TOKEN`, `signingSecret` `process.env.SLACK_SIGNING_SECRET`, `socketMode: true`, `appToken` `process.env.SLACK_APP_TOKEN`. It starts `createOpencode({ port: 0 })`, maps Slack channel+thread to `client.session.create` with `body.title` `` Slack thread ${thread} ``, optionally `client.session.share`, then `client.session.prompt` with `{ type: "text", text: message.text }`. Command `/test` replies `🤖 Bot is working! I can hear you loud and clear.` After `app.start()` it logs `⚡️ Slack bot is running!`

## Error handling

| Condition | Behavior | Source |
|-----------|----------|--------|
| Primary bin cannot resolve a native binary | stderr `"It seems that your package manager failed to install the right version of the opencode CLI for your platform. You can try manually installing " + quoted platform package names + " package"` then `process.exit(1)` | `packages/opencode/bin/opencode` |
| Alternate bin cannot resolve a native binary | stderr `"It seems that your package manager failed to install the right lildax CLI package. Try manually installing " + quoted names + " package"` then `process.exit(1)` | `packages/cli/bin/lildax.cjs` |
| Bin child `error` | `console.error(error.message)` then `process.exit(1)` | both bin wrappers `run` |
| Primary CLI parse/runtime throw | `FormatError` via `UI.error`; if unformatted, `UI.error("Unexpected error" + EOL)` and `errorMessage(e)` on stderr; `process.exitCode = 1` | `packages/opencode/src/index.ts` |
| `serve` without `OPENCODE_SERVER_PASSWORD` | stdout `Warning: OPENCODE_SERVER_PASSWORD is not set; server is unsecured.` | `ServeCommand` |
| `web` without `OPENCODE_SERVER_PASSWORD` | `UI.println` of `!  OPENCODE_SERVER_PASSWORD is not set; server is unsecured.` (warning style) | `WebCommand` |
| SDK server start timeout | reject `Timeout waiting for server to start after ${options.timeout}ms` | `createOpencodeServer` |
| SDK listen line without URL | reject `Failed to parse server url from output: ${line}` | `createOpencodeServer` |
| SDK child exit before listen | reject `Server exited with code ${code}` plus optional `Server output:` | `createOpencodeServer` |
| `lildax api` missing OpenAPI path param | throw `Missing path parameter: ${name}` | `packages/cli/src/commands/handlers/api.ts` `resolveOperation` |
| `lildax api` header without `:` | `Error` `Invalid header, expected name:value: ${header}` | `packages/cli/src/commands/handlers/api.ts` |
| Desktop sidecar not ready | reject `Sidecar did not become ready within 60000ms: ${sidecar}` | `spawnLocalServer` |
| Desktop ephemeral listen has no address | `Failed to get port` | `packages/desktop/src/main/index.ts` |
| Slack `session.create` `error` | `say` `Sorry, I had trouble creating a session. Please try again.` | `packages/slack/src/index.ts` |
| Slack `session.prompt` `error` | `say` `Sorry, I had trouble processing your message. Please try again.` | `packages/slack/src/index.ts` |
| `--mini` without TTY stdin | `INTERACTIVE_INPUT_ERROR` `"--mini requires a controlling terminal for input"` | `packages/opencode/src/cli/cmd/run/runtime.stdin.ts` |
